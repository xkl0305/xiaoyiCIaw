### 图文生图工作流踩坑记录

1. **本地文件路径问题**：`--image` 传入本地文件路径（如 `/tmp/xy_channel/xxx.jpg`）时，脚本中的 `_process_image_input` 会调用 `upload_file()` 上传图片，但后续下载环节有时会失败导致 exit code 1
2. **解决方法**：先用 `upload_file()` 手动上传本地图片获取公网 URL，再用该 URL 做 `--image` 参数
3. **提示词长度限制**：当提示词过长时，API 返回 `None` 且无明确错误信息。排查方法：缩短提示词，去掉冗余描述，让 API 能成功返回
4. **API 返回 None 的问题**：`generate_image()` 返回 None 时用 `if result:` 保护，不能直接遍历
