# 进化提案：小艺命名体系与分层关系定论

- 状态：**已确认（approved，2026-09-25）**
- 修改文件：USER.md

## 权威定论
- **小艺Cloud** = AI能力底座（大模型理解/对话系统/意图识别/服务分发/端云协同）
- **小艺App** = 系统入口（鸿蒙内置AI语音助手入口，承载对话交互与服务分发）
- **小艺Claw** = 主动执行智能体（基于OpenClaw：主动执行/深度记忆/多端协同）
- **小艺Work** = 小艺Claw 在办公场景的升级形态（鸿蒙手机端+平板端的原有小艺Claw 已升级为小艺Work，保留使用习惯/偏好/项目记忆）

当前对话即用升级后的小艺Work，底层为 Claw 智能体 + Cloud 能力底座。

## 更正点
此前记录「小艺APP=端侧壳 / 小艺Work=Claw 办公叫法」更新为上述更精确口径：小艺App=系统入口；小艺Work=Claw 的办公场景**升级形态**。共同版本号 26.9.1 仍有效。
