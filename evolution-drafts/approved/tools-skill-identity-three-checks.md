# 进化提案：技能身份定性三查法（相似命名目录≠版本演进）

- **日期**: 2026-11-01
- **状态**: pending → approved（俞哥 02:36 确认）
- **落盘目标**: TOOLS.md 技能经验区（"技能检索纪律"节之后）

## 背景

介绍 seedream-image-gen 时，机器上有 3 个相似命名目录（`seedream-image-gen` / `seedream-image_gen` / `seedream_image_gen`），AI 凭"日期新、文件大"误判下划线版为"新版主用"、连字符三通道版为"旧版冗余"并建议删除——实际两者是**不同技能**（三通道 API 直连版 vs 小艺图像创作 Flash/Pro 版），同名不同物；且 TOOLS.md 里明明固化着华为 SSE/火山 ARK 三通道实测经验，介绍时却没关联，把三通道本体当"旧版"。被俞哥指出"这个技能一直是三通道""介绍技能都能出bug"。

## 规则

1. **相似命名的目录 ≠ 版本演进关系**——可能是不同技能、兼容 shim、占位包并存，禁止仅凭目录日期/文件大小推断"新版替代旧版"。
2. 给技能定性（介绍/清理/收敛）前必须**三查**：①查引用关系（governance 注册表 skill_trigger_registry/skill_profiles、其他技能与脚本的实际调用路径）②查历史记忆（TOOLS.md/MEMORY.md 有无该技能实测固化经验）③查来源（自建实测/端侧下发/内建）。
3. 介绍用户点名的技能时，**以用户点名的目录为准**，不擅自"以最新版为准"替换介绍对象；发现疑似变体目录只作说明，不改变介绍主体。
4. 触发场景：介绍技能、技能对账、技能清理/收敛、发现多个相似命名目录时。
