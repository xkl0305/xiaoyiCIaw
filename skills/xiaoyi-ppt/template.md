# 大纲模板与格式规范

> **模型须知**：生成大纲时必须严格遵守本文件的所有格式规范。输出必须是纯 Markdown 文本，**严禁输出任何非 Markdown 格式**。

---

## 格式规范（必须遵守⚠️）

每页之间用 `\n---\n` 分隔，页面层级标记：
- `<style>` 开头 — 类型声明页（第一页声明`<style>` 标签）
- `# 标题` — 封面页（第二页）
- `## ...目录` — 目录页
- `## 01 章节标题` — 章节页（**仅双层结构**）
- `### 内容标题` — 内容页
- 生成标签必须闭合，示例：
  ~~~
  <image_gen_queries>
  - 市场分析概念插画
  </image_gen_queries>
  
  <image_search_queries>
  - 传统客服中心工作场景照片
  - 客服排队等待数据图表
  </image_search_queries>
  
  <image_user_provided>
  - /tmp/xy_channel/1782790538830_3d1fc382.jpg | 星巴克经典Logo白色哑光杯身
  </image_user_provided>
  ~~~

**绝对不可以遗漏 `\n---\n` 分割线，否则会导致格式解析失败，任务无法完成**

## ⚠️ 常见格式错误（严禁出现）

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 输出字符串列表 | `["封面", "目录"]` | 必须输出纯 Markdown 文本 |
| 缺少 `<style>` 标签 | 第一页直接 `# 标题` | 第一行必须为 `<style>xxx</style>` |
