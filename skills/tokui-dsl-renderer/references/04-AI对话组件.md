# 04 - AI / 对话组件

> ⚠️ 本分册穷举所有 AI 与对话相关组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `bubble` | 容器 | `role`, `model`, `time` | 对话气泡。`role`：`user`/`ai`/`system` |
| `toolbar` | 容器 | `pos`, `align` | 工具栏 |
| `tool-call` | 容器 | `name`, `status`, `duration`, `id` | 工具调用。`status`：`pending`/`running`/`done`/`error`/`denied` |
| `typing` | 自闭合 | `text` | 输入中指示（注意用 `text` 非 `tx`） |
| `quick-reply` | 容器 | `items`, `clk` | 快捷回复。`items` 逗号标签 |
| `suggestions` | 容器 | `cols`, `clk`, `id` | 建议卡片网格。`cols` 1-4 |
| `suggestion` | 自闭合 | `tt`, `tx`, `clk`, `icon`, `dis` | 建议项 |
| `source` | 自闭合 | `n`, `tt`, `sn`, `u`/`url` | 引用源 |
| `diff` | 容器·原始 | `title`, `lang` | 代码差异。`+` 增（绿）/`-` 删（红） |
| `file-tree` | 容器 | — | 文件树。子项 `ft-folder`/`ft-file` |
| `ft-folder` | 容器 | `name`, `open` | 文件夹 |
| `ft-file` | 自闭合 | `name`, `badge` | 文件 |
| `terminal` | 容器·原始 | `title`, `status` | 终端输出 |
| `sandbox` | 容器·原始 | `lang`, `title`, `height` | 代码沙箱 |
| `test-result` | 容器 | `pass`, `fail`, `skip`, `total`, `duration` | 测试结果。子项 `test-case`/`case` |
| `test-case`/`case` | 自闭合 | `status`, `name`, `duration`, `error` | 测试用例。`status`：`pass`/`fail`/`skip` |
| `commit` | 自闭合 | `hash`, `msg`, `author`, `branch`, `time`, `additions`, `deletions` | Git 提交 |
| `quote` | 容器 | `role`, `tx`, `msgid` | 引用消息 |
| `latency` | 自闭合 | `v`, `t` | 延迟指标。`t`：`thinking`/`generating`/`total` |
| `video` | 自闭合 | `s`, `poster`, `ratio`, `w`, `h`, `fit` | 视频。`ratio`：`16:9`/`4:3`/`1:1`/`21:9` |
| `audio` | 自闭合 | `s`, `tt`, `duration`, `w` | 音频播放器 |
| `conversations` | 容器 | `clk`, `act` | 会话列表。子项 `conv` |
| `conv` | 自闭合 | `tt`, `time`, `active`, `act` | 会话项 |
| `welcome` | 容器 | `tt`, `st`, `bd`, `hd`, `ft` | 欢迎页。子项 `welcome-feature`/`feature` |
| `welcome-feature`/`feature` | 容器/自闭合 | `tt`, `tx`, `i`, `clk` | 特性卡片。`i`：`code`/`chart`/`doc`/`dashboard`/`print`/`chat`/`table`/`form` |
| `attachments` | 容器 | `clk` | 附件列表。子项 `attach` |
| `attach` | 自闭合 | `t`, `s`, `u`, `size`, `clk` | 附件。`t`：`image`/`pdf`/`word`/`excel`/`ppt`/`zip`/`code`/`video`/`audio` |
| `artifact` | 容器 | `tt`, `lang`, `pos`, `w` | Artifact 侧边预览。子项 `artifact-code`+`artifact-preview` |
| `artifact-code` | 容器·原始 | — | Artifact 代码槽 |
| `artifact-preview` | 容器 | — | Artifact 预览槽 |
| `command` | 容器 | `ph`, `clk`, `id`, `hotkey` | 命令面板。子项 `command-group` |
| `command-group` | 容器 | `tt` | 命令分组。子项 `command-item`/`item` |
| `command-item` | 自闭合 | `tx`, `v`, `clk`, `shortcut` | 命令项 |
| `canvas` | 容器 | `tt`, `pos`, `w`, `tx`, `open`, `closable` | 画布面板。子项 `canvas-content` |
| `canvas-content` | 容器 | — | 画布内容区 |

## DSL 示例

```
[bubble role:user time:10:30]
[p 帮我写一个登录页面]
[/bubble]

[bubble role:ai model:GPT-4 time:10:31]
[typing text:正在思考...]
[tool-call name:code-gen status:done duration:2.3s id:tc1]
[md]
已为您生成登录页面代码。
[/md]
[/bubble]

[quick-reply items:"继续,修改,解释代码" clk:onReply]

[suggestions cols:2]
[suggestion tt:数据分析 tx:分析销售数据 icon:chart]
[suggestion tt:代码生成 tx:写一个REST API icon:code]
[/suggestions]

[terminal title:Terminal status:success]
$ npm install
$ npm run build
✓ Build completed
[/terminal]

[file-tree]
[ft-folder name:src open]
[ft-file name:index.js]
[ft-file name:app.js]
[/ft-folder]
[ft-file name:package.json]
[/file-tree]

[commit hash:a1b2c3d msg:"feat: add login" author:dev branch:main time:2h additions:120 deletions:30]
[latency v:1.5s t:thinking]
[source n:1 tt:官方文档 u:https://example.com]
```
