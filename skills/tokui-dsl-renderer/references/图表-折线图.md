# 折线图 `[chart t:line]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:line` | 必填 | - |
| `d:` | 单系列 `v1,v2,v3`；多系列 `v1,v2\|v3,v4` | - |
| `l:` | x 轴标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `smooth` | 曲线平滑 | `false` |
| `fill` | 填充区域（变成面积效果） | `false` |
| `stacked` | 堆叠（多系列时生效） | `false` |
| `point-radius:` | 数据点半径 | `3` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础单系列折线

```tokui
[chart t:line l:"Q1,Q2,Q3,Q4" d:"100,200,150,300" h:300 title:"季度营收" /]
```

### 2. 平滑曲线 + 单位

```tokui
[chart t:line l:"1月,2月,3月,4月,5月" d:"1200,1800,1500,2200,1900" smooth h:300 unit:"元" title:"月度销售额" /]
```

### 3. 多系列折线（`|` 分隔系列 + `legend` 显示图例）

```tokui
[chart t:line l:"一月,二月,三月,四月" d:"120,80,200,160|90,150,60,130|50,70,110,90" c:"#FF4D4F,#1677FF,#52C41A" h:400 legend title:"三产品月度对比" /]
```

### 4. 堆叠折线 + 填充

```tokui
[chart t:line l:"Mon,Tue,Wed,Thu,Fri" d:"120,132,101,134,90|220,182,191,234,290" c:"#1677FF,#52C41A" stacked fill h:350 legend title:"堆叠面积折线" /]
```

### 5. 自定义点大小

```tokui
[chart t:line l:"A,B,C,D,E" d:"10,25,18,32,22" point-radius:6 h:300 title:"大点折线" /]
```
