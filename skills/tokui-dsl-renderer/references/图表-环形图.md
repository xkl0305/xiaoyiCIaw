# 环形图 `[chart t:donut]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。与饼图类似但中间挖空。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:donut` | 必填 | - |
| `d:` | `v1,v2,v3` | - |
| `l:` | 标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `size:` | 环形大小比例（0~1） | `0.8` |
| `label-pos:` | 标签位置：`outside`/`inside`/`none` | `outside` |
| `leader-line` | 显示引导线 | `false` |
| `show-percent` | 显示百分比 | `false` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础环形图

```tokui
[chart t:donut l:"技术部,市场部,运营部,财务部" d:"40,25,20,15" c:"#1677FF,#52C41A,#FAAD14,#FF4D4F" h:400 title:"人员分布" /]
```

### 2. 引导线 + 图例

```tokui
[chart t:donut l:"Chrome,Safari,Firefox,Edge,其他" d:"65,18,8,5,4" leader-line h:400 legend title:"浏览器占比" /]
```

### 3. 标签在内 + 百分比

```tokui
[chart t:donut l:"已完成,进行中,待审批" d:"50,30,20" label-pos:inside show-percent c:"#52C41A,#FAAD14,#FF4D4F" h:350 title:"工单状态" /]
```

### 4. 调整环形大小

```tokui
[chart t:donut l:"线上,线下" d:"72,28" size:0.6 c:"#1677FF,#52C41A" h:300 title:"渠道占比" /]
```
