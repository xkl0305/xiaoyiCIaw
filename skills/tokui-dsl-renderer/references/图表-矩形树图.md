# 矩形树图 `[chart t:treemap]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。用矩形面积表示数值大小。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:treemap` | 必填 | - |
| `d:` | `名称1:值1,名称2:值2,名称3:值3`（`,` 分项，`:` 分隔名值） | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

## 容器模式

省略 `d:`，用子节点声明：

| 子节点 | 说明 |
|--------|------|
| `[hrow name:名称 value:值/]` | 一个矩形块 |

---

## DSL 示例

### 1. 基础矩形树图（`:` 分隔名称和值）

```tokui
[chart t:treemap d:"分类A:20,分类B:15,分类C:10,分类D:8,分类E:5" h:400 title:"分类占比" /]
```

### 2. 自定义颜色

```tokui
[chart t:treemap d:"手机:45,电脑:30,平板:15,手表:10" c:"#1677FF,#52C41A,#FAAD14,#FF4D4F" h:400 title:"产品线收入" /]
```

### 3. 容器模式（子节点声明）

```tokui
[chart t:treemap h:400 title:"磁盘使用"
  [hrow name:"系统" value:50/]
  [hrow name:"应用程序" value:30/]
  [hrow name:"文档" value:15/]
  [hrow name:"其他" value:5/]
]
```
