# 漏斗图 `[chart t:funnel]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。表示逐级递减的转化关系。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:funnel` | 必填 | - |
| `d:` | `v1,v2,v3`（从上到下递减） | - |
| `l:` | 层级标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`、`unit:`。

## 容器模式

省略 `d:`/`l:`，用子节点逐层声明：

| 子节点 | 说明 |
|--------|------|
| `[hrow name:名称 value:值/]` | 漏斗的一层 |

---

## DSL 示例

### 1. 基础漏斗图

```tokui
[chart t:funnel l:"展示,点击,访问,咨询,订单" d:"100,80,60,40,20" h:400 title:"营销漏斗" /]
```

### 2. 自定义颜色 + 单位

```tokui
[chart t:funnel l:"浏览,加购,下单,支付" d:"5000,2000,800,500" c:"#1677FF,#52C41A,#FAAD14,#FF4D4F" h:400 unit:"人" title:"电商转化" /]
```

### 3. 容器模式（子节点声明）

```tokui
[chart t:funnel h:400 title:"招聘漏斗"
  [hrow name:"简历投递" value:1000/]
  [hrow name:"笔试通过" value:500/]
  [hrow name:"一面通过" value:200/]
  [hrow name:"二面通过" value:80/]
  [hrow name:"最终录用" value:30/]
]
```
