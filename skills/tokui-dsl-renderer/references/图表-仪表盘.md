# 仪表盘 `[chart t:gauge]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染（非 Chart.js）。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:gauge` | 必填 | - |
| `d:` | 当前值（单数值） | - |
| `min:` | 最小值 | `0` |
| `max:` | 最大值 | `100` |
| `unit:` | 单位后缀 | - |
| `c:` | 主色（`#` 开头） | 自动 |
| `start-angle:` | 起始角度（度） | `-135` |
| `end-angle:` | 结束角度（度） | `135` |
| `thickness:` | 环宽（px） | `20` |
| `show-value` | 显示数值 | `true` |
| `show-ticks` | 显示刻度线 | `false` |
| `label:` | 底部标签文字 | - |
| `thresholds:` | 阈值色段 `阈值1,#颜色1\|阈值2,#颜色2` | - |

> 另支持通用属性：`title:`、`w:`、`h:`。

---

## DSL 示例

### 1. 基础仪表盘

```tokui
[chart t:gauge d:72 h:300 c:"#52C41A" label:"完成率" /]
```

### 2. 自定义范围 + 单位

```tokui
[chart t:gauge d:85 min:0 max:100 unit:"%" h:300 c:"#FF4D4F" label:"CPU 使用率" /]
```

### 3. 自定义角度范围 + 刻度

```tokui
[chart t:gauge d:60 min:0 max:120 start-angle:-180 end-angle:0 show-ticks h:300 unit:"km/h" label:"车速" /]
```

### 4. 阈值色段（不同区间不同颜色）

```tokui
[chart t:gauge d:75 max:100 unit:"%" thresholds:"60,#52C41A|80,#FAAD14|100,#FF4D4F" h:300 label:"系统负载" /]
```

### 5. 隐藏数值 + 细环

```tokui
[chart t:gauge d:45 thickness:10 show-value:false h:250 c:"#1677FF" label:"进度指示" /]
```
