# 06 - 表单组件

> ⚠️ 本分册穷举所有表单组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `form` | 容器 | `act`, `mtd`, `sub`, `clk`, `id` | 表单 |
| `input` | 自闭合 | `t`, `l`, `ph`, `id`, `n`, `val`, `ml`, `min`, `max`, `step`, `req`, `dis`, `ro`, `w`, `hint`, `search`, `v`, `pre`/`app`/`prebtn`/`appbtn` | 输入框。`val` 存初值（`v` 是变体） |
| `pwd` | 自闭合 | 同 `input` + `toggle` | 密码框 |
| `textarea` | 容器 | `l`, `id`, `n`, `ph`, `rows`, `maxlen`, `maxrows`, `auto`, `tx`/裸内容, `req`, `dis`, `ro` | 多行文本 |
| `select` | 容器 | `l`, `ph`, `multi`, `id`, `n`, `req`, `v`, `opt` | 下拉选择。子项 `opt` |
| `radio` | 容器 | `l`, `id`, `n`, `v`, `opt` | 单选组。子项 `opt` |
| `opt` | 自闭合 | `v`, `tx`, `chk`, `p` | 选项（随父级变 select/radio/checkbox/picker/cascader/transfer） |
| `checkbox` | 自闭合/容器 | `l`, `chk`, `id`, `n`, `v`, `opt`, `multi` | 复选框（三态） |
| `switch` | 自闭合 | `l`, `chk`, `dis`, `clk`, `id`, `n`, `v` | 开关 |
| `slider` | 自闭合 | `l`, `min`, `max`, `step`, `v`, `dis`, `clk`, `id`, `n` | 滑块 |
| `rate` | 自闭合 | `l`, `v`, `max`, `tx`, `ro`, `dis`, `clk`, `id`, `n` | 评分 |
| `numinput` | 自闭合 | `l`, `v`, `min`, `max`, `step`, `dis`, `id`, `n` | 数字输入 |
| `btn` | 自闭合 | `tx`, `t`, `sub`, `clk`, `id`, `dis`, `w`, `bg`, `fc`, `radius`, `icon`, `i`, `l`/`tt`, `form`, `reset`, `print` | 按钮 |
| `btngroup` | 容器 | `id`, `v` | 按钮组 |
| `picker` | 容器 | `l`, `ph`, `multi`, `dis`, `id`, `n`, `v` | 选择器（搜索下拉）。子项 `opt` |
| `cascader` | 容器 | `l`, `ph`, `dis`, `clk`, `v`, `id`, `n` | 级联选择。子项 `opt`（`p` 指定父值） |
| `transfer` | 容器 | `l`, `tt`, `tt2`, `clk`, `id`, `dis`, `n`, `h`, `mh` | 穿梭框。子项 `opt`（`chk` 进右栏） |
| `upload` | 自闭合 | `l`, `ph`, `accept`, `multi`, `dis`, `clk`, `max`, `id`, `n` | 文件上传 |
| `datepicker` | 自闭合 | `l`, `ph`, `fmt`, `v`, `clk`, `dis`, `id`, `n` | 日期选择 |
| `timepicker` | 自闭合 | `l`, `ph`, `fmt`, `v`, `clk`, `dis`, `id`, `n` | 时间选择 |
| `datetimepicker` | 自闭合 | `l`, `ph`, `fmt`, `v`, `clk`, `dis`, `id`, `n` | 日期时间选择 |

## opt 简写语法

`;` 分隔项，`:` 分隔 value:label，整串**必须双引号**：

```
[radio n:gender l:性别 opt:"1:男;2:女"]
[select n:city l:城市 opt:"bj:北京;sh:上海"]
[checkbox n:brand l:品牌 opt:"1:篮球;2:足球;3:羽毛球"]
```

## checkbox 三态

| 形态 | 判定 | 写法 |
|------|------|------|
| 单布尔 | 无 `opt` 无 `multi` | `[checkbox l:同意协议 n:agree]` |
| 简写多选 | 有 `opt` | `[checkbox n:brand l:品牌 opt:"1:篮球;2:足球"]` |
| 容器多选 | 有 `multi` | `[checkbox n:brand l:品牌 multi][opt v:1 tx:篮球]…[/checkbox]` |

## btn 内置动作

优先级 `print > reset > submit > clk`：

```
[btn tx:提交 form:login sub:onLogin t:primary]    ;; 绑定表单提交
[btn tx:重置 form:login reset]                     ;; 重置绑定表单
[btn tx:打印 print:pa1]                            ;; 打印 print-area#pa1
[btn tx:打印本卡 print:self]                       ;; 打印最近祖先
```

## btn 图标

```
[btn tx:查看 icon:view t:primary clk:view]         ;; icon: 取内置 SVG 名（见公共规范 §7）
[btn icon:edit l:保存 clk:save]                    ;; icon-only，l: 作 tooltip
[btn tx:复制 i:📋 clk:copy]                        ;; i: emoji/字符
```

## DSL 示例

```
[form id:login sub:handleLogin]
[input t:text l:用户名 id:uname req ph:请输入用户名]
[pwd l:密码 id:pwd req ph:请输入密码]
[btn tx:登录 t:submit clk:handleLogin v:primary block]
[/form]

[input t:email l:邮箱 id:email ph:请输入邮箱 v:underline]
[input l:金额 id:amount t:number min:0 max:10000 step:100 pre:"¥"]
[input l:搜索 ph:请输入关键词 search]

[textarea l:备注 id:remark ph:请输入备注内容 rows:4]

[select l:城市 id:city opt:"bj:北京;sh:上海;gz:广州"]

[radio n:gender l:性别 opt:"m:男;f:女"]
[radio n:pay l:支付方式 v:inline]
[opt v:wx tx:微信支付]
[opt v:ali tx:支付宝]
[/radio]

[checkbox l:同意协议 id:agree req]
[checkbox n:hobby l:爱好 opt:"1:篮球;2:足球;3:游泳"]

[switch l:通知 chk id:sw1]
[slider l:音量 min:0 max:100 v:50 id:sl1]
[rate l:评分 v:4 id:r1]
[numinput l:数量 v:1 min:0 max:999 id:ni1]

[datepicker l:开始日期 ph:选择日期]
[timepicker l:会议时间 fmt:HH:mm]
[datetimepicker l:截止时间]

[upload l:上传文件 accept:".pdf,.doc" max:5]
[cascader l:地区]
[opt v:bj tx:北京]
[opt v:sh tx:上海 p:华东]
[opt v:hz tx:杭州 p:华东]
[/cascader]
```
