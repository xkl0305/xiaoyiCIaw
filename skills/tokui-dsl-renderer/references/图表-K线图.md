# K线图 `[chart t:candlestick]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。展示股票/期货的开盘、最高、最低、收盘价。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:candlestick` | 必填 | - |
| `d:` | `open,high,low,close;open,high,low,close`（`;` 分K线，`,` 分 OHLC 四值） | - |
| `l:` | x 轴标签（日期等） | - |
| `up-color:` | 阳线颜色（`#` 开头） | `#52C41A` |
| `down-color:` | 阴线颜色（`#` 开头） | `#FF4D4F` |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

---

## DSL 示例

### 1. 基础 K 线图（每根 K 线：开盘,最高,最低,收盘）

```tokui
[chart t:candlestick l:"周一,周二,周三,周四,周五" d:"20,25,18,23;23,28,21,26;26,30,24,28;28,32,25,27;27,35,26,33" h:400 title:"周K线" /]
```

### 2. 自定义阴阳线颜色

```tokui
[chart t:candlestick l:"01-01,01-02,01-03,01-04" d:"100,110,95,108;108,115,105,112;112,118,108,110;110,120,108,118" up-color:"#52C41A" down-color:"#FF4D4F" h:400 title:"日线走势" /]
```

### 3. 实际股票数据示例

```tokui
[chart t:candlestick l:"3/1,3/2,3/3,3/4,3/5" d:"3050,3120,3020,3100;3100,3150,3080,3130;3130,3180,3100,3160;3160,3200,3140,3180;3180,3250,3150,3230" h:450 title:"沪深指数" /]
```
