# 07 - 表格组件

> ⚠️ 本分册穷举所有表格组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `table` | 容器 | `stripe`, `cap`/`caption`, `v`, `id` | 表格 |
| `thead` | 容器/自闭合 | `cols` | 表头。列名支持对齐(`/c`/`/r`/`/l`)和配色(`/primary`等) |
| `tbody` | 容器 | — | 表体 |
| `tr` | 自闭合 | `cs`(legacy), `v:total` | 行，逗号分隔单元格 |
| `tcol` | 自闭合 | `n` | 列占位 |

---

## tr 单元格特殊语法

- **序号列**：thead 写 `#`，tr 对应位置留空
- **勾选列**：thead 写 `chk`
- **进度条**：`progress v:98 t:span`
- **标签**：`tag:VIP t:success`
- **操作按钮**：`btn:详情 clk:handler|btn:删除 v:danger clk:handler`（`|` 分隔多钮）
- **内联组件**：`[badge count:5]`、`[dot t:success tx:运行中]`
- **横向合并**：`值=cN`（横跨 N 列）
- **纵向合并**：`值=rN`（纵跨 N 行）
- **对齐**：`/c` 居中 `/r` 居右 `/l` 居左
- **配色**：`/primary` `/success` `/warning` `/danger` `/info`
- **汇总行**：`tr v:total`

---

## 表格翻页

表格本身不含分页逻辑，翻页通过在 `[table]` 后放置 `[pagination]` 组件实现。

**约束：每页默认 10 条，总记录数禁止超过 200 条。**

`pagination` 属性：

| 属性 | 说明 |
|------|------|
| `page` | 当前页码（默认 1） |
| `total` | 总页数 |
| `count` | 总条目数（配合 `show-total` 显示） |
| `show-total` | 布尔，显示总条目/总页数 |
| `clk` | 翻页回调名，回调参数 `{ page: 页码 }` |
| `s` | 尺寸：`sm` / `lg` |

> `pagination` 组件的完整属性定义见 02-状态反馈与交互手册。

---

## DSL 示例

### 基础表格（勾选列 + 标签 + 操作按钮 + 汇总行）

```
[table stripe v:compact]
[thead cols:"#,chk,姓名,年龄/c,城市/r,状态,操作"]
[tbody]
[tr ,张三,25,北京,tag:在职 t:success,btn:详情 clk:view|btn:删除 v:danger clk:del]
[tr ,李四,30,上海,tag:休假 t:warning,btn:详情 clk:view]
[tr ,王五,28,深圳,tag:在职 t:success,btn:详情 clk:view]
[tr v:total 合计,,,3人,,,]
[/tbody]
[/table]
```

### 对齐与数字格式

```
[table]
[thead cols:"姓名,部门/c,绩效/r,等级/c,工资/l"]
[tbody]
[tr 张三,技术部,95,A,"10,500"]
[tr 李四,产品部,88,B,"9,500"]
[tr 王五,设计部,92,A,"10,000"]
[/tbody]
[/table]
```

### 基础翻页表格（50 条数据，每页 10 条 = 5 页）

```
[table stripe id:userTable]
[thead cols:"#,姓名,部门,职位,状态"]
[tbody]
[tr ,张三,技术部,前端,tag:在职 t:success]
[tr ,李四,产品部,经理,tag:在职 t:success]
[tr ,王五,设计部,主管,tag:休假 t:warning]
[tr ,赵六,运营部,专员,tag:在职 t:success]
[tr ,孙七,技术部,后端,tag:在职 t:success]
[tr ,周八,人事部,主管,tag:出差 t:info]
[tr ,吴九,财务部,会计,tag:在职 t:success]
[tr ,郑十,技术部,测试,tag:在职 t:success]
[tr ,陈十一,市场部,总监,tag:在职 t:success]
[tr ,林十二,技术部,架构师,tag:在职 t:success]
[/tbody]
[/table]
[pagination page:1 total:5 count:50 show-total clk:onPageChange /]
```
