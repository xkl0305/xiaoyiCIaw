# 01 - 文本与基础组件

> ⚠️ 本分册穷举所有文本与基础组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `h1`~`h6` | 自闭合 | 裸内容, `v`, `bg`, `fc` | 标题。变体见公共规范 §4 |
| `p` | 双模 | 裸内容, `v` | 段落。有正文=自闭合（可含内联子节点 `a`/`tag`/`b`/`strong`/`em`/`mark`/`spin`/`sub`/`sup`/`code`/`i`）；无正文=容器 `[p]...[/p]` |
| `a` | 自闭合 | `u`, `tx`/裸内容, `tt`, `target`, `dis`, `v` | 链接。href 白名单：`http(s)`/`mailto`/`tel`/`/`/`#` |
| `img` | 自闭合 | `s`, `alt`, `w`, `h`, `tt`, `v` | 图片（点击灯箱）。变体：`avatar`/`rounded`/`bordered` |
| `hr` | 自闭合 | — | 水平分割线 |
| `dv` | 自闭合 | `tx`/裸内容, `v`, `vert`, `size`, `align`, `bg`, `th`, `plain` | 分割线 |
| `md` | 容器·原始 | — | Markdown 渲染 |
| `code` | 容器·原始 | `lang` | 语法高亮代码块。`lang` 可选值：`js`/`ts`/`py`/`html`/`css`/`sql`/`json`/`java`/`go`/`rust`/`bash` 及别名 `javascript`/`jsx`/`tsx`/`typescript`/`sh`/`shell`/`zsh` |
| `tag` | 自闭合 | `tx`, `t`, `s`, `round`, `bordered`, `closable`, `dis`, `bg`, `fc` | 标签。`t` 颜色：`default`/`primary`/`success`/`warning`/`danger`/`info`。`s` 尺寸：`small`/`medium`/`large` |
| `b`/`strong` | 自闭合 | 裸内容 | 加粗 |
| `em` | 自闭合 | 裸内容 | 斜体 |
| `mark` | 自闭合 | 裸内容 | 高亮 |
| `del` | 自闭合 | 裸内容 | 删除线 |
| `sub`/`sup` | 自闭合 | 裸内容 | 下标/上标 |

---

## DSL 示例

```
[h1 v:center 项目概览]

[p 这是一段普通文本，包含 [a u:https://example.com 链接] 和 [tag tx:标签 t:success]。]

[md]
# Markdown 标题
- 列表项 A
- 列表项 B
[/md]

[code lang:js]
function hello() {
  console.log("Hello TokUI!");
}
[/code]

[dv tx:分割线 v:dashed]
[hr]
```
