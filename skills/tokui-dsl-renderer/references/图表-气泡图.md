# 气泡图 `[chart t:bubble]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。散点图的扩展，第三个维度用气泡大小表示。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:bubble` | 必填 | - |
| `d:` | `x,y,s;x,y,s;x,y,s`（`;` 分点，`,` 分 x/y/大小） | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础气泡图（每个点有 x、y、大小三个值）

```tokui
[chart t:bubble d:"10,20,5;20,30,8;30,25,3;40,35,6" h:300 title:"项目风险评估" /]
```

### 2. 自定义颜色

```tokui
[chart t:bubble d:"100,200,15;200,150,25;300,100,10;150,250,20;250,300,18" c:"#1677FF" h:350 title:"城市人口分布" /]
```

### 3. 多色气泡 + 图例

```tokui
[chart t:bubble d:"5,15,8;15,25,12;25,20,6|8,18,10;18,28,15;28,22,9" c:"#FF4D4F,#1677FF" h:400 legend title:"A组 vs B组" /]
```
