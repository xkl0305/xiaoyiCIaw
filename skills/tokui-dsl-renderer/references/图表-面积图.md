# 面积图 `[chart t:area]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。本质是自动填充区域的折线图。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:area` | 必填 | - |
| `d:` | 单系列 `v1,v2,v3`；多系列 `v1,v2\|v3,v4` | - |
| `l:` | x 轴标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `smooth` | 曲线平滑 | `false` |
| `stacked` | 堆叠（多系列时生效） | `false` |
| `fill-opacity:` | 填充透明度（0~1） | `0.4` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础面积图

```tokui
[chart t:area l:"Mon,Tue,Wed,Thu,Fri" d:"120,132,101,134,90" h:300 title:"工作日流量" /]
```

### 2. 平滑曲线 + 自定义透明度

```tokui
[chart t:area l:"1月,2月,3月,4月,5月,6月" d:"220,180,250,310,280,350" smooth fill-opacity:0.3 h:300 unit:"次" title:"月度访问量" /]
```

### 3. 多系列面积图（`|` 分隔 + 图例）

```tokui
[chart t:area l:"Q1,Q2,Q3,Q4" d:"120,200,150,300|80,150,100,200" c:"#1677FF,#52C41A" h:400 legend title:"产品线营收" /]
```

### 4. 堆叠面积图

```tokui
[chart t:area l:"一月,二月,三月,四月" d:"120,132,101,134|220,182,191,234|150,232,201,154" c:"#1677FF,#52C41A,#FAAD14" stacked h:400 legend title:"渠道流量堆叠" /]
```
