# 柱状图 `[chart t:bar]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:bar` | 必填 | - |
| `d:` | 单系列 `v1,v2,v3`；多系列 `v1,v2\|v3,v4` | - |
| `l:` | 类别标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `horizontal` | 水平方向（横向柱状） | `false` |
| `stacked` | 堆叠（多系列时生效） | `false` |
| `border-radius:` | 柱体圆角半径 | `0` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础柱状图

```tokui
[chart t:bar l:"苹果,香蕉,橙子,葡萄" d:"300,200,150,250" h:300 title:"水果销量" /]
```

### 2. 自定义颜色 + 圆角

```tokui
[chart t:bar l:"语文,数学,英语" d:"85,92,78" c:"#1677FF,#52C41A,#FAAD14" border-radius:8 h:300 title:"考试成绩" /]
```

### 3. 多系列柱状图（`|` 分隔系列 + `legend`）

```tokui
[chart t:bar l:"Q1,Q2,Q3,Q4" d:"100,200,150,300|80,180,120,250" c:"#1677FF,#FF4D4F" h:400 legend title:"两年营收对比" /]
```

### 4. 水平柱状图

```tokui
[chart t:bar l:"研发部,市场部,运营部,财务部" d:"45,32,28,15" horizontal h:300 unit:"人" title:"部门人数" /]
```

### 5. 堆叠柱状图

```tokui
[chart t:bar l:"一月,二月,三月" d:"120,80,150|80,120,60|50,40,70" c:"#1677FF,#52C41A,#FAAD14" stacked h:400 legend title:"产品堆叠销量" /]
```
