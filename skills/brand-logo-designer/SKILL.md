# Brand Logo Designer

为高端品牌生成 SVG Logo 方案集 + 展示页面。用户只需提供品牌基础信息即可产出可交付的完整方案。

## 工作流程

### 1. 收集品牌信息

要求用户提供以下信息：
- **品牌名称**（中英文）
- **品牌定位**（如：高端东方美学香氛）
- **品牌调性**（2-4个关键词，如：静谧、诗意、克制）
- **可选**：品牌名出处/典故、主色调偏好、行业属性

### 2. 生成 5 套 Logo 设计方案

按以下固定风格清单生成，每套都需要适配用户提供的品牌：

| # | 风格 | 描述 | 推荐场景 |
|---|------|------|----------|
| 1 | **现代极简 · 山峦/形态融合** | 克制线条、充分留白，几何山脊+升腾抽象符号，体现克制美学 | 官网·名片·品牌主视觉 |
| 2 | **浮雕云纹 · 层叠纹理** | 多层渐变远山+流云线条，浅浮雕质感，金色细框装裱 | 礼盒·瓶身雕刻·线下店招 |
| 3 | **抽象几何 · 瓶身/器物剪影** | 器物轮廓+内部抽象几何图形，"瓶中藏境"的东方哲学 | 产品包装·电商·App图标 |
| 4 | **水墨写意 · 笔触与留白** | SVG路径模拟毛笔枯湿浓淡，墨色晕染，印章点睛 | 限定版·品牌故事·艺术联名 |
| 5 | **文字意境 · 字形即Logo** | 品牌汉字作为主视觉，字形疏朗，辅以装饰线性符号 | 全场景通用标识 |

### 3. 色彩系统（可用作参考）

```
墨绿 #2D4A3E  —— 主色（静谧、自然）
金色 #C9A96E  —— 辅助色（奢华、克制）
深褐 #4A3728  —— 辅助色（大地、沉稳）
米白 #F5F0E8  —— 背景/点缀（留白、呼吸感）
暗红 #6B3A3A  —— 印章/点缀（东方、温度）
```

### 4. 生成展示 HTML + 单独 SVG 文件

#### 4.1 HTML 展示页面
单文件、无外部依赖，包含：
- 深色背景（#0D0D0D 或 #1A1A1A）
- 所有 5 套 SVG 内联
- 每个 Logo 带标题、设计说明、推荐场景标签
- 网格/瀑布流布局，适配桌面和移动端
- 淡入动画
- 品牌 header（名称+标语）

#### 4.2 单独 SVG 文件
每套 Logo 生成独立的 `.svg` 文件，保存到 output/ 目录：
- `logo-minimalist.svg`
- `logo-relief.svg`
- `logo-bottle.svg`
- `logo-inkwash.svg`
- `logo-typography.svg`

**每个 SVG 必须包含：**
- `role="img"` 属性
- `<title>` 标签
- `<desc>` 标签
- 品牌名称文字

#### 4.3 交付
- 生成后，使用 `send_file_to_user` 工具把 HTML 和所有 SVG 文件一起发给用户
- 向用户说明 5 套方案的风格特征和推荐场景

## SVG 设计指南

### 命名空间与结构
- viewBox 统一使用 `0 0 600 360`（便于排版对齐）
- 使用 `<defs>` 定义渐变色
- 颜色使用品牌主色调

### 渐变色技巧
- 墨绿渐变：从 `#2D4A3E` 到 `#3A5C4E` 制造层次
- 金色渐变：从 `#C9A96E` 到 `#E8D5A0` 再回到 `#C9A96E` 表现金属质感
- 透明度控制：主体元素 opacity 0.7-0.9，装饰元素 0.1-0.4

### 文字处理
- 中文字体：`Georgia,'Noto Serif SC','Songti SC',serif`
- 英文字体：`Georgia,serif`
- 字号保持品牌名 13-18px，英文副标 9-12px
- letter-spacing 使用 6-12 营造疏朗感

## 资源

### assets/templates/
预置的 5 套 SVG 模板文件（对应"暮山归远"品牌示例），可直接复用结构或修改品牌名与配色。

1. 一个 `logo-showcase.html` 展示页面
2. 5 个独立 `.svg` 文件
3. 全部文件打包或单独发送给用户
