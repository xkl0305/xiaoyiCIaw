# 通用定义

## 接口结果通用释义

这些是接口最外层的通用状态响应字段。

| 字段路径       | 类型  | 核心释义          |
| ---------- | --- | ------------- |
| `code`     | 数字  | 接口全局状态，0 = 成功 |
| `msg`      | 字符串 | 接口提示信息        |
| `serialNo` | 字符串 | 请求的唯一标识ID     |
| `data`     | 对象  | **核心业务数据**    |

## 通用金额转换规则

适用于所有财务数据及行情中的金额字段：

- 绝对值 ≥ 1亿（100,000,000）时，转换为"X.XX亿元"（四舍五入保留两位小数）
- 1万（10,000） ≤ 绝对值 < 1亿时，转换为"X.XX万元"
- 绝对值 < 1万时，保留原数值并以"元"为单位，保留两位小数（如"1234.56元"）
- 日涨跌幅等百分比字段直接在数字后加"%"，保留两位小数（如"3.25%"）
