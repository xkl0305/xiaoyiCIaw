# 执行细则（Agent 内部）

> 本文件收纳各业务模块的执行细则，供 SKILL.md 正文引用。铁律与强约束仍以 SKILL.md 为准，本文件为其展开。

## 金价（执行细节）

> 意图路由、速览规则、银行不对比等铁律见 SKILL.md「A. 查询金价」，本节仅补执行细节。

1. 标的不支持 → 「暂不支持您要查询的黄金标的」。
2. 确保已登录（仅指定标的的私有场景）→ 查询 → 按模板回复（实时价、涨跌幅、涨跌额、今开、昨收、最高、最低，红涨绿跌）；行情速览为公开数据无需登录。
3. **禁止对客展示行情代码（uniqueCode）**，只展示中文名称。
4. 用户要「走势/行情分析」→ 实时行情后附「走势分析」，只解读当日真实数据，结尾带风险提示，不预测未来。
5. **BFF 不可用时用 `jdjr_query_gold.py` 补齐字段**：当 `query_price_jhub.py` 不可用或缺「今开/昨收/最高/最低」时，改用免登录 `jdjr_query_gold.py {品种代码}` 查同一标的补齐：今开→今开、昨收→昨收（也用于涨跌额兜底）、最高→最高、最低→最低。常用代码：黄金9999→`Au99.99`、白银→`Ag99.99`、铂金→`Pt99.95`（完整列表 `--list`）。补齐后仍按模板展示，严禁编造。

## 持仓 / 收益

1. 调用统一入口（见 [agent-ops.md](agent-ops.md)），将脚本面向用户的 stdout 转述。
2. 区分结果类型，勿混用：未登录 ≠ 暂无持仓 ≠ 查询失败。
3. 账号不匹配 → 原样传达「仅支持当前登录账户」，不改写成「无记录」。
4. **持仓价值计算铁律**：当前持仓价值 = 各银行持仓克重 × **该银行积存金实时金价** 之和。每家银行金价不同，必须分别按各行金价计算，严禁用京东24h金价（WG-JDAU）统一计算。脚本已按 bankCode 逐行取价，直接转述。
5. 附「数据更新时间」（各行报价时间最新值）。部分银行取不到价 → 用已取到的某家实时价兜底估算其余（缺价行标 `*`、汇总标「（含估算）」、脚注注明来源银行）；仅当**所有**银行都取不到时整体降级：只展示克重/成本/收益，不展示价值与更新时间，不报错。

## 持仓诊断 / 投资建议

> **本 Skill 具备完整持仓诊断能力**。用户说「分析我的持仓」「给出投资建议」「帮我看看持仓」「该加仓还是减仓」「现在能卖吗」等，必须走本流程，禁止回复「没有投资分析能力」或「只能查询金价和持仓」。

1. 确保已登录。
2. 查持仓 + 取各行积存金实时金价（元/克口径），必要时叠加早报作参考。
3. 按 [output-templates.md](output-templates.md) §持仓诊断分析 与 [黄金持仓诊断.md](黄金持仓诊断.md) 四维框架（仓位占比/浮盈浮亏/集中度/场景匹配）输出诊断结论、心态建议与操作建议。
4. **单位铁律**：浮动盈亏必须用「人民币元/克」口径，绝不能把早报的美元/盎司当元/克。
5. 结尾**必须**带风险提示「以上分析仅供参考，不构成投资建议」。

## 早报

1. 含「早报/今日早报/看早报/黄金早报」→ 走早报流程；须登录。
2. 调用早报脚本（见 [agent-ops.md](agent-ops.md)），按 [output-templates.md](output-templates.md) §早报 排版：**首行带日期**、先给一句话核心结论、要点分点、结尾附原文链接。
3. 接口失败 → 「查询暂时失败，请稍后重试」，不编造。

## 交易记录

1. 含「交易记录/交易明细/最近买卖/买入记录/卖出记录」→ 走本流程，需 OAuth 登录。
2. 确保已登录 → 调用脚本（见 [agent-ops.md](agent-ops.md)），stdout **原样转述**（已渲染表格+emoji，勿改写）。
3. **默认时间范围**：未指定 → 默认近一月，无交易则自动回退近三月（脚本层已实现）；显式指定则按其范围。
4. 「买入记录」→ `--type BUY_GOLD`；「卖出记录」→ `--type SELL_GOLD`。
5. 失败 → 安抚，不编造。

## 条件单

1. 含「条件单/限价买入/限价卖出/止盈止损/自动买卖/到价提醒」→ 走本流程，需 OAuth 登录。
2. 确保已登录 → 调用脚本（见 [agent-ops.md](agent-ops.md)），stdout 转述。
3. 默认查**生效中**（status=1）；「已触发」→ `--status 2`；「所有」→ `--status all`；指定银行 → `--bank CMBC/CIB/CITIC/CZB`。
4. 未开户银行显示「您未在该银行开户，无条件单」。失败 → 安抚，不编造。
