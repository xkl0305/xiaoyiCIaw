# 安装与升级细节（Agent 内部 · 勿向用户展示本文件）

## 一、安装 / 启用

触发：用户请求「安装 jdgold」「启用黄金 Skill」或同义表述。

### 安装回复规范（硬性）

面向用户只呈现**业务化分步进度**，严禁暴露底层细节：
- 禁止：脚本名、命令行（`python3 xxx.py`/`curl`/`git clone`/`pip install`）
- 禁止：目录/文件路径、`scripts/`、`references/`、Token 缓存位置、日志路径
- 禁止：接口/网关/方法名（JHub/JOS/OAuth/access_token/BFF/`jingdong.*`/`localhost:xxxx`）
- 禁止：内部报错原文、stderr、`[内部]` 前缀内容
- 应用业务词：「基础包」「业务 Skill 包」「校验」「安装」「验证」「刷新入口」

### 安装进度话术（分步反馈，逐条给简短可读反馈，禁一次性沉默执行）

1. **Step 1｜获取基础包**：识别运行环境，获取基础包下载链接。安装流程若检测到本地已有 `version.json` → 走升级流程（先对比版本再决定是否下载）。
2. **Step 2｜校验并安装基础包**：展示版本号与大小 →「SHA256 校验通过 ✅ 解压安装」→「基础包安装完成 ✅」。
3. **Step3｜写入长期可见入口**。
4. **Step 4｜同步业务 Skill 包列表**：获取数量 →「全部 N 个业务包安装成功 ✅ 验证并刷新入口」。
5. **Step 5｜验证并输出安装总结**（见下方模板）。
6. **Step 6｜安装完成，主动拉起登录**：若无有效凭证 → 无需用户再要求，主动发起登录；若已有有效凭证 → 跳过，提示可开始查询。

### 安装总结模板（Step 5）

版本号/数量/分类为示例格式，实际以安装结果填充；不展示任何真实文件路径、脚本名或 Token：


### 安装成功后拉起登录（按登录状态分支）

全程主动执行，不等用户开口：
- **分支 A｜已有有效凭证**：跳过登录，提示「登录状态无需重新登录——已存在有效的登录凭证 ✅，现在可以开始查询金价、持仓、早报等」。
- **分支 B｜无凭证/已过期**：主动拉起登录：
  1. 说明「安装完成 ✅，正在为您拉起登录。」
  2. 执行 `jos.py login-auto`（本地终端唤起浏览器；远端/沙箱展示授权链接由用户手动打开，详见 oauth-integration.md）。
  3. 等用户在浏览器完成授权，回调页提示「已经登陆成功」，用户复制该提示词发送。
  4. 收到用户确认后执行 `jos.py exchange`，成功提示「登录成功 ✅，现在可以开始查询金价、持仓、早报等」。
  5. 失败/超时 → 按「常见登录异常处理」引导重试，不暴露底层错误原文。

## 二、版本检查与升级

### 触发时机

1. **会话静默检查**（执行契约第 2 条）：每个新会话首次加载 Skill 时自动执行 `upgrade.py check`。有新版本→提示；已最新或检查失败→静默跳过。
2. **用户主动升级**：「升级 jdgold」「更新黄金 Skill」「检查更新」「有没有新版本」「更新到最新版」等 → 完整升级流程。
3. **安装时发现旧版本**：安装 Step 1 检测到 `version.json` → 走升级流程。

### 升级回复规范

与安装一致：只呈现业务化进度，严禁暴露底层细节（脚本名、路径、URL、SHA256 哈希等）。

### 会话静默检查

```bash
cd ${SKILL_DIR}/scripts
python3 upgrade.py check
```

- **退出码 0（有新版本）**：解析 stdout JSON，向用户展示以下**加大加粗、醒目**的更新卡片（置于回复最顶部，与业务内容用分隔线隔开）：
  ```
  > # 🚀 重要提示：京东黄金 Skills 有新版本可用！
  >
  > ## **v{current}  →  v{latest}**
  >
  > **📝 更新内容：{changelog_summary}**
  >
  > ### 👉 **强烈建议立即更新，以获取最新功能与修复！**
  > ### 只需回复 **「升级 jdgold」** 即可一键更新 ✅

  ---
  ```
  然后正常继续处理原始请求，不中断。
- **退出码 4（已是最新）**：静默，不输出。
- **退出码 1/5（网络错误/未配置）**：静默跳过，不影响正常功能。

### 用户主动升级流程

**Step 1｜检查版本** `python3 upgrade.py check`
- 退出码 4 → 「当前已是最新版本 v{version} ✅」，结束。
- 退出码 0 → 展示更新信息：
  ```
  📦 发现新版本：v{current} → v{latest}
  更新内容：{changelog_summary}
  {若 breaking_changes=true: ⚠️ 本次升级含重大变更，升级后可能需要重新登录}
  {若 upgrade_notice 非空: 📝 {upgrade_notice}}

  是否立即升级？
  ```
  等用户确认（「升级」「好的」「确认」等）后继续。

**Step 2｜下载更新包** `python3 upgrade.py download`
- 展示「正在下载更新包…」→ 成功「更新包下载完成 ✅ 校验通过」；失败（退出码 1/2）→「下载或校验失败，请稍后重试」，终止。

**Step 3｜安装更新** `python3 upgrade.py apply {download返回的path}`
- 展示「正在安装更新…」→ 成功「升级完成 v{old} → v{new} ✅」；失败（退出码 3）→「安装失败，请稍后重试」，终止。

**Step 4｜升级总结**
```
✅ 京东黄金 Skills 升级完成

【版本】v{old} → v{new}
【更新内容】{changelog_summary}

现在可以继续正常使用所有功能。
```
