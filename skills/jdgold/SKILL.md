# 黄金服务Skill（jdgold）

查询黄金标的实时金价，以及**当前登录账号**的积存金持仓与收益；并支持黄金**模拟交易**（模拟金叶子买卖、账户/记录查询、行情分析，以及「全自动托管」自动盯盘低买高卖）。

> **首次调用时请完整读取本文件**。同一会话内若距上次读取不超过 5 分钟且无版本更新提示，可复用缓存。

## 关键行为规则

### 0. 全局铁律（详见 iron-rules.md）

- **接口超时与失败重试**（§3）：最多重试 5 次、退出码 0 不等于成功、五次失败后安抚、禁止编造。
- **金价单位一致性**（§1）：人民币元/克 vs 美元/盎司严禁混用；算浮盈浮亏必须元/克口径；早报价位不参与计算。
- **金价查不到时约数兜底**（§4）：优先真实价→黄金9999→伦敦金换算，约数标「约」，优先出结果。
- **客户端类型上报（claw）**：所有脚本均支持 `--claw`，取值优先级命令行 `--claw` > 环境变量 `CLAW`；底层自动附加请求头 `x-claw`，为空则不注入。细节见 [agent-ops.md](references/agent-ops.md)。

### A. 查询金价（未指定标的直接出速览，禁止回问）

> **★查金价铁律**：
> - 「查金价/黄金多少钱/金价怎么样/今日金价/实时金价」等**未指定标的** → **唯一正确动作=输出「黄金行情速览」**（`query_price_jhub.py --overview`），含黄金基础行情组 + 积存金组两组。
> - **禁止**：❌ 只给黄金9999或京东24h金价单条；❌ 回问「请输入要查询的标的」；❌ 先要求 OAuth 登录——行情速览为公开行情，无需登录。
> - **退出码 3 ≠ 需要登录**：`--overview` 内建每标的最多 5 次重试，偶发 `code=-1` 属正常抖动，按全局重试规则重试即可。

1. **未指定标的 → 「黄金行情速览」**：调用 `python3 query_price_jhub.py --overview`（或 `--parse "查询金价"`），含两组：
   - **一、黄金基础行情**：黄金9999（上金所）、伦敦金（美元/盎司）、京东24h金价（元/克）；说明京东24h金价拟合了黄金9999、伦敦金、暗金（PAXG），实现 7×24 连续报价；现货类休市自动提示。附一句总结。
   - **二、黄金积存金实时行情**：浙商、民生、兴业积存金（元/克）；附一句总结，说明积存金主要跟踪黄金9999和伦敦金。
2. **指定标的 → 单条查询**：标的明确且支持 → 确保已登录 → 查询 → 按模板返回。
3. **银行维度**：指定某银行积存金价 → 查该银行 uniqueCode 对应金价。
4. **不做跨标的对比**：单问某家银行积存金价格时只回该行金价，不与京东24h金价对比，除非用户明确要求。
5. **涨跌额兜底**：接口可能不返回 raise 字段，脚本已用「最新价 − 昨收」兜底，直接转述。

### B. 查询持仓/收益（须登录）

1. **仅支持当前登录账号**，不支持指定他人账号。
2. 他人账号且与当前登录不一致 → 「仅支持查询您当前登录账户的信息」。
3. 未登录 → 给授权链接；优先用 `--wait-login`，登录后自动续查。
4. **不要编造**持仓或收益数据。

| 用户表述 | 处理 |
|----------|------|
| 查询持仓/收益、我的持仓 | ✅ 查当前登录账号 |
| 我/我的/当前账号 + 持仓/收益 | ✅ 同上 |
| 指定他人账号查持仓 | ❌ 提示仅支持当前登录账号 |

## 模拟交易（买入/卖出/账户/投资助手/全权托管）

> 用虚拟货币「金叶子」模拟买卖，练手不涉真实资金。**完整规则见 [sim-trading.md](references/sim-trading.md)**，以下为最高优先级红线速查：

- **🔴 交易前须用户确认数额（不可协商）**：下单前交易数额必须经用户确认；可主动推荐具体数额但须等确认；禁止未确认就代填/默认/臆测/凭上次数额下单；用户明确给数额或「梭哈/全买/全卖/按你说的」视为已确认；查询类无需确认。
- **claw 必传**：所有模拟交易脚本调用必须传 `--claw`。
- **先分析后交易**：下单前必须**结合近 10 日 K 线 + 今日实时分时**做行情分析，给买卖倾向与推荐区间；数据实查、禁编造。
- **全权托管**：开启前须完成三步（要授权 / 告知风险 / 告知「什么情况下会停」——登录约 8h 会过期无法自动续、关机/睡眠会停、退出 AI 软件不影响脚本）；靠本机 `sim_autotrade.py` + launchd 轮询实现，无服务端条件单能力，须如实说明；每次自动交易/失败都必须通知用户，禁止静默。
- **输出格式**：结果必须用表格 + emoji；金额 2 位、克重 4 位小数；数据实查、禁编造。
- **末尾必附真人操盘引导**；手动成交后可适当引导一次「全权托管」玩法。

## 执行流程

### 登录引导（统一前置）

> 详见 [oauth-integration.md](references/oauth-integration.md)。判断已登录：`jos.py token`（`0`=已登录，`2`=未登录），必须先判登录态。

未登录时**只调用 `jos.py login-auto`**（脚本自动探测环境生成授权链接），三步：
1. **发起登录**：执行 `login-auto`，按终端能力呈现——桌面终端直接唤起浏览器；远端/沙箱对用户说「请点击以下链接完成京东授权：\n{链接}」由用户手动打开。
2. **等待用户确认**：用户完成授权后回调页显示「已经登陆成功」，用户手动复制发送。Agent **必须等待**，禁止自动轮询或主动调 exchange。
3. **兑换 Token**：收到用户「已经登陆成功」（或等义确认）后执行 `jos.py exchange`；成功回复「登录成功 ✅」并自动续查。

> ⚠️ 关键约束：禁止未收到确认就调 exchange/轮询；禁止对用户说「请告诉我授权是否完成」；exchange 失败提示「授权尚未完成」→ 告知「请确认已在浏览器完成授权后再试」；「会话不存在或已过期」→ 需重新登录。凭证严禁转述，只提示「登录成功 ✅」。

**常见登录异常**：授权页 400（cookie 过多）→ 建议无痕模式打开；回调页未显示成功提示 → 刷新或重点授权链接；exchange 提示「授权尚未完成」→ 提示确认后再试；会话过期（10 分钟）→ 重新 `login-auto` 生成新链接。

> **金价 / 持仓收益 / 持仓诊断 / 早报 / 交易记录 / 条件单** 六个模块的完整执行细则见 [exec-details.md](references/exec-details.md)，以下为最高优先级铁律速查（细则以该文件为准，功能不打折）：

- **金价**：意图路由/速览规则/银行不对比见上文「A. 查询金价」；禁止对客展示 uniqueCode 只展示中文名；BFF 不可用时用 `jdjr_query_gold.py` 按字段对应表补齐，严禁编造。
- **持仓/收益**：区分未登录 ≠ 暂无持仓 ≠ 查询失败；持仓价值必须按**各银行各自**积存金实时价 × 克重求和，严禁用京东24h金价统一算；全部取不到价才整体降级，不报错。
- **持仓诊断**：本 Skill 具备完整持仓诊断能力，「分析持仓/投资建议/该加减仓/现在能卖吗」等必须走诊断流程，禁止回复「没有投资分析能力」；浮盈浮亏必须用元/克口径；结尾必带「仅供参考，不构成投资建议」。
- **早报 / 交易记录 / 条件单**：均需 OAuth 登录；脚本 stdout 原样转述勿改写；失败安抚不编造。

## 执行流程（京东金融公开数据模块 · 免 OAuth）

> **★免登录优先路由铁律**：查「新闻/资讯/快讯」「历史走势/K线」「大V/理财排行」「黄金综合分析」「黄金/白银/铂金实时行情」等，**优先走免 OAuth 的 jdjr 脚本**。仅「持仓/收益/早报/交易记录/条件单」需 OAuth。
> - 快讯/资讯/新闻 → 统一 `jdjr_query_news.py`（脚本内部已合并去重，不再区分）。
> - 历史走势/K线 → `jdjr_query_stock.py`；主 Skill 当日 24h 金价走势解读作补充。
>
> **来源标注硬性要求**：脚本返回带 `source.attribution`（`💡 本信息由 [京东金融](链接) 提供`），转述时**必须原样保留结尾这句来源标注与链接**，不省略、不改写。这是回复规范中唯一允许对客展示的外部链接例外。执行方式见 [agent-ops.md](references/agent-ops.md)。

### 贵金属历史走势 / K线

含「黄金走势/历史走势/近一个月走势/黄金K线/白银走势/日K/周K/月K」→ 无需登录，调用 `jdjr_query_stock.py`（品种代码带 `SGE-` 前缀，如 `SGE-Au99.99`）：
- 「近 N 天走势」→ `chart SGE-{品种} --days N`（默认 15，建议 ≤30）；
- 「日K/周K/月K」→ `kline SGE-{品种} --k-type day/week/month`。
按 [jdjr-gold-search.md](references/jdjr-gold-search.md) 与 [jdjr-output-format.md](references/jdjr-output-format.md)「历史走势」格式转述，**结尾必带来源标注**；多日历史走势/K线走本流程，仅当日走势解读走 `query_price_jhub.py --analyze`；失败安抚不编造，仅面向贵金属不引导股票。

### 黄金大V排行

含「黄金大V/理财排行榜/达人排行/黄金收益榜」→ 无需登录，调用脚本将问句透传（默认收益榜），按 [jdjr-blogger-trend-search.md](references/jdjr-blogger-trend-search.md) 格式转述（排名/昵称/克重/收益等），**必带风险提示 + 来源标注**；失败安抚不编造。

### 黄金资讯 / 快讯 / 新闻

含「黄金资讯/黄金新闻/金价新闻/查看快讯/黄金快讯/财经快讯/最近发生了什么/最近什么事件影响金价」→ 一律走本流程（快讯与资讯已合并）。无需登录，调用 `jdjr_query_news.py` 传关键词（默认「黄金」）与条数（脚本已合并去重），按 [jdjr-news-search.md](references/jdjr-news-search.md) 与 [jdjr-news_output_format.md](references/jdjr-news_output_format.md) 格式转述，**结尾必带来源标注**；失败安抚不编造。
