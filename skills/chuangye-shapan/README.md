# 创业沙盘（chuangye-shapan）

> 创业点子全链路验证框架 · ToC 方向 · V4.6

## 这是什么

> **砸钱之前，先让证据说话——创业沙盘 48 小时判你的点子该 Go 还是 No-Go。**

当用户只有一个散乱的创业点子时，帮助 TA 从**宏观环境预判 → 用户需求验证 → 假设推演 → 访谈设计 → 证据链分析 → 方案推演**做全链路创业验证，最终输出 Go / No-Go 决策依据。

**核心功能**：
- 🧭 全链路验证：宏观预判 → 用户访谈 → 反假设推演 → 证据链分析 → 方案推演，一条龙跑完
- 🛣️ 三路径适配：新手 48h 出信号卡 / 标准 1-4 周出报告 / 高阶含单位经济模型
- 🛡️ 反自我欺骗：强制反假设 + 对抗性自检，防止被自己的热情带偏
- 📋 灵活验证：做不了真人访谈？桌面证据替代路径，证据照样说话
- 🎯 只给方向不代做：输出 Go/No-Go 与验证路径，执行权在你

适用于 ToC（面向个人消费者）方向的创业想法验证。

## 快速开始

1. 用户描述创业点子（或直接说"帮我验证创业想法"）
2. AI 做 C 端边界对齐 → 2 问分流 → 推荐路径（A 极简 / B 标准 / C 深度）
3. 按路径走完整验证流程，每个阶段结束出现升级检查点（可升级/保持/降级/止损）
4. 输出验证结论 + 进度存档（可跨会话恢复）

## 三路径模式

| 路径 | 定位 | 产出 | 耗时 |
|------|------|------|------|
| 🟢 A 新手极简 | 快速方向扫描 | 方向信号卡 | 48h |
| 🔵 B 标准完整 | 全链路验证 | 完整验证报告 | 1-4周 |
| 🟣 C 高阶深度 | 深度推演 | 深度推演报告 | 3-6周 |

**每步升级检查点**：每个阶段完成可 ①升级（自动补全）②保持 ③降级 ④止损
