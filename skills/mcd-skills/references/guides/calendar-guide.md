# 活动与新品查询（麦麦日历）

本指南介绍麦麦日历（活动与新品）相关工具的使用方式。

> 业务流程以「活动查询」口径编排；错误与重试参见 `references/infra/error-handling.md`；认证与调用方式参见 `references/infra/tool-calling-strategy.md`。

## 日历工具概览

| 工具名称 | 功能描述 | 使用场景 |
|---------|---------|---------|
| campaign-calendar | 查询活动日历 | 查看活动和订阅状态 |
| now-time-info | 获取当前时间 | 需要指定日期查询时 |

## 适用场景

- 用户问"最近有什么活动/本周有什么活动/新品/限时优惠"

## 需要先确认的关键信息（缺参问法）

1. 时间范围：最近/本周/指定日期（用户不说则默认最近）
2. 关注方向：想看优惠力度/新品/指定品类或套餐
3. 是否需要后续动作：仅查询，还是看完要领券或进入点餐

## 标准流程

```
确认时间范围与关注点 → 展示活动/新品清单
→ 用户选择感兴趣的活动 → 展示活动详情/可用券
→（可选）用户确认后引导领券或进入点餐
```

## 关键规则

### 调用顺序

0. 检查 `117797261_login_token` 是否有效；过期则调用 `HuaweiIDTool("mcd-skills", "117797261")` 刷新
1. （按需）`now-time-info` → 获取当前日期，用于构造 specifiedDate
2. `campaign-calendar` → 展示活动列表 + 已订阅内容
3. （可选）引导用户领券或进入点餐

### 图片展示要求

- 活动、优惠券类图片须完整展示，勿截断或改写图片链接
- 可使用 Markdown `![描述](URL)` 或 HTML `<img>` 渲染图片；使用 `<img>` 时须限制 `height="300"`，如：`<img src="URL" alt="" height="300" width="auto">`

面向用户说明时使用自然中文，不暴露工具名称。

## 备注

- 活动查询完成后，若用户未明确后续动作，建议用一句话询问"要不要顺便领券/点餐？"以便继续推进。
- `specifiedDate` 不填时默认返回当月所有活动，适合用户问"最近有什么活动"的场景；用户指定具体日期时传入该参数可缩小范围。
