# 积分查询与商城兑换（麦麦商城）

本指南介绍积分查询与麦麦商城兑换相关工具的使用方式。

> 业务流程以「积分 / 商城兑换」口径编排；错误与重试参见 `references/infra/error-handling.md`；认证与调用方式参见 `references/infra/tool-calling-strategy.md`。

## 商城工具概览

| 工具名称 | 功能描述 | 使用场景 |
|---------|---------|---------|
| query-my-account | 查询积分余额 | 用户问"我有多少积分" |
| mall-points-products | 查询可兑换商品 | 用户问"积分可以兑换什么" |
| mall-product-detail | 查询商品详情 | 用户想了解商品详情 |
| mall-create-order | 创建兑换订单 | 用户确认兑换商品时 |
| mall-order-list | 查询兑换订单列表 | 用户问"我的兑换记录"、"积分商城订单" |
| mall-order-detail | 查询兑换订单详情 | 用户查看某个兑换订单的详细信息 |

## 适用场景

- 用户要查积分/查积分余额/查可用积分
- 用户要用积分兑换商品/积分换券/进入麦麦商城兑换

## 标准流程

```
确认意图（查积分 or 兑换）→（如兑换）查询可兑换商品 →（按需）查询商品详情 → 确认兑换对象/数量 → 展示兑换确认信息 → 用户确认 → 创建兑换订单 → 展示兑换结果 →（可选）引导进入优惠券/点餐
```

## 工具详情

### query-my-account — 查询积分余额

**参数**：无需传参

**前置条件**：用户已登录

---

### mall-points-products — 查询可兑换商品列表

**参数**：无需传参

**前置条件**：用户已登录

**注意**：
- 如果用户提示词中带有"我"、"个人"等主观信息，需要在返回所有商品列表后，根据用户的积分余额给出兑换建议
- 积分不够的商品，提示用户可以点餐攒积分，说明是因为积分不足还不能兑换
- 商品图片须完整展示，可使用 Markdown `![商品名称](完整URL)` 或 HTML `<img>` 渲染；使用 `<img>` 时须限制 `height="300"`，如：`<img src="URL" alt="" height="300" width="auto">`

---

### mall-product-detail — 查询商品详情

**参数**：

详见 scripts/cache/ 下当天的工具缓存文件（inputSchema）

**前置条件**：必须已调用 `mall-points-products`，由用户选择一个商品后获取 spuId

---

### mall-create-order — 创建兑换订单

**参数**：

详见 scripts/cache/ 下当天的工具缓存文件（inputSchema）

**前置条件**：
- 必须调用本工具完成交易，禁止直接生成"下单成功"等结论性文字
- 已知商品 skuId（从商品列表或详情中获取）
- 用户积分充足
- 如果用户需要兑换多个商品，必须分别下单且需要排队，等前一个订单响应成功后再创建下一个订单

**错误处理**：

| 错误码 | 含义 | 用户提示 |
|--------|------|---------|
| 510001 | 积分不足 | 提示用户去点餐攒积分 |
| 5100003 | 库存不足 | 提示用户换个商品下单 |
| 5100011 | 用户触发限购 | 提示用户换个商品下单 |
| 56300002 | 卡券兑换失败 | 提示用户换个商品下单或稍后重试 |

**注意**：code 信息可以不提示给用户，优先提示 message 信息

## 关键规则

### 调用顺序（不可跳步）

0. 检查 `117797261_login_token` 是否有效；过期则调用 `huawei_id_tool("117797261","mcd-skills")` 刷新，仅调用一次，不得重复调用。
1. （查积分）`query-my-account` → 展示积分详情
2. （兑换）`mall-points-products` → 用户选择商品
3. （按需）`mall-product-detail` → 展示商品详情
4. `mall-create-order` → **必须等待用户确认后再下单**
5. （按需）`query-my-account` → 查询兑换后积分余额

---

### mall-order-list — 查询兑换订单列表

**参数**：

```json
{"lastId": 0, "size": 10}
```

- `lastId`：分页游标，首次传 0，后续传上一页最后一条的 ID
- `size`：每页条数，默认 10

**使用场景**：用户问"我的兑换记录"、"积分商城订单"、"之前兑换了什么"

---

### mall-order-detail — 查询兑换订单详情

**参数**：

```json
{"orderId": "订单ID"}
```

**前置条件**：必须已从 `mall-order-list` 获取到 `orderId`

**使用场景**：用户想查看某个兑换订单的具体内容（商品、状态、时间等）

---

## 备注

- 兑换前先展示"兑换确认信息"，避免用户误操作；用户确认后再进入提交/展示结果的步骤。
- 积分商城商品图须完整展示，可使用 Markdown `![描述](完整URL)` 或 HTML `<img>` 渲染；使用 `<img>` 时须限制 `height="300"`；表格中最后一列同样适用。
- 示例中的积分、商品列表与推荐文案为演示结构；**实际数值与可兑列表以 `query-my-account`、`mall-points-products` 等接口返回为准**。
- 兑换成功页中的订单号、优惠券分等**以 `mall-create-order` 及账户查询接口返回为准**。
