# 营养信息查询与热量/蛋白质问答

本指南介绍营养与热量相关查询工具的使用方式。

> 业务流程以「营养查询 / 低热量搭配」口径编排；错误与重试参见 `references/infra/error-handling.md`；认证与调用方式参见 `references/infra/tool-calling-strategy.md`。

## 营养工具概览

| 工具名称 | 功能描述 | 使用场景 |
|---------|---------|---------|
| list-nutrition-foods | 获取营养成分数据 | 咨询热量、搭配套餐 |

## 适用场景

- 用户问"这个多少热量/蛋白质/营养"
- 用户要求"低热量套餐/健康搭配/控制摄入"

## 需要先确认的关键信息（缺参问法）

1. 查询对象：具体单品/套餐名称，或用户想要的搭配目标
2. 约束条件：热量上限、蛋白质偏好、是否有禁忌（如不吃辣/不过敏）
3. 是否需要后续点餐：用户是否希望直接进入点餐链路

## 标准流程

```
确认查询对象与约束 → 展示营养关键指标（热量/蛋白质等）→ 如需搭配给出组合建议
→ 用户确认后（可选）引导进入点餐
```

## 工具详情

### list-nutrition-foods — 获取营养成分数据

**参数**：无需传参

**前置条件**：无

**注意**：
- `data` 字段为字符串类型（非结构化 JSON 对象），需解析后提取营养信息
- 返回的是常见餐品的静态营养数据，非门店实时菜单
- 用户问单品热量时，从数据中匹配对应餐品展示即可
- 用户要求搭配方案时，基于营养数据计算组合总热量，给出多个方案供选择

**错误处理**：

- 查询失败时：提示稍后重试
- 未匹配到餐品时：告知用户该餐品暂无营养数据，建议换一个查询

## 关键规则

### 调用顺序

0. 检查 `117797261_login_token` 是否有效；过期则调用 `HuaweiIDTool("mcd-skills", "117797261")` 刷新
1. `list-nutrition-foods` → 获取全量营养数据
2. 根据用户需求匹配餐品 → 展示营养信息或搭配方案
3. （可选）引导进入点餐

面向用户说明时使用自然中文，不暴露工具名称。

## 备注

- 搭配建议时优先给"可选范围 + 解释一句话理由"，避免信息过载。
- 营养数据为常见餐品的参考值，实际可能因门店和时段略有差异。
