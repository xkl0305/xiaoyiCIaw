# 领券与优惠查询

本指南介绍麦麦省领券与优惠查询相关工具的使用方式。

> 业务流程以「优惠券」口径编排；错误与重试参见 `references/infra/error-handling.md`；认证与调用方式参见 `references/infra/tool-calling-strategy.md`。

## 优惠券工具概览

| 工具名称 | 功能描述 | 使用场景 |
|---------|---------|---------|
| available-coupons | 麦麦省优惠券列表查询 | 用户问"有什么优惠" |
| auto-bind-coupons | 麦麦省一键领取 | 用户说"帮我领券" |
| query-my-coupons | 我的优惠券查询 | 用户问"我有什么券" |

## 适用场景

- 用户问"有没有券/什么券能用/帮我看看能领什么"
- 用户明确要领券："领券/把券都领了/帮我领券"
- 用户查看已有券："我有什么券/我的优惠券/券详情"

## 标准流程

```
麦麦省券列表查询 → 展示清单 → 用户决定是否领取 → 麦麦省一键领券 →（可选）引导进入点餐
```

## 工具详情

### available-coupons — 麦麦省优惠券列表查询

**参数**：无需传参

**前置条件**：无

**注意**：
- 该工具返回的是麦麦省可领取的券列表，不是用户已拥有的券
- 若需查询用户已有的券，使用 `query-my-coupons`
- 若需查询当前门店/订单可用的券，使用 `query-store-coupons`（见点餐域）

---

### auto-bind-coupons — 麦麦省一键领取

**参数**：无需传参（系统自动领取所有当前可领的券）

**前置条件**：无需指定具体优惠券或 couponId，系统自动处理

---

### query-my-coupons — 我的优惠券查询

**参数**：

需要参数 schema 时使用 `bash scripts/discover_tools.sh --json` 实时查询（inputSchema）

**前置条件**：无

**注意**：
- 该接口返回的是用户已拥有的券，不进道、配送方式等下单规则校验，不承诺可用于当前订单
- 若业务目标是"当前门店/当前订单可用的券"，请调用 `query-store-coupons`（见点餐域）

## 关键规则

### 调用顺序

- 查看可领券 → `available-coupons`
- 一键领券 → `auto-bind-coupons`
- 查看已有券 → `query-my-coupons`
- 三个工具之间无强制先后依赖，按用户意图直接调用即可

### 图片展示要求

- 查询优惠券时，图片链接必须完整响应
- 不要截断、修改或省略图片 URL
- 确保 `couponImage` / `bigImage` / `image` 字段的完整 URL 被返回和展示
- 使用完整的图片 URL 进行渲染：Markdown `![优惠券名称](完整图片URL)` 或 HTML `<img>`；使用 `<img>` 时须限制 `height="300"`

面向用户说明时使用自然中文，不暴露工具名称。

## 备注

- `available-coupons` 查的是麦麦省可领的券，`query-my-coupons` 查的是用户卡包里已有的券，两者用途不同。
- `query-my-coupons` 返回的券不保证在当前门店/订单可用；门店可用券请用 `query-store-coupons`（点餐域）。
- 领券后可引导用户进入点餐流程使用优惠券。
