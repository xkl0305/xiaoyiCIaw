# 短篇小说技能

## TL;DR（5 步）

1. **定题型**：用 `references/module-one-prescreen.md` 7 问确认题材
2. **写开局**：第1章首句塞入世界观+冲突+主角；前50字悬念·冲突·情绪·反常识全炸
3. **埋卡点**：前3章给主角立场永久改变的抉择（非事件开端）
4. **逐章写**：每章 1000-1400 字，章末留钩；对话≥30%；中文双引号
5. **跑闸门**：8 个机械闸 + 十维评分（每维≥90）全过才交付

## 6 大框架入口

- 框架1 爆款基因 → `references/premise-frontend-gate.md`
- 框架2 十维评分 → `references/review-scoring.md`
- 框架3 去AI味 → `references/deai.md`
- 框架4 期待感与节奏 → `references/expectation-engine.md` `references/hooks.md` `references/rhythm-climax-plus.md`
- 框架5 人设与逻辑 → `references/character-integrity.md` `references/gh-audit.md`
- 框架6 全自动 → `references/auto-creation.md`

## 4 道检查点闸

| 闸 | 触发 | 动作 |
|----|------|------|
| C1 路径 | 意图未明 | 走 Mode 选择 |
| C2 锚点 | 灵魂锚点空 | 退回采集 |
| C3 决策 | 确认未回 | 暂停等用户 |
| C4 交付 | 文件跑完 | 机械全 0+逐维证据 |

## 4 条 P0 硬线

1. 中文双引号唯一（禁英文/日式/单引号）
2. 第1章首句＝世界观+冲突+主角（三件缺一不可）
3. Phase 0 后全自动推进，不问"是否继续"
4. G 类人物行为合理性安全底线

## 验收铁律

- 8 个机械闸脚本必须全 exit=0
- 十维评分每维≥90
- 命中 P0 毒点（送女/绿帽/历史虚无/政治影射/公职负面/宗教民族敏感）→ 不交付
