# 模块九·短篇创作与成稿质量指引

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### 核心指标速查

| 指标 | 标准 | 说明 |
|------|---------|------|
| **总字数** | 8000-10000字 | 约9000字黏性曲线最佳 |
| **单章字数** | 1000-1400字（目标~1200） | 短篇单章偏短但需装下完整节拍+钩子 |
| **章节数** | 7-10章 | 约7-8章×1200字≈9000字（最佳黏性曲线）；上限10章×1000字=1万（总字硬顶） |
| **开篇节奏** | 前500字抛出核心冲突（导向） | 开篇尽快入戏，环境描写**建议**≤50字、非硬卡；直接进入情节为佳 |
| **第一句话** | 三件事同时完成 | 世界观暗示+冲突建立+主角定位 |
| **黏性卡点位置** | 前3章内（约2.0k-4.2k字） | 不可逆抉择（人物立场永久改变），非事件开端 |
| **章末钩子** | 每章必须有黏性钩子 | 读者耐心极短，断章要狠，留悬念/危机/信息差 |
| **结尾** | 留悬念 | 结尾悬念可提升读者黏性与持续阅读欲 |
| **叙事视角** | 第三人称（限知）为默认；第一人称用于强代入叙事 | 两种视角各擅胜场：第三人称利于多线铺陈与信息控制，第一人称强化主角内心代入 |

### 节奏控制

**短篇标准结构（约9000字为例）：**

| 阶段 | 字数范围 | 功能 | 情绪要求 |
|------|---------|------|---------|
| **开篇冲突** | 0-500字 | 抛出核心冲突，第一句话完成三件事 | 高张力、直击读者 |
| **情绪累积+密集钩子** | 500-3000字 | 推进情节、铺垫人物关系、埋伏笔、章末黏性钩子 | 逐步累积紧张感，钩子不断 |
| **黏性卡点** | 前3章内（约2.0k-4.2k字） | **不可逆抉择**：人物立场永久改变 | 情绪峰值，迫使读者决定黏性 |
| **高潮+结尾** | 卡点后-9000字 | 揭示谜底、解决冲突、章末黏性钩子、结尾留悬念 | 释放紧张感+新悬念钩子 |

> **核心规律**：前500字决定读者是否点开，前3章黏性卡点决定读者是否留下，每章末黏性钩子决定读者是否翻到下一章，结尾悬念决定读者是否持续阅读下一篇。
> **勿套用长篇模板**：网文攻略常说的“黄金开篇两万字/看前三名五万字”是**长篇视角**，短故事只看前500字+首句三件事，切勿照搬长篇结构。

### 质量自评（⭐ Phase 4 交付前强制执行）

> **核心理念**：以专业审阅视角检查成稿，核心问题是：**“这部作品的前500字能留住读者吗？前3章的黏性卡点能让读者决定黏性吗？”**

**执行步骤：**

1. 完成全篇后，用审阅视角检查三个关键位置：
   - **前500字**：是否有强冲突？第一句话是否完成三件事？是否有超过50字的环境描写？
   - **前3章黏性卡点**：是否为不可逆抉择？前文情绪累积是否足够饱满？每章末是否有黏性钩子？
   - **结尾**：是否留悬念？

2. 三句话推荐语测试：
   - 第一句：`这是一篇[视角/题材]的短篇，核心冲突是____`
   - 第二句：`它在____方面区别于同类作品（如黏性卡点设计/人设反转/金手指设定）`
   - 第三句：`预期前3章读者留下率____，读者黏性____`

3. 判断标准：
   - 三句都能写 → ✅ 可通过
   - 写不出第二句 → ⚠️ 差异化不足，检查核心设定是否太常见
   - 写不出第三句 → ❌ 读者定位不清晰，回到爆款基因6问重新确认

4. **诚实评估双轨（⭐⭐ 防虚假乐观·强制执行）**：
   > **问题背景**：AI倾向于给出虚假乐观的质量评估（如连续报85-92%），直到用户逼问才说出真实20-30%。以下机制强制诚实评估。

   必须同时输出两套数字，缺一不可：

   | 估计类型 | 区间 | 依据 |
   |---------|------|------|
   | **乐观估计** | __%-__% | 假设题材契合+开篇完美执行+无同类竞品 |
   | **悲观估计** | __%-__% | 假设题材平淡+开篇有1-2处硬伤+同题材有3+竞品 |

   **强制规则**：
   - 两套数字必须同时输出，**禁止只给乐观估计**
   - 乐观与悲观差距<15%→说明评估不够严谨，须重新分析
   - 须标注“切换依据”：什么条件下悲观估计会切换为乐观估计（如“若前500字冲突密度提升至每50字1个→可从30%切换至50%”）
   - 悲观估计<20%→必须在报告中加粗标注**⚠️ 质量高风险**，并给出至少2个改进方向
   - **禁止在任何场景下只输出一个数字**——单一数字必然偏乐观

   > **核心结论**：短篇的核心是“前500字决定点击、前3章黏性卡点决定留下、每章末黏性钩子决定翻页、结尾悬念决定是否持续阅读”，四者缺一不可。

### 书名 / 简介情绪承诺（情绪承诺引擎·方法论）

> **Phase 4 交付前强制**：把「题材词」改写为「情绪词」，让读者点开前就预定爽 / 甜 / 虐 / 燃。详见 `references/emotion-promise.md`。

- **公式**：书名 / 简介 = 明确情绪词 + 具体场景 + 结果预期。
- **自检**：把“这是一篇XX文”改写成“这能让你感到XX”，通过即合格。
- **三问锁定**：最爽一次是什么 / 最虐瞬间呢 / 读者凭什么留下。
- **对比测试**：同设定生成虐恋 / 爽文 / 喜剧三版书名 + 简介，选最贴核心且市场空位的一版。

> 📎 配合模块九质量自评的「三句话推荐语测试」，先内部评估差异化，再用本小节做门面情绪化。

### 基准配置：短篇/超短篇（zhihu-short）

短篇最匹配的题材配置。以下为短篇基线，其他题材在此基础上做差异调整。

| 配置项 | 值 |
|--------|-----|
| **钩子偏好** | 情绪钩>悬念钩>选择钩 |
| **钩子基线** | strong（短篇每章都必须有强钩子） |
| **爽点密度** | high（2+/章，短篇不容注水） |
| **Combo间隔** | 2章参考1次（短篇节奏极快） |
| **里程碑间隔** | 3章参考1次（短篇的“大事件”需求更密集） |
| **微兑现类型** | 情绪兑现>信息兑现>关系兑现 |
| **微兑现下限** | 2/章（每章至少2次微兑现） |
| **过渡章下限** | 2/章（过渡章也不可降微兑现） |
| **停滞阈值** | **1章**（连续1章无推进即触发预警） |
| **主线最大连续** | 2章（短篇篇幅短，主线比例天然高） |
| **感情线断档** | 3章（短篇感情线不容长期断档） |
| **过渡章上限** | **0章**（短篇不允许连续过渡章） |
| **债务倍率** | 2.0（短篇节奏要求最严格） |
| **偿还窗口** | 1章（节奏债务必须在1章内偿还） |

> **短篇铁律**：以上基线对所有短篇都适用，区别在于不同题材的钩子/爽点/微兑现偏好不同。

### 十维评分题材自适应速查（短篇版）

| 维度 | 基准（zhihu-short） | 宽松方向（悬疑/克苏鲁） | 严格方向（爽文/游戏/直播） |
|:----:|:------------------:|:----------------------:|:------------------------:|
| 1.开局引力 | 前500字出冲突 | 前800字（需少量铺垫） | 前300字 |
| 2.节奏爽点 | 2+/章 | 1/章（信息兑当代替） | 3+/章 |
| 6.黏性转化 | 情绪钩优先 | 悬念钩优先 | 渴望钩/危机钩优先 |
| 过渡章容忍 | 0章 | 最多1章 | 0章 |

> **使用说明**：短篇篇幅决定了所有题材的节奏基准都显著高于长篇。配置表中的值已做短篇化压缩处理。Phase 3评分时，先查题材归属，按配置调整预期——不要把悬疑按爽文的标准评爽点，也不要把电竞按言情标准评感情线。
