# 模块四·Phase 2 逐章写作细则

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### 写前分析与核心设计（6步）

1. 读取大纲 → 查看TODO list和已完成章节摘要
2. 读取上一章摘要和结尾钩子
3. 读取情绪曲线 → 确认本章情绪节奏位置
4. 将本章标记为“进行中”
5. 设计开头钩子 → 前20%必须有即时冲突
6. 规划场景 → 本章3-5个场景

**第1章专属协议（⭐⭐⭐ P0·合并版）：**

第1章写前/写后必须执行以下3项检查（其余协议已合并到核心原则中，不再单独展开）：

- **第一句话三件事**：同时承载世界观暗示+冲突建立+主角定位。缺一→重写。
- **主动决策**：章末主角必须做出自己的选择（不是被动逃跑/被救/被安排）。
- **核心设定暴露时机**：核心差异化卖点在前3段内被读者感知，不超过第3段→重写。

**爽点前置（⭐⭐ 每章必遵）：**

- **写前确认**：明确“本章前40%的爽点是什么？”
- **结构规划**：爽点放在第1或第2场景（前40%以内）。如果爽点天然在后期发生，在前40%植入一个“小爽点”。
- **写后修复**：如果爽点在后60%→立即将爽点相关动作提前，或在前40%插入辅助爽点。

### 撰写与润色（8步）

7. 首章特殊要求：前500字抛核心冲突，不超过50字环境描写；第一句话完成三件事（世界观暗示+冲突建立+主角定位）；核心设定前3段内可感知
8. 短篇章节结构（节奏）：【开篇500字抛冲突】【1k-3k字推进+情绪累积+密集钩子】【前3章内黏性卡点（不可逆抉择）】【卡点后高潮+结尾留悬念+章末黏性钩子】。结尾必须留悬念——“离婚协议签字瞬间，他递来的U盘里，是我失踪五年的孕检报告”。读者耐心极短，章末必须有黏性钩子，断章要狠。
9. 对话规范 → 使用内置规范：口语化、每人有说话习惯、对话占比≥30%；**对话类型区分（⭐ 新增）**：区分信息传递型对话（角色解释设定/背景/规则）与情感冲突型对话（角色立场碰撞/情绪对抗），信息传递型占比≤30%，超出部分须改为“行动中暴露设定”而非角色口述；女性向第一人称优先、男性向第三人称（按视角定视角，不可混用）；**对话灵气与去AI腔（⭐⭐）**：详见 **9.5** 专节与 `references/dialogue-aura.md`（配套机械闸 `scripts/detect_dialogue_ai.py`）。
9.5 **对话灵气与去AI腔句式（⭐⭐ 基于对话四法 + 《透明人审计》实战教训）**：S9 的对话规范只管“占比与类型”，本段补“写法硬约束”——以下六条为 P0 级写法红线，注意与 S10.5「每300字≥1处肢体反应」（那只是扩充手段，非写法硬约束）区分开：
   - **① 动作卡位硬约束（P0级）**：禁止连续≥2句纯「X说：」式标签对话而不夹动作/神态/情境；每3句对话至少1处动作卡位；按情绪选动作替代「说」——愤怒→攥拳/拍桌，轻蔑→咂嘴/撇嘴，从容→转笔/理绳。
   - **② 去AI腔对话红线**：连续>3次「说/道」须换引导动词（嘀咕/冷笑/反问/喃喃…）；禁止剧本体问答（A：“”B：“”连续无动作间隔）。
   - **③ 神态神韵+情境穿插**：用眼神/微表情（瞪/眯眼/撇嘴）与环境音（鞋跟敲瓷砖/笔尖划纸/表针咔咔）替代「说」，既打断问答剧本体又传递情绪。
   - **④ 语感辨识**：角色专属语言风格/口头禅（如老王「透明人」梗、杜伟「有人管就好」复读），不用标签也能分辨说话人。
   - **⑤ 语境适配（关键）**：回忆/概述段禁用即时对话标签（「点头说记下了」→「记在了心里」）；实时场景可用动作承接（动作。+引号）。
   - **⑥ 对话动作密度检测（配套 verify）**：`scripts/detect_dialogue_ai.py` 统计连续「X说：“”X：」纯标签计数与无动作间隔，与已有的「对话归属(夺句，写作/审阅时逐句核对说话人归属)」及 `detect_ai_flavor.py`（引号合规）互补，形成「冒号合规+夺句+动作密度」三位一体对话质检。

10. 内容不足？使用内置扩充手段：肢体反应/心理描写/场景细节/有意义对话
   ⚠️ **段落分隔符硬线（P0级·同“扩充步骤”）**：扩充插入的每段内容必须用 `\n\n`（双换行）分隔，禁止单 `\n`；单换行会在 DOCX 生成时 `split('\n\n')` 把多段误合并为一段（对齐下方“扩充步骤”第1行硬线）。
10.5 **对话占比不足定向改写清单（⭐ 新增·S10.5）**：当对话占比<30%（按对话字符数/总字符数计算含标点）时，按以下步骤逐个段落定位+替换——
   ① **定位长叙述段**：扫描每段>150字且无对话的段落，标记为“高密度低信息段”
   ② **拆分规则**：将1段长叙述拆为“对话+动作+少量叙述”结构，目标是将叙述转为角色互动
   ③ **动作插入**：在情绪转折点插入肢体反应（攥拳/低头/眨眼/移开视线），每300字≥1处
   ④ **对话注入**：在冲突段落末尾补1条短对话，即使原稿无对话（“你怎么了？”“没事”→够了，至少2句）
   ⑤ **信息拆分**：如果一段长叙述在“解释设定/背景”，拆成角色间争�式对话��“你以为呢？”↔“你根本不懂！”
   ⑥ **重检字数**：改写后若>1400字→从非关键段落同量压缩；若<1000字→回到扩充步骤
   ⑦ **重检AI味**：改写后过 detect_ai_flavor.py 确认 exit=0
   ⑧ **最终确认**：对话占比≥30%且≤70%（过高变剧本），信息传递型对话≤30%
11. 设置结尾钩子 → 使用内置5种钩子：悬念/危机/信息差/情感/行动
12. 初稿字数粗检 → 确保1000-1400字附近（目标~1200）

### 撰写后优化（6步·精简版）

13. **引号专项校验（⭐⭐⭐ P0）**：逐字符扫描全章，确认所有引号均为中文双引号`“”`（U+201C/U+201D）。违规引号必须全部替换
14. 连贯性检查 → 执行内置检查：时间线5章无矛盾+人设不跳变+信息源符合身份
15. **深度润色（去AI味）**：L1-L2检测 + 去除过度修饰 + 口语化 + 节奏感优化
16. **字数检查** → 确保1000-1400字（目标~1200，可用脚本：`scripts/check_chapter_wordcount.py`）
17. **写入后交叉校验（非十维评分）** → 使用7维度模板做格式/节奏/对话/钩子/字数完整性校验：情绪/节奏/人设/对话/AI味/钩子/字数。⚠️ **本步骤仅校验基础完整性，不代表叙事质量已达十维审阅标准。十维审阅（引用文本证据+逐维打分+迭代优化至每维度≥90）是Phase 3独立流程，不可省略、不可替代。**
18. 情绪连续性校验 → 章首承诺→章末兑现是否匹配（核心原则#1）

### 收尾（4步）

19. 生成章节摘要 → 添加100-200字到大纲
20. 更新TODO → 将本章标记为“完成”
21. 写入优化效能日志 → 记录本轮优化手段与提分效果（模块七 7.1）
22. 更新 experience_log.md → 记录本轮迭代的关键发现

### 逐章字数控制

**压缩步骤（>1400字时）：**
1. 识别超过150字且无对话的纯叙述段落
2. 去掉重复修饰词、合并短句、削减非功能性景物描写
3. 每段压缩50-100字（或当前段落字数的20%，取较小值）
4. 重检对话占比（不得低于35%，按对话字符数/总字符数计算含标点）
5. 压缩后重检AI味词密度（确保压缩未引入新的AI味表达）
6. **精确公式**：若总字数N>1400，压缩目标= N-1200；每段压缩量= min(80, 段落字数×20%)
7. **章末断章刀保护**：压缩时不得破坏最后50字的悬念效果

**扩充步骤（<1000字时）：**  ⚠️ **段落分隔符硬线（P0级）**：所有扩写内容必须用 `\n\n`（双换行）分隔段落，禁止单 `\n`；单换行会在 DOCX 生成时 `split('\n\n')` 把多段误合并为一段。
1. 识别信息密度过低的段落（单段>200字且无对话为高密度低信息段落）
2. 增加人物肢体/心理反应、补充场景细节、插入有意义的对话
3. 每段扩充50-100字（或目标缺口字数的50%，取较小值）
4. 扩充后重检字数（确保不超过1400字）
5. 扩充后重检对话占比和AI味词密度
6. **精确公式**：若总字数N<1000，扩充目标= 1200-N；每段扩充量= min(80, (1200-N)/低密度段落数)
7. **前200字保护**：扩充首段时不得稀释前200字内的冲突密度

### 字数均衡子流程（⭐ 合规模式默认触发 + 用户可显式要求）

> **修订原则**：默认“合规模式”仅保证每章 1000-1400，不强制向均值收敛（标准节奏下的章节方差本就合理，无意义拉平会伤害节奏）。
> **自动触发条件（⭐ 新增·修复“全自动流程永不执行”断点）**：Phase 2 每组写完后**自动计算本组字数极差** `(max-min)/mean`；若 **>13%**（即明显失衡，如原稿 1312–2160 跨度 65% 情形）则自动执行本子流程压缩方差；正常节奏（极差≤13%）不干预，避免拉平合理节奏。用户也可在任意阶段显式要求“均衡”强制触发。

① 计算 target = clamp(round(均值), 1000, 1400)
② 方差阈值：各章落入 [target-130, target+130]（跨度≤13%）即停
③ 优先在章尾/情感高点插入（躲开头尾锚点冲突）
④ 插入前：`anchor` 在目标章内 `t.count(anchor) == 1`（唯一性快速验证；规则详见边界条件「6项基础规范自动检查」第③项）；高动作重复场景优先章尾或情感高点插入
⑤ 插入后立即运行 `detect_repetition.py`，0 重复才通过
⑥ 插入后段落必须用 `\n\n` 双换行分隔（见章末钩子/扩充步骤段落硬线）
⑦ 校验黏性卡点累计字数不变（卡点位置不被插入推动）

### 章末钩子添加步骤

> ⚠️ **段落分隔符硬线（同扩充步骤·P0级）**：插入钩子内容若含多段，必须用 `\n\n`（双换行）分隔，禁止单 `\n`；单换行会在 DOCX 生成时 `split('\n\n')` 把多段误合并为一段。

1. 使用内置钩子技巧（5种类型）
2. 根据题材选择最合适的钩子类型（悬念/危机/信息差/情感/行动）
3. 在章末插入钩子
4. 检查字数是否超标（1400字上限），超标则从其他段落同量压缩

> **核心原则（⭐⭐⭐ P0硬线）**：只有 **Phase 0 确认清单** 是唯一需要用户确认的检查点。Phase 1-4 中的所有“确认”动作均为**AI内部自检**。**擅自停下来询问用户“是否继续”=违反P0硬线，不可发生。**
