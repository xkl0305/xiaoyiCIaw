# 模块三·补·去水感/文学质感/思考路径三层硬线

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### 一、去水感 / 快慢分配（接第2维 节奏爽点 硬扣分项）

**核心规则**：短篇篇幅紧，任何“无情节/无情绪推进”的铺陈段都视为水段，必须砍或重写。
- **水段判定**：单段连续 >200 字且无①新事件 ②新情绪 ③新信息 任一推进 → 水段。
- **快慢分配**：高潮/冲突段须与过渡段有可感知的节奏差（高潮用短句密节奏、过渡用长句疏节奏）；全文若节奏恒定无起伏 → 快慢失衡。
  - ⚠️ **澄清（防误执行）**：“高潮用短句”指句子写短、分段写密，**不是场景时间写短**。高潮处句子要短，但场景时间必须用五感拉长（慢镜头）；该删的是铺垫过程，不是高潮本身。详见 `references/rhythm-climax-plus.md` 第三节。
- **机械闸**：`scripts/detect_water.py` 对每段统计字数+动作/事件动词密度+对话引号密度，水段候选≥3 → exit=1 阻断（并入验收铁律机械闸）。
- **扣分（已并入第2维）**：段落拖沓/水段(单段>200字无推进 -15/段)；快慢分配失衡(高潮与过渡无节奏差 -10)。

### 二、文学质感（接第8维 文笔质感 硬扣分项·审阅级门槛）

**核心升级**：第8维从“抗AI味”扩展为“文笔质感(抗AI味+文学表现力)”，门槛从“有手法”提到“审阅级动人”。
L3四法（白描/句式变奏/叙事温度/场景可视化）仅作**入场券**（无则-10/项，维持原L3→第8维逻辑）；本层追加**质量扣分项**（有手法但平淡仍扣分）：

| 扣分项 | 分值 | 判定 |
|--------|------|------|
| 缺乏感染力 | -15~25 | 重要情绪段读毕无“心头一紧/鼻酸/后背发凉”等生理共鸣信号 |
| 重要情节力度不够深 | -15~25 | 关键转折/高潮写得轻飘，无重量感（可用“是否想再读一遍这句”反向验证） |
| 复杂情感不够细腻 | -15~25 | 矛盾/纠结只用“他很X”直述，无思维碎片/生理通感/具象物承载 |
| 感官叠加套路化 | -10 | “掌心是凉的”类陈词式叠加，非不可替换的具体物 |
| 展示而非讲述不足 | -10 | 抽象陈述段连续>3段无具象动作/物件承载 |

> **关键区别**：旧规只在“完全没有该手法”时扣分；新规在“手法有了但平淡无感染力”时同样扣分。审阅拒的恰恰是后者。

### 三、思考路径层 L4（接去AI味·自下而上归纳）

> **核心理念**：去AI味不能只洗词汇句式（L0-L3），必须重构思考路径。AI腔本质是“自上而下演绎式”——先定结论再填充论据、结构严整无思考痕迹；人类写作是“自下而上归纳式”——从具体现场细节提炼，含个人化偏见与不可替换的细节。

**L4 执行规则（写作时即应用，Phase 3 第8维审核）**：
1. **禁止结论先行填充**：不得先写“他明白了XX”再补“因为…（三点论据）”。必须从现场具体细节（动作/物件/气味/声音）自然推出认知。
2. **细节私有化到不可替换**：每个关键感官细节须是“换一篇就立不住”的具体物（如“第七层禁制是入职第一天刻的，边缘有她咬过的牙印”），禁用通用模板细节（“掌心是凉的”“夜色很沉”）。
3. **个人化偏见/观点**：允许并鼓励带主角主观滤镜的具体判断（“这茶难喝，但比住院部的那种暖壶水强”），禁中立客观报告腔。
4. **检测**：结论先行由 Phase 3 第8维审核时识别（“他明白/她意识到/这一刻”后接抽象总结句→标记扣分）；后续可扩展 `detect_ai_flavor.py` 启发式。

### 四、私有经验生命表达（破同质化·接 Phase 0）

> **问题**：零确认全自动 + 统一工艺模板 → 11篇同质化、审阅理由字字相同。
> **修复**：Phase 0 六问之外，强制采集一个“私有经验灵魂锚点”——作者本人/主角独有的、不可被模板生成的真实生命经验或独特细节，作为全文质感底座。

**Phase 0 新增第7问（灵魂锚点）**：“给一个你/主角私有的、具体的生命经验或独特细节（一件旧物/一句口头禅/一种身体记忆/一段真实窘迫），它将作为本文不可复制的灵魂底座。”

**工艺变体（破模板同质）**：写作时从以下变体中随机择一打破固定4321分配——
- 开篇变体：非主角视角切入 / 倒叙钩子 / 物件特写开篇
- 节奏变体：允许单章内“慢铺+急转”反差，而非固定每3章小高潮
- 语感变体：依题材注入不同口语底色（市井/书卷/江湖），非统一“活人感”词表

### 五、双检关卡（接验收铁律·保留零确认）

Phase 3 终审在原有机械闸 + 十维≥90 之外，新增自动化双检（不中断询问，符合P0零确认）：
- **机械半检**：`detect_water.py` exit=0（去水感，无水段超标）——已并入验收铁律条件①机械闸。
- **文学半检**：第8维 文笔质感不低于90 且含“感染力/力度/细腻”三项真实文本证据各至少1处——已并入验收铁律条件④。
- 任一不过 → 自动进入对应维度迭代（不询问用户），直至通过。
