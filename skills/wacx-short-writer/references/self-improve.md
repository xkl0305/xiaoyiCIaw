# 模块七·自我改进代理

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### 7.1 效能追踪（Optimization Efficiency Log）

**文件**：`optimization_efficiency.log`，格式：`[轮次] 手段 → 上轮提分 | 状态(优先复用≥5/有效3-5/低效<3/停用≤0)`

**追踪规则**：
- Phase 2每组完成后，记录该组打分卡变化值和使用的优化手段
- Phase 3每轮迭代后，记录该轮各维度的提分/扣分
- 每次迭代只记录实际执行的手段及其效果，不记录未使用的手段

### 7.2 策略自适应

**自适应规则**：迭代前读取log→按提分分级执行（≥5优先复用 / 3-5保留 / <3减少 / ≤0停用）。连续2轮同一手段提分递减→标记“边际效应递减”→寻替代方案。零效手段→立即替换新策略。

### 7.3 经验日志（Learning Log）

**文件**：`experience_log.md`（每次作品完成后更新）。字段：总迭代轮数/最终最弱维度/最终总分/最佳&最差优化手段(含累计提分)/关键发现/待改进项。

### 7.4 周期复盘（Periodic Review）

**触发**：完成作品/幕/完整审阅迭代。**复盘**：统计最佳/最差手段→识别顽固问题→更新策略库优先级→输出lessons-learned.md
