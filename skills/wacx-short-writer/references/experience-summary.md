## 模块八：经验总结

**触发时机：** 完成完整短篇/完成一轮审阅→修改→再审阅/用户主动触发

**七大总结维度：**
1. 前端指标（前500字捕获力/第一句话三件事完成度/核心设定暴露时机/黏性卡点类型）
2. 字数控制（达标率/偏差模式/经验教训）
3. 钩子/断章刀效果（使用频率/最强句式/章末黏性钩子密度）
4. AI味问题（命中数/最高频词/最有效替换）
5. 节奏问题（起承爆惊执行率/爽点密度/前3章高潮分布）
6. 角色表现（对话占比/辨识度/记忆标签/第1章主动决策）
7. 评分变化趋势（初评→终评/提升最大维度/短板）

**报告格式：** Keep/Improve/Try + 优化策略优先级调整 + 下一部注意事项 + 效能日志摘要

**经验总结触发时，额外输出「实操避坑清单」（⭐ 新增·基于不达标经验提炼）：**

| 坑 | 教训 | 预防方案 |
|---|------|---------|
| 字数统计偏差 | AI自报字数偏差可达500字/章 | 用len/wc-m硬校验，不采信AI自报 |
| 文件链式损坏 | 多次find-and-replace导致不可逆损坏 | 审阅前备份，复杂替换用Python脚本 |
| 十维漏检 | 人工审阅漏掉Ch1-Ch2时间线重叠 | 每次大版本迭代后必须跑完整十维评分 |
| 题材匹配误判 | 以为改内容能解决一切，忽视平台特性 | 选题阶段先做平台匹配度评估，低匹配度→换平台 |
| 黏性卡点 | 以“事件开端”而非“不可逆抉择”作为黏性点 | 黏性卡点必须是人物基于价值观的不可逆决定 |
| 文字重复 | 同一比喻/描写跨章出现，或扩写复述原文造成重复 | 运行 `scripts/detect_repetition.py` 两遍捕获（默认 min-len=8 实质重复 + `--min-len 4` 兜底短句碎片如 ch01 7字遗留句；跨章警告+--fuzzy 近重复）；插入前 `t.count(anchor)==1` 验证锚点唯一性 |
| 自报字数不匹配 | 旁白“三个字”指“退婚”（实际4字），改台词后漏同步计数 | 运行 `scripts/detect_wordcount_claim.py` 机械闸门校验；写作时避免自报引用文本字数 |

### 不达标反馈→解法映射表（⭐ 跨项目复用）

> **核心理念**：每次遇到审阅反馈时重新推导解法是低效的。本映射表将实际不达标反馈与已验证解法一一对应，下次同类反馈可直接查表调用，无需重复推导。

| 审阅反馈 | 解法 | 实操示例 |
|----------|------|---------|
| **文笔有待提高** | 感官叠加法 | 不写“他很难过”，写“指甲里还有朱砂，掌心是凉的” |
| **整体缺乏吸引力** | 矛盾前置法 | 前50字直接抛出核心冲突——“离婚协议摆在桌上，她签了字，才发现丈夫的名字不是他的” |
| **切入点缺乏吸引力** | 配角视角切入法 | 从配角视角引入主角，打破“主角第一句出场”定式——“新来的实习生第一次见林总监时，她正在会议室里撕合同” |
| **矛盾有些欠缺** | 生理通感法 | 不写“她犹豫了”，写“笔悬在签名栏上方，空调嗡嗡响，手指关节发白” |
| **情感不够细腻** | 抽象具体法+思维碎片法 | 把抽象情绪转化为具体意象——“像握着一封写了很久的信”；崩溃时写反常冷静——“她想的是这双鞋该换了，鞋底已经磨穿一个洞” |

> **使用方式**：收到审阅反馈后，先匹配反馈类型→查表找对应解法→应用到修改中。若反馈类型不在表中，完成修改后在映射表补充新行，形成持续积累的。

> **交叉引用**：黏性卡点→核心原则#3；第一句话三件事→核心原则#0.5；活人感终审→模块三L2（Phase 3第3轮重点）；自适应迭代→模块七；效能追踪→模块七7.1；作品复盘→模块七7.4。其余功能均已内联至对应模块，按模块标题导航即可。
