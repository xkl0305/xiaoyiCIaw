# 模块二·审阅评分体系（十大维度/自查/打分卡/边界）

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### 十大维度评分（满分1000——含扣分项）

> 本技能为通用短篇创作与成稿质量评估，评分细则基于短篇叙事质量基准（核心指标：前3章读者留下率/读完整度/读者黏性）。
> **📌 题材感知**：以下评分规则为通用基准。实际十维评分时，须参照**模块九点五·题材感知配置**按题材调整预期——例如悬疑类的信息兑现权重高于爽点密度，甜宠类的人设/代入感维度权重更高。短篇篇幅决定了所有题材的节奏基准比长篇更紧凑（停滞阈值≤2章，过渡章容忍≤1章）。

| 维度(满分) | 核心考察 | 对标指标 | 扣分项(分值) |
|:----------|---------|---------|:------------|
| 1. 开局引力(100) | 前500字冲突密度、第一句话三件事、核心设定前3段内暴露；开篇500字不出现超过50字环境描写；**前500字禁止角色简介式信息倾销（连续3句话以上纯背景介绍无情节推进）**；**前500字情感锚点检测（情感词数≥技术词数）** | 开篇吸引力、首章读者留下率 | 第一句话缺三件事(-25)；前50字无冲突(-15)；前500字信息密度过低(-15)；章首承诺与章末回报不匹配(-20)；前500字出现角色简介式信息倾销(-15)；**前500字情感词<技术词(-15)**（技术词如“视网膜/协议/数据/系统/终端”，情感词如“害怕/愤怒/心疼/不甘/慌”——技术词占比过高=读者无情感抓手） |
| 2. 节奏爽点(100) | 钩子率、爽点密度(黏性卡点前≥1强情绪释放)、卡点前情绪累积质量、章末黏性钩子密度、快慢分配(高潮密节奏/过渡疏节奏) | 读完整度、读者黏性 | 连续2章无爽点(-25)；爽点出现在章后60%(-10)；章末无黏性钩子(-15)；段落拖沓/水段(单段>200字无情节·情绪推进 -15/段)；快慢分配失衡(高潮与过渡无节奏差 -10) |
- **题材自适应**：爽文/都市异能→要求higher密度（黏性卡点前≥2强释放）；悬疑/克苏鲁→可接受卡点前≥1信息兑现（降低纯爽点要求）
| 3. 人设吸引力(100) | 主角动机+反差点、配角记忆标签；**第1章末主角主动决策** | 读完整度 | **第1章末无主动决策(-30)**；非第1章主角无主动决策(-20) |
| 4. 情绪曲线(100) | 压抑释放比、卡点前情绪铺垫密度；章首承诺→章末回报 | 读完整度 | 章首承诺→章末回报断裂(-20) |
| 5. 信息密度(100) | 废章率、冲突段落占比、**对话类型分布** | 阅读时长 | 对话占比<30%或每300字<1条新信息(-15)；**信息传递型对话占比>30%(-15)**（信息传递型=角色解释设定/背景/规则；情感冲突型=角色立场碰撞/情绪对抗。信息传递型占比>30%说明对话沦为“设定解说”，须改为在行动中暴露设定） |
| 6. 黏性转化(100) | 黏性卡点类型(**必须为不可逆抉择**)、卡点位置(前3章内/约2.0k-4.2k字)、卡点前情绪累积、章末黏性钩子强度 | 前3章读者留下率、读者黏性 | 卡点为“事件开端”而非不可逆抉择(-20)；章末钩子不完整(-15)；前3章无强黏性事件(-15) |
- **题材自适应**：钩子类型按题材偏好调整——爽文/游戏文→渴望钩/危机钩优先；言情/替身文→情绪钩优先；悬疑/规则怪谈→悬念钩优先（详见模块九点五各题材hook_config）
| 7. 题材适配(100) | 标签匹配、情绪母题明确、题材匹配度 | 综合表现 | 题材非主流(-15)；情绪母题不明确(-10) |
| 8. 文笔质感(抗AI味+文学表现力)(100) | AI词占比、细节私有化、语言自然度；引号类型——仅允许中文双引号U+201C/U+201D；**文学表现力**：感染力/重要情节力度/复杂情感细腻度/感官叠加非套路化/展示而非讲述 | 读者阅读体验率 | 禁用词命中(-10/处)；破折号（全篇>5处时每超1处-5，封顶至0，与L0≤5处一致）；引号违规(-10/处，含中文单引号U+2018/U+2019)；**缺乏感染力(-15~25)**；**重要情节力度不够深(-15~25)**；**复杂情感不够细腻(-15~25)**；**感官叠加套路化(-10)**；**展示而非讲述不足(-10)**；冒号按L0处理（对话引导用“他说/她道”不带冒号，说明性冒号不单列硬扣） | （各标点国标正确用法详见模块三·附「标点符号用法速查（GB/T 15834-2011）」） |
| 9. 逻辑合理性(100) | **G类+P0最高**：感官/认知/信息/体力极限；G+心理动机/因果链/社会情理；时间线/H类 | 读完整度 | G类越界(-25)；H类跨章矛盾(-15/处)；G+心理动机断裂(-20)；社会情理违背(-15) |
| **10. 代入感(100)** | **读者是否在乎主角的命运**：主角内心揭示度、情感共鸣触发点、读者在乎五问 | 读完整度、读者黏性 | 全篇<3个情感触发点(-20)；内心揭示空白章节(-15/章)；旁观者视角段落(-10段)；第1章未建立“在乎主角”(-25) |

**评分规则：**
- 从满分扣分，分三级：🔴严重(15-25分)、🟡中度(5-14分)、🟢轻微(1-4分)
- **每个扣分必须引用具体文本证据**，不可凭感觉扣分
- 每个维度至少引用1处文本证据，否则该维度评分无效
- 总分 = 十大维度得分之和（满分1000），但等级判定以**每维度最低分**为准——合格/优秀线不看总分，看最弱维度
- 评审报告输出格式：**自然语言审阅口吻，非机械清单**。每维一行“维度: 得分/100（扣分: 具体文本位置→问题→修改建议）”。避免“模板腔”——不要每维都以“该维度考察的是…”开头，直接点明问题+证据+建议。
- **整体评价**必须包含：总得分、最弱维度、一句话总结（<30字）、**1条最高优先级的修改建议**（具体到“删哪句话/添什么内容”）
- 评审报告输出：得分+扣分理由+文本证据+修改建议

**三套评分体系仲裁规则（优先级从高到低）：**
1. **十大维度1000分**（最终裁决标准）：Phase 3终审唯一依据。若十大维度每维度≥90且无双硬线断裂，则视为达标
2. **打分卡100分制**（Phase 2过程指标）：每组完成后用打分卡初筛，算法核弹<18或商业性<15时立即返工
3. **5维自检**（最低优先级）：仅作为Phase 2的初步筛选，不达标时先做针对性修正后再用打分卡复评
- **冲突处理**：当5维自检合格但打分卡不合格时，以打分卡为准返工；当打分卡合格但十大维度存在维度<90时，以十大维度为准进入下一轮迭代

**等级划分（每维度合格/优秀制）：**
| 每维度最低分 | 等级 | 行动 |
|:----------:|:----:|------|
| 每维度≥95 | 🏆 现象级爆款 | 可直接交付 |
| 每维度≥90 | ✅ 精品佳作 | 可交付，建议继续优化 |
| 每维度≥85 | 优质作品 | 必须修改，重点修P0项 |
| 每维度≥80（<90） | 未达交付线 | 须续优至≥90 方可交付 |
| 每维度≥70 | 合格 | 必须修改，重点修P0项 |
| 每维度≥60 | 较薄弱 | 大幅修改后复评 |
| 存在维度<60 | ⛔ 风险区 | 不可交付 |

> **扣分项已整合到十大维度评分表中**（每维度列明扣分项及分值）。评审时直接引用表中扣分项，不再单独查询明细表。

> ### 验收铁律（交付判据 · 分级制 ⭐⭐⭐）
> **铁律**：机械闸门为两档共同硬基线（须实际运行脚本，非自查），任一项 exit≠0 即不交付。
> **🟢 达标线（默认交付）— 四者同时成立：**
> 1. **机械闸门全 exit=0**：`check_chapter_wordcount.py`(单章1000-1400+总8k-10k) + `detect_repetition.py`三遍(min-len=8/4/fuzzy0.8) + `detect_ai_flavor.py`(破折号≤5/禁用词0/引号合规) + `detect_hallucination.py`(提供锚点exit0；无锚点→exit=2降级LLM自评不阻塞) + `detect_wordcount_claim.py`(自报字数一致) + `detect_water.py`(去水感·水段≤阈值) + `detect_hook.py`(开篇避雷针)
> 2. **十维评分每维≥90 + 每维有真实文本证据**
> 3. **视角选择（按视角）**：男性向第三人称/女性向第一人称优先
> 4. **第8维文笔质感≥90** 且含“感染力/力度/细腻”三项真实文本证据；缺任一→自动进入第8维迭代（符合P0零确认）
> **🏆 卓越线（高标准 · 95+）**：在达标线基础上，十维每维≥95 且第8维≥95 三项证据齐全。
> **任何“已达标”声明若未附退出码+逐维证据，一律无效。**

> ### 反幻觉机制（两层定义 ⭐⭐）
> 小说写作技能的“幻觉”分两层，必须分别用机械方式封堵，缺一不可：
> - **叙事层幻觉**：生成内容违背自己 established 的事实锚点（如前文锁定取证设备=录音笔，后文却写成“袖口藏着两部手机”；男性向被写成第一人称）。封堵 = Phase 1 锁定 `fact_anchor.json` + Phase 4 前跑 `detect_hallucination.py`（硬冲突 exit=1 阻断）。
> - **元层幻觉**：技能/报告声称达标但通过无工具证据（子代理自报成功、凭空报分）。封堵 = 上方「验收铁律」：达标唯一判据 = 机械退出码 + 逐维真实文本证据，禁子代理自报。
> 两条规则互为补充：元层铁律确保“过的真过了”，叙事层闸确保“写的不自相矛盾”。

### 迭代后自查清单（6项高频问题——详见边界条件表“6项基础规范自动检查”，此处仅作速查）

> **说明**：6项检查的完整标准和失败处理已整合到边界条件表（“6项基础规范自动检查”行），本清单仅列检查项名称，以消除两处定义的冗余。执行时按边界条件表的标准操作。

| □ | 检查项 |
|---|--------|
| □ | 破折号计数（全篇≤5处）|
| □ | Ch1-Ch2时间线重叠（不可写同一时间段同一事件）|
| □ | 文字重复（同一比喻/描写不得跨章重复）|
| □ | G类越界（主角限知视角不得描写其不可能知道的信息）|
| □ | 第一句话三件事（世界观+冲突+主角定位同时完成）|
| □ | 视角选择（男性向须第三人称叙述/叙事“我”=0；女性向第一人称优先）|
| □ | 事实锚点一致性（detect_hallucination.py 传入 fact_anchor.json，硬冲突=0）|
| □ | 自报字数一致性（detect_wordcount_claim.py 检查旁白“X个字”与实际引文字数是否匹配）|

### 短篇打分卡（100分制，双硬线）

| 维度 | 满分 | 核心要求 |
|:----|:----:|----------|
| 算法核弹——读者留下率与爽感 | 30 | 第一句话三件事(10)、前500字信息密度(5)、前3章高潮密度(5)、断章刀(5)、黏性卡点类型=不可逆抉择(5) |
| 商业性——情绪与黏性 | 25 | 情绪母题(8)、标题焦虑放大器(8)、黏性情绪核爆(9) |
| 逻辑与连贯性 | 20 | 金手指(6)、人设标签化(6)、无坑闭环(8) |
| 文本与情绪 | 25 | 即时蜕变(8)、AI味零容忍(10)、代入感(7) |

**双硬线校验（严格执行）：**
- 算法核弹 ≥ 18分 + 商业性 ≥ 15分（任一不达标→直接不合格）
- 总分 ≥ 85分→合格

### 边界条件

| 异常场景 | 处理动作 |
|----------|---------|
| 单章过短(<1000字) | 标记「章节不完整」，跳过十大维度评分，仅做AI味扫描（含破折号/禁用词/引号机械检测 detect_ai_flavor.py） |
| 连续3章字数超标 | 暂停，调整后续章节节奏 |
| 用户中断 | 保存进度，等待指示 |
| 参考文件缺失 | **全部已内联**：references 目录不再需要，所有 fallback 逻辑已整合至 SKILL.md 对应步骤中。执行时直接读取自身文件即可。 |
| Token超限 | 截断最旧章节上下文，保留最近5章+大纲 |
| 上下文窗口溢出 | 分段处理：每次只审阅3-5章 |
| 中断恢复 | 每5章自动保存进度快照（文件：`progress_snapshot_ch{N}.md`，内容：JSON格式的章节摘要+打分卡结果+待修复P0/P1清单），支持从快照重入（从快照下一章继续，不重复审阅） |
| 文件可用性降级 | 所有 references 已内联，不再检查外部文件；若 `scripts/check_chapter_wordcount.py` 不存在：手工估算字数，偏差容忍±50字 |
| **file 工具不可用回退（⭐ 新增）** | 若 `file_read`/`file_write` 报错“path is empty”等：统一改用 `shell+python` 内联脚本完成读/写操作，功能等价。示例：`python -c “import pathlib; print(pathlib.Path('file.txt').read_text())”` 代替 file_read；`python -c “pathlib.Path('file.txt').write_text(content)”` 代替 file_write。 |
| **字数强制校验（⭐ 新增）** | **AI自报字数不可信**（实测偏差可达500字/章）。强制校验规则：(1)写完每章后，先用`len(text.strip())`或`wc -m`对原始文本计数；(2)若AI估算与实际计数偏差>5%（约90字）→标记「字数不通过」，不允许进入下一章；(3)偏差来源通常是“AI少计了标点”，以实际字符数为准 |
| **6项基础规范自动检查（⭐ 新增·含自报字数）** | 每章写完后，按以下6项逐一扫描，全部通过才算本章完成：①破折号计数（全篇≤5处，超标即扣分）②Ch1-Ch2时间线重叠检测（两章不可写同一时间段的同一事件）③文字重复检测 → 运行 `scripts/detect_repetition.py` **三遍扫描**所有扩写/润色后文本：第一遍默认 `min-len=8` 捕获实质重复句；第二遍 `--min-len 4` 兜底捕获短句遗留/碎片复制（如 ch01 7字遗留句 `我盯着碗里的虾。`）；**第三遍 `--fuzzy 0.8` 捕获改写式近义复述（不同措辞讲同一事件/同一反思，成稿审阅不达标高频点）**；发现重复句（≥2次相同）或近义复述（fuzzy≥0.8）→阻断本章，定位去重后再放行；跨章节相同句警告同步处理；脚本缺失则人工逐句比对（按 。！？ 切句、去标点、长度>8 标记重复，不推荐）【锚点规则·插入前】`anchor` 在目标章内 `t.count(anchor)==1`（唯一性快速验证）；高动作重复场景（杯沿摩挲/轻划类）优先章尾或情感高点插入【插入后】跑 `detect_repetition.py --fuzzy 0.8` 覆盖“后续相似句式”近重复④G类越界检测（主角限知视角是否描写了不可能知道的信息）⑤第一句话三件事检测（第一章：冲突引入+世界观暗示+主角定位三件事是否齐全）**⑥自报字数一致性检测 → 运行 `scripts/detect_wordcount_claim.py` 扫描旁白中“X个字”标注与紧邻引文的实际汉字计数是否一致（如“退婚”两个字×实际3字→阻断）；退出码1即阻断本章** |
| 去AI味长文本采样 | **每章独立采样**：短篇单章≤1400字（硬顶），始终全量扫描；本技能不存在>1400字分层抽样场景（写作约束1000-1400字与检测阈值统一，无长文本分层分支） |
| 跨章指标评估 | 情绪曲线/连贯性等跨章指标需在Phase 3终审时至少读取最近5章上下文 |
| **Phase 3 全卷逻辑一致性审计发现🔴矛盾** | **暂停进入十维评分，先执行H类三大审计动作修复矛盾，修复后复检，再进入十维评分（零确认）** |
| **全卷审计发现🔴矛盾但无法自动修复（如矛盾根因涉及多章联动）** | **标记为“需人工干预”→在审计报告中标注矛盾详情和建议方案→跳过该矛盾继续Phase 3（不卡死）→ Phase 4交付报告中作为已知问题列出** |
