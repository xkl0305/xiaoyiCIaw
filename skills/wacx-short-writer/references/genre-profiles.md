# 模块九点五·题材感知配置

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### 基准配置：短篇/超短篇（zhihu-short）

短篇最匹配的题材配置。以下为短篇基线，其他题材在此基础上做差异调整。

| 配置项 | 值 |
|--------|-----|
| **钩子偏好** | 情绪钩>悬念钩>选择钩 |
| **钩子基线** | strong（短篇每章都必须有强钩子） |
| **爽点密度** | high（2+/章，短篇不容注水） |
| **Combo间隔** | 2章参考1次（短篇节奏极快） |
| **里程碑间隔** | 3章参考1次（短篇的“大事件”需求更密集） |
| **微兑现类型** | 情绪兑现>信息兑现>关系兑现 |
| **微兑现下限** | 2/章（每章至少2次微兑现） |
| **过渡章下限** | 2/章（过渡章也不可降微兑现） |
| **停滞阈值** | **1章**（连续1章无推进即触发预警） |
| **主线最大连续** | 2章（短篇篇幅短，主线比例天然高） |
| **感情线断档** | 3章（短篇感情线不容长期断档） |
| **过渡章上限** | **0章**（短篇不允许连续过渡章） |
| **债务倍率** | 2.0（短篇节奏要求最严格） |
| **偿还窗口** | 1章（节奏债务必须在1章内偿还） |

> **短篇铁律**：以上基线对所有短篇都适用，区别在于不同题材的钩子/爽点/微兑现偏好不同。

所有题材共享短篇基线（停滞阈值≤2章、过渡章≤1章、债务倍率≥1.0），以下列出各题材的**差异化配置**：

| 1 | **爽文/系统流** | 渴望钩>危机钩>情绪钩 | high(2+) | 能力/资源/认可 | 停滞2章·主线3章 | 金手指尽快亮（前1-2章）；数值反馈可视化；章末留明确期待 |
| 2 | **修仙/玄幻** | 危机钩>渴望钩>选择钩 | high(2+) | 能力/资源/信息 | 停滞2章·主线4章 | 境界突破是核心期待；短篇中阶位制要简化（不宜体系太复杂） |
| 3 | **言情/甜宠** | **情绪钩>渴望钩>选择钩** | medium(1) | 关系/情绪/认可 | **感情断档3章** | 情绪钩是王牌；关系进展是最重要的微兑现；短篇中感情线须占据C位 |

| 4 | **悬疑/推理** | **悬念钩>危机钩>选择钩** | low(0-1) | 信息/线索 | 停滞2章·主线4章 | 逻辑完整优先于爽点密度；信息兑现是核心；短篇不宜铺太复杂谜题 |
| 5 | **规则怪谈** | 危机钩>**悬念钩>选择钩** | medium(1) | 信息/线索/能力 | **停滞1章·主线2章** | 过渡章容忍极低；债务倍率高；短篇中诡计规则要简洁清晰 |
| 6 | **都市异能** | 危机钩>渴望钩>情绪钩 | **high(2+)** | 认可/能力/关系 | **停滞1章·主线3章** | 打脸装逼核心爽点；隐藏身份→掉马；3章一峰节奏适配短篇长度 |
| 7 | **替身文/虐文** | **情绪钩>选择钩>悬念钩** | medium(1) | 情绪/关系/认可 | **感情断档3章** | 情绪钩是绝对核心；身份掉马是王牌；短篇要快速进入虐→反转循环 |
| 8 | **电竞** | 危机钩>选择钩>渴望钩 | high(2+) | 信息/认可/关系 | 停滞1章·主线3章 | 比赛章节有可追踪胜负目标；逆风翻盘核心爽点；比分/舆论实时反馈 |

### 十维评分题材自适应速查（短篇版）

| 维度 | 基准（zhihu-short） | 宽松方向（悬疑/克苏鲁） | 严格方向（爽文/游戏/直播） |
|:----:|:------------------:|:----------------------:|:------------------------:|
| 1.开局引力 | 前500字出冲突 | 前800字（需少量铺垫） | 前300字 |
| 2.节奏爽点 | 2+/章 | 1/章（信息兑当代替） | 3+/章 |
| 6.黏性转化 | 情绪钩优先 | 悬念钩优先 | 渴望钩/危机钩优先 |
| 过渡章容忍 | 0章 | 最多1章 | 0章 |

> **使用说明**：短篇篇幅决定了所有题材的节奏基准都显著高于长篇。配置表中的值已做短篇化压缩处理。Phase 3评分时，先查题材归属，按配置调整预期——不要把悬疑按爽文的标准评爽点，也不要把电竞按言情标准评感情线。

## 选题破局技法（抓痛点·破关七类）

> 题材配置解决「怎么写」，本段解决「写什么能火 / 读者要什么」。与 `bestseller-methodology.md` 的「现实焦虑荒诞化模型 / 三维坐标选题法」互补。

- **评论区情绪抓取法**：从社交平台评论提炼读者真实情绪需求（大龄剩女被嘲→千亿总裁打脸），比主观猜更准。
- **经典内核反转法**：传统套路180°反转（退婚流→男方退婚/女方逼婚是魔女），意料之外又在类型逻辑内。
- **关键词缝合法（细化）**：现实焦虑词 + 网文题材词精准焊接（租房坑→修真界灵石贷；教育内卷→修仙衡水），反差即爽点。
- **旧瓶装新酒法**：经典结构换背景/人设（战神归来女儿住狗窝→后代是挖矿奴隶）。
- **反套路设定**：让读者意料之外（被反派打死能成神，主角求死被当英雄）。

**落点**：Phase 0 选题时，先用三维坐标（热爱∩擅长∩市场）定根基，再用上述技法找一个「情绪锚点」做开篇承诺。
