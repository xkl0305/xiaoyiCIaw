# 边界条件与异常 Fallback（深度扩展·按需读取）

主流程核心规则（评分表/验收铁律/灵魂锚点/去AI）已内联 SKILL.md 正文（L2）。本文件处理异常分支，仅在触发时读取。

## 短篇基准

- **输入无效**：非中文 / 乱码 / 空正文 → 返回“请提供有效中文正文”并要求重传，绝不强行生成。
- **字数越界**：单章 <1000 或 >1400 / 总篇 <8k 或 >10k → 触发字数闸门拦截，提示压缩/扩充，不交付。
- **全文超长**：>10万字 → 建议拆分多卷/多篇，按批审阅，避免一次性上下文溢出。
- **脚本执行失败**（沙箱禁 shell）：机械闸退化 LLM 按验收铁律自评，报告须标注“机械闸未执行·软约束”，且不得声称“exit=0 硬达标”。
- **锚点缺失**：Phase 0 退回灵魂锚点采集，不进入自动模式（见灵魂锚点非空强制）。
- **格式异常**：正文含不可解析标记/二进制碎片 → 提示用户清理后重传。

## 通用原则

- 任何 fallback 都不绕过 P0 零确认硬线（仅 Phase 0 可交互）。
- 降级路径（LLM 自评）产出物须明确标注降幅，不得伪装为机械闸验证结果。
- 锚点缺失且无任何可采集来源时，宁可中止也不产出无魂文（对应缺陷③防同质化）。

## 机械闸脚本异常码与失败处理对照表

各 `scripts/*.py` 机械闸以**退出码**传达结果，调用方（子代理 / 终审）须严格按码处置，**禁止把 exit=2 伪装成 exit=0 硬达标**（对应验收铁律“反元层幻觉”）。

| 脚本 | exit=0 | exit=1 | exit=2（脚本故障·非文本违规） |
|------|--------|--------|-------------------------------|
| detect_ai_flavor.py | 合规放行 | 命中破折号>限 / 禁用词 / 引号违规 / 思考路径结构 | 参数缺失 / 文件不存在 / 非 UTF-8 解码失败 / 读取异常 |
| detect_water.py | 去水感达标 | 水段候选 ≥ 阈值(默认3) | 文件不存在 / 非 UTF-8 / 读取异常 / 无输入 |
| detect_repetition.py | 无重复 | 存在语义 / 字面重复 | 文件不存在 / 非 UTF-8 / 读取异常 |
| check_chapter_wordcount.py | 字数达标(单章1000-1400+总8k-10k) | 越界 | 文件不存在 / 非 UTF-8 / 读取异常 |
| detect_wordcount_claim.py | 自报一致 | 自报与实测不符 | 文件不存在 / 非 UTF-8 / 读取异常 |
| detect_hook.py | 开篇钩子合规 | 命中避雷针(天气/睡醒/照镜子/简历/世界观/日常) | 文件不存在 / 非 UTF-8 / 读取异常 |
| detect_hallucination.py | 无硬冲突(有锚点时) | 与 fact_anchor.json 冲突 | 无锚点文件→exit=2降级LLM自评(不阻塞) / 非 UTF-8 / 读取异常 |
| detect_dialogue_ai.py | 对话灵气达标 | 对话AI腔命中 | 文件不存在 / 非 UTF-8 / 读取异常 |

**exit=2 统一降级处置（强制）**：
1. 立即终止该脚本的硬阻断效力，不得据其判“未达标”或“达标”。
2. 改走 LLM 自评降级：按验收铁律逐维核对文本证据（字数 / 重复 / AI味 / 水感 / 钩子 / 对话灵气）。
3. 终审报告须显式标注「机械闸未执行·软约束·可靠性降级」，列明失败的脚本名与原因，提示用户本地复核。
4. 若多个脚本同时 exit=2，整体结论标注“全机械闸失效，仅 LLM 自评，勿视为硬达标”。

**典型失败原因与排查**：
- `UnicodeDecodeError`：源文件含 GBK / UTF-16 等编码 → 转 UTF-8 后重跑。
- `FileNotFoundError`：路径传错或文件未生成 → 检查 Phase 产出路径。
- 空输入（detect_water 收 stdin 无内容）：上游未产出正文 → 退回重生成。
- 参数缺失（detect_ai_flavor 未给 <file>）：补文件路径重跑。

## 各脚本 exit=2 专项降级自评清单（调用方兜底时逐项核对）

当某脚本 exit=2，LLM 须按该脚本职责手动复核，并在报告中列出已核条目与结论：

- **detect_ai_flavor.py 缺失** → 手动逐行扫描：破折号是否 >5 处；BANNED_WORDS 是否命中；引号是否全中文双引号；是否存在“总分总框架词 / 排比 / 空泛升华 / 无代价完美承诺”思考路径。给出逐类计数。
- **detect_water.py 缺失** → 手动切段（空行分段），对每段判断是否“无对话 + 无生理反应 + 静态铺陈主导”；对 >200 字长段重点检查是否有情绪推进信号；留意段内字面重复拖沓。给出水段候选清单。
- **detect_repetition.py 缺失** → 手动通读相邻章节，标记语义近似复述（同义堆叠 / 句式模板 / 跨章句式雷同）；必要时请用户辅助交叉比对。
- **check_chapter_wordcount.py 缺失** → 用 `wc -m` 或 `len(text)` 手算每章有效字数，对照 1000-1400 闸门与总篇 8k-10k。
- **detect_wordcount_claim.py 缺失** → 比对报告自报字数与实测字数是否一致。
- **detect_hook.py 缺失** → 检查开篇 200 字是否命中避雷针（天气 / 睡醒 / 照镜子 / 简历 / 世界观 dump / 日常流水）。
- **detect_hallucination.py 缺失** → 将正文关键设定与 `fact_anchor.json` 逐条比对，标记硬冲突。
- **detect_dialogue_ai.py 缺失** → 检查对话是否“信息交换型 > 情感交锋型”、标签是否机械重复、是否存在机械问答/解释欲过强；逐段估算对话灵气。

## 异常决策流（调用方 SOP）

1. 调用前：确认输入文件已生成、路径存在、编码为 UTF-8、非空。
2. 调用后读退出码：
   - exit=0 → 该维机械闸通过，进入下一闸。
   - exit=1 → 该维硬不达标，返回具体命中项，要求迭代修复，不交付。
   - exit=2 → 触发本文件降级处置，转 LLM 自评并标注，绝不伪装 exit=0。
3. 多脚本分歧：以“机械闸优先、LLM 兜底”为原则；任一 exit=2 即整体标注“部分机械闸失效”。
4. 全部 exit=0 → 进入十维评分；任一维度 < 验收线 → 回到对应 references 选词/规则迭代。
5. 终审：报告须区分“机械闸验证”与“LLM 自评”两类结论，分别列证。

## 补充边界情形与排查手册

- **空文件（0 字节）**：detect_* 多判为 exit=2（无输入）→ 退回上游确认正文是否真正产出，勿当作“合规”。
- **二进制 / 不可解码碎片**：读取抛 `UnicodeDecodeError` → 提示用户清理乱码 / 重导出 UTF-8 纯文本。
- **超长单行（无空行）**：detect_water 按 `。！？` 滑动窗口每 4 句并段兜底；若仍异常，人工分段后重跑。
- **`--json` 解析失败**：脚本正常退出但调用方解析 JSON 报错 → 检查 stdout 是否被日志污染；必要时改用纯文本解析 `[WATER]` / `WATER_TOTAL` 行。
- **脚本超时 / 被沙箱 kill**：视为 exit=2，按降级处置；超时多为超长输入，先拆分再跑。
- **stdin 无内容**：detect_water 收 stdin 时空输入 → exit=2，退回重生成正文。
- **路径含空格 / 中文 / 特殊符**：部分 shell 拆词失败 → 用引号包裹路径或传绝对路径。
- **权限拒绝（PermissionError）**：文件被占用 / 只读 → 复制副本后重跑。
- **重复运行幂等**：多次运行同一文件结果应一致；若不一致，检查是否混入临时写入，清理后重跑。
- **多脚本结论冲突（如 water 判水但 LLM 认为有张力）**：以“机械闸候选 + LLM 终裁”处理，LLM 须给出推翻理由并标注，不得静默忽略机械闸信号。
