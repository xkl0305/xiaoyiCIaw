# 爆款方法论（深度补充参考）

> 本文件为「爆款基因·情绪承诺·题材感知」模块的实操补充。每条标注来源与适用（通用/偏短篇/偏长篇）。

## 一、核心框架（6 个）

**① 四维度拆解框架（情绪价值/金手指/冲突节奏/角色人设）** 
动笔前/完稿后逐项自检：①首章是否埋“委屈或金手指”情绪钩子；②前三章是否说清“主角凭啥赢、外挂多强”；③每章结尾是否抛钩子、一波未平一波起；④主角是否有鲜明性格标签且行为一致。

**② Hook 模型四步曲（触发→行动→奖励→投入）** 
开篇挖读者渴望/愤怒点做触发；开头用最少脑细胞给期待做行动；用不可预见的惊喜（抽盲盒式）做奖励；让主角持续积累装备/地位/势力做投入，使读者因“沉没成本”难弃书。

**③ 创作四步公式（生产需求→给予希望→努力解决→得偿所愿）** 
把主角扔进极端不公困境制造“不该如此”认知失调；亮金手指给确定性希望；用延迟满足（阶梯式+套娃式困境）拉长解决；让期待在克服后兑现。

**④ 核心循环 + 三幕式** 
用“脑洞(世界观)+点子(外挂)+梗(爽点冲突)”做地基，以“起因→经过→结果”为灵魂且结果即下一循环起因，无限滚雪球，支撑百万/千万字产能。

**⑤ 五步拆解法（前10章解构）** 
整体印象→人物关系（哪章裂哪章炸）→设定冲突（尤其信息差）→节奏钩子（章末钩子分类：信息/情感/外部威胁）→偷师转化（当场改写一技巧进自己章节）。

**⑥ 现实焦虑荒诞化模型** 
把内卷/焦虑（教育/职场/婚恋/买房/租房）用极端荒诞方式包装进类型文（教育内卷→修仙衡水、职场PUA→魔门内卷、租房坑→灵石贷），制造强代入情绪共鸣。

## 二、爆款公式与技法（10 个）

- **300字双输出**：前300字必须同时“出主角+出冲突”，信息密度优先，禁先写景/铺垫/起床。
- **角色三棱镜**：动机+性格+实力三面折射主角，三者高度统一不自相矛盾；人设靠“面对冲突时的选择”立住。
- **配角功能化+主题扩音器**：配角贴功能标签+独立动机；高级用法让配角之口点主题、立反衬。
- **黄金三章**：最快走完第一个三幕式循环，把“主角外挂+核心仇恨”直接砸向读者。
- **开篇三秒钩子（打破日常预期）**：第一句含“变量”(打破平静事件)或“问号”(违反常理结果)，制造冲突张力；慢热即原罪。
- **开篇3章抛冲突+先抑后扬**：前三章抛核心冲突不拖沓；爽点先抑后扬（困境→反转打脸），密度适中。
- **四大原罪**：妄想/懒惰/贪婪/痴迷四对人性的杠杆拿捏读者爽点。原罪↔读者心理映射：欲望→妄想（帮读者实现脱离现实的逆袭妄想）/ 简单→懒惰（喂懒让读者躺着看不动脑）/ 运气→贪婪（不确定惊喜吊着贪婪永远期待下一章）/ 财富→痴迷（虚拟财富营造美好掩盖现实窘迫）。设计爽点时按此四杠杆校准「爽感来源」。
- **苟—爆—苟 螺旋节奏**：隐忍蓄势→爆发反杀/布局权谋→回归低调，融合强爽点。
- **信息差与代价/可控的意外**：制造“既知主角会赢又时刻感觉要输”，靠信息差+把代价写成揪心戏。
- **扫榜选题+追读比验证**：扫畅销榜前50挑题材融合创新；试写2-3万字用追读比小成本验证。

## 三、决策规则（5 条）

1. 若开篇300字内未同时“出主角+出冲突”→ 判定开篇不合格必须重改（黄金三秒留不住人即扑街）。
2. 若追读比优（如500收藏对应200+追读）则坚持题材；偏低则弃文换题，不靠主观评论判断。
3. 若主角赢得太轻松→ 破坏延迟满足，须升级“阶梯式爽感+套娃式困境”。
4. 若奖励可被预见→ 失去对下一章期待，改“抽盲盒式随机惊喜”（如屠龙爆龙蛋）。
5. 若章末无钩子（信息/情感/外部威胁任一缺失）→ 留存率下滑，必须断章抛悬念。

## 四、短篇 vs 长篇 差异化应用

**偏短篇**
1. 开篇三秒/300字内直接砸钩子与核心冲突，零世界观铺垫。
2. 第一句话含“变量或问号”，打破日常预期一句话抓人。
3. 黄金三章快速走完首个三幕式，开头即高潮、期待即兑现。
4. 情绪钩子单一集中，首章埋“委屈或金手指”爽点，不做长线铺陈。
5. 现实焦虑荒诞化做单点爆破（一个痛点一个梗），共鸣更直接。

**偏长篇**
1. 核心循环+三幕式无限滚雪球，支撑百万/千万字产能。
2. 套娃式困境与层级翻新（生存→管理→权谋）维持长线爽感。
3. 信息差+代价制造“可控的意外”长线勾连，代价写成揪心戏。
4. 追读比数据驱动，前期小成本试写2-3万字验证题材后再稳定日更。
5. 配角功能化+主题扩音器做长线人物弧光与反英雄塑造，黑深残下用黑色幽默缓冲。

## 五、P1 增量决策规则（题材 / 冲突 / 弹药 · 补全）

> 本次补全前，决策规则仅 5 条且偏“开篇 / 追读 / 奖励 / 钩子”执行面；以下 3 条补足“选题决策、冲突结构、爽点弹药”三个独有模块。

**⑥ 三维坐标选题法**：题材须落在「热爱度 ∩ 擅长点 ∩ 市场风向」三者交集；只因市场热却无热爱/擅长→易扑且难持续，只因热爱却无市场→自嗨小众。开篇前用三维坐标自检题材根基，避免写完才发现赛道错位。

**⑦ 三类冲突并列框架**：每章冲突须明确落在「外部(打脸/对抗) / 内部(人性抉择/自我怀疑) / 环境(对抗规则/系统)」至少一类，长线混用三类避免单调；纯外部冲突连章→人物扁平，须穿插内部/环境冲突立人设、做弧光。

**⑧ 爽点弹药前置管理**：配角的嘲讽 / 质疑 / 误解是未来「打脸」的弹药——须在逆境章提前埋设（读者/主角知而配角不知的信息差），不可临到打脸章才现编；弹药越足，打脸越爽。每轮循环开场即布质疑，高潮章回收。

## 六、破关七类元框架（技法归位 · 总览导航）

> 以下「破关-防崩-去水感-抓痛点-抓眼球-塑记忆-提点击」七类元框架。把零散技巧按“直击痛点”归为七类，动笔前或卡关时据此快速定位“该补哪一类”，避免盲目堆技法。〔通用〕

| 类别 | 痛点域 | 核心解法（一句话） |
|------|--------|-------------------|
| **破卡关** | 境界突破（拒签→签约→千均→精品→万订） | 黄金三章+500字钩子+套娃循环+逆推锚点，分阶段破局 |
| **防崩文** | 结构稳固（写散/中期疲软/逻辑崩） | 套娃循环+计划意外+故事细胞分裂+三线并行+伏笔回收 |
| **去水感** | 文笔提鲜（流水账/AI味/无画面） | 镜头推拉+展示非讲述+去过滤词+快慢分配+留白 |
| **抓痛点** | 选题市场（写啥能火/读者要啥） | 关键词缝合+经典内核反转+评论区抓取+旧瓶装新酒+反套路 |
| **抓眼球** | 开篇钩子（前三章定生死） | 500字四钩+危机应对法+黄金三章+开篇三不要 |
| **塑记忆** | 人设群像（过目不忘/情感投射） | 人设烙印+三层代入+记忆钢印+反派动机+落幕仪式 |
| **提点击** | 运营包装（标题/简介/投稿封装） | 标题公式+简介广告化+投稿封装+更新字数策略 |

**晋级阶段 × 类别速查**（定位你当前卡在哪）：
- 拒签境：抓眼球（500字钩）+ 抓痛点（关键词缝合）+ 破卡关（先完成再完美）
- 签约境：破卡关（主线至上+套娃循环）+ 防崩文（计划意外）
- 千均境：破卡关（情绪拉扯+三线并行）+ 提点击（标题简介广告化）
- 精品境：防崩文（核心梗循环+多层嵌套）+ 去水感（文笔高优先级）
- 万订境：破卡关（逆推锚点+人物弧光）+ 塑记忆（群像鲜活）+ 去水感（电影级文笔）
