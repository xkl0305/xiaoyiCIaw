# AI协作写作工作流（短篇·单章快速迭代版）

> AI是实习生与初稿工，作者是总编辑与灵魂注入者。AI承担细节、扩展与效率，判断、情绪与风格由人定夺。协作的终点，是让文字从概率拼接的“正确废话”，走向私有经验的生命表达。

## 一、AI协作定位观

1. 把AI当作实习生与初稿工，作者担任总编辑。AI负责场景描写、细节填充、逻辑推导、多方案枚举；作者负责生活感悟、人物动机、主题判断与最终定稿。
2. AI能做的：把想好的情节扩写成环境氛围、围观反应、反派神态；生成三个备选方向供挑选；按指令润色文风。
3. 作者留住的：故事的灵魂、人物的独特情感、最动人的细节。AI生成的是半成品，经通读、修改、注入个人细节之后才算作品。
4. 有效指令公式：角色定位，加具体任务，加约束条件，加风格参考。示例：你是一位擅长细腻情感的小说家；写男主角雨夜独处场景；禁用“泪流满面、心如刀绞”类成语，200字内；模仿余华式平静中蕴含悲怆的笔触。
5. 沟通姿势：高手用AI“喂饭”，给出题材、人物、场景、字数、风格的具体要求；避免“帮我写个玄幻开头”式的空指令。

## 二、逆转AI底层创作逻辑三原则

AI写作依赖公共数据做概率拼接，产出工整全面的“正确废话”；真人写作基于私有经验做生命表达，产出有瑕疵却强共鸣的文字。要逆转这一逻辑，守住三条原则：

1. 私有化与具体化：创作素材必须来自私有经验，包括个人经历与记忆、真实案例、感官场景细节、内心纠结与废稿。口诀是重展示、轻直说。示例：不写“他非常焦虑”，写“他把打火机在手里按响了十七次，没一次冒出火苗”。
2. 人化节奏与思维流：结构跟随情绪与思维流动，拒绝总分总与匀速段落。急促时用短句碎句，压抑时用长句堆细节，顿悟时留白一行再落一句白话。允许跑题与自我质疑，保留“等等，扯远了”式的思维毛边。
3. 人格注入与风格锚定：为文本注入明确人设与态度，贯穿始终。先确定说话姿态（犀利吐槽或温暖陪伴），多用“我个人觉得、老实说”开启观点，保留口头禅与独特比喻，把最核心的观点藏进日常场景。终极指令示例：“请像一位刚踩完坑的疲惫创业者，在深夜加班后跟朋友吐槽时那样写作，素材用我提供的具体案例，结构跟着情绪走。”

## 三、“导演工作法”三步

把AI从聊天搭子变成方法派导演，分三步注入灵魂：

1. 赋予角色内在逻辑：深挖角色行为背后的潜意识，别只贴人设标签。示例：问AI“林越童年与破碎、修复有关的记忆是什么；感到不安时他会更刻薄还是反常地沉默”，把最精彩的答案固定成档案。
2. 构建具象场景氛围：写章节前先带AI沉浸到场景里，调用五感。示例：让AI用三种嗅觉写暴雨夜的旧书店，写一个只有该雨夜才会发生的细节动作，并设计雨声从开头到结尾的变化。
3. 设计有潜台词的对话：对话的灵魂在没说出来的那一半。示例：苏晚问“这本书很贵吧”，真正想说的是“你看起来不像懂书的人”；林越嘴上说“修旧如旧，比新的还贵”，身体却下意识替她挡雨。要求至少两处用动作与环境音填补的沉默。

整合三步产出的角色小传、场景氛围与对话片段，让AI生成完整章节，随后由作者补一笔个人专属的细节，比如一段童年闪回或一句只有自己懂的叹息。

## 四、真人写作四大心法

1. 创作顺序反转：先当考古员，再当建筑师。先蹲在现场，摸泥土、嗅气味、听风声，让细节自己长出故事，再谈结构。产出现场构思手记，记录考据、灵感与废稿修改理由。
2. 文字刃口：摒弃光滑无刺的表达，每300字植入一处“生理细节，加心理暗涌，加文明隐喻”的三重组合。示例：不写“血流如注”，写“血顺着锁骨沟往下淌，在道袍前襟洇开一片暗红，像一张慢慢浸透的、无人能识的符”。
3. 呼吸节奏控制：按情绪调整句式。急促时短句碎句模拟喘不过气，窒息时长句堆细节制造压迫，顿悟时留白一行再落一句白话。
4. 藏刺于平实：不写宏大概念，把最狠的观点藏进日常场景与朴素句子。示例：不写“文明冲突”，写“他教孩子数羊：一、二、三……孩子掰手指：Un、deux、trois……两套数字在泥地上相遇，谁也没压过谁”。

细节约束：细节只服务三处，包括关键人物的瞬间状态、核心道具的独特质感、最重要的情绪转折点；纯过渡与说明处保持干净利落。

## 五、AI改稿四步

改稿遵循“先删后改”。删是底线：与推进剧情无关的华丽修辞、自鸣得意的比喻，一律砍掉；一句话能说清，不用三句。改是精髓，走四步：

1. 感官定点爆发：不写“她很伤心”，写她看到什么、闻到什么、摸到什么；重要场景至少调动两种感官，把读者扔进主角的身体里。
2. 欲望同步：开场就让读者与主角想要同一件事，复仇、求生、找真相，钩子必须挂牢。
3. 认知错位：利用信息差，让读者知道主角不知道的阴谋而揪心，或让主角发现读者不知道的线索而惊呼；控制节奏，不一次性倒完。
4. 情绪节奏：紧张时句子短、段落碎，像鼓点；舒缓或内心翻涌时句子长、段落绵，像暗流。文字节奏就是读者的心跳。

## 六、9大流派AI写手速查表

| 流派 | 创作哲学 | 文笔特征 |
|---|---|---|
| 冷感白描派 | 少即是多，像摄影机冷眼观察，把解读空间留给读者 | 短句密集、节奏冷冽，少形容词多用名词动词，画面感强，情绪藏在动作与环境之下 |
| 电影叙事派 | 把文字当摄影机，用镜头化场景与蒙太奇制造节奏张力 | 场景开篇、多感官齐下，长短句交替模拟镜头，分镜式分段，情绪靠画面推进 |
| 情绪爆发派 | 情绪是故事的核心商品，用生理反馈与感官扭曲让读者替角色感受 | 细腻生理细节，环境随情绪变色，节奏按“压忍、泄露、爆发”设计 |
| 悬念操控派 | 好奇心是阅读的第一动力，用信息缺口编织悬念网 | 开篇300字内抛异常或疑问，对话充满潜台词与信息差，章末留钩子，铺垫、期待、点燃层层递进 |
| 人设定格派 | 好故事源于好人物，用“特质加行为加动机”打造辨识度角色 | 语言精炼，细节动作直接反映性格，对白符合身份，强调两难抉择中的价值排序 |
| 题材造境派 | 在专属领域登峰造极，用考据级细节把读者拉入那个世界 | 词汇句式高度贴合题材，氛围感强、时代感准确，用文化元素构建时空围墙 |
| 蓝图构筑派 | 先画图纸再施工，用主线、支线、因果链保证长篇不崩 | 行文逻辑驱动、理性冷静，善用结构工具，语言简洁重效率 |
| 真人润色派 | 专职对抗AI腔，给底稿注入个人经历与思维毛边 | 口语化、有自言自语的味道，结构松散但有指向，故意保留少量瑕疵增温度 |
| 哲思独白派 | 以沉静悲悯的目光注视人生，追问生死与时间命题 | 第一人称独语，语言质朴含深意，句式平缓带冥想节奏，以小物见宇宙 |

可按故事调性召唤对应流派，也可组合多派创造独特风格。

## 七、协作红线清单

1. AI内容占比控制：AI生成内容控制在成品三成以内，全文通读改写，融入个人细节。
2. 金手指约束：金手指必须有约束、代价与成长曲线，有缺陷才有冲突与看点。
3. 最终人工终审：每一个AI输出都要经过作者的思考、筛选与改写，作者是定稿人。
4. 逻辑审查：人物动机与行为前后一致，伏笔按时回收，剧情点逻辑自洽。
5. 去AI腔扫尾：把“说道、心想、突然”换成更精准的词；把空泛形容词换成具体细节；加入只有你知道的生活细节；大声朗读对话，不顺口就重写；打破工整句式。

## 八、短篇单章快速迭代节奏

单章生产循环，一章一闭环：

1. 定调性：先定本章的情绪主色与流派（从9大流派中选一个或组合），并明确本章钩子。
2. 导演工作法调教：分别向AI要角色内在逻辑、场景氛围、潜台词对话三份素材，再喂回AI生成初稿。
3. 初稿生成：要求单章篇幅内骨架扎实、情绪集中，砍掉支线枝蔓。
4. 改稿四步：先删无关剧情，再做感官定点爆发、欲望同步、认知错位、情绪节奏四项改造。
5. 终审收口：人工终审加逻辑审查加去AI腔扫尾，通读一遍确认节奏无拖沓。

每章生产后立即复盘三个问题：钩子是否立住、结尾是否留余味、情绪曲线是否一压一放。

## 九、单章节奏清单

1. 开篇300字内抛出一个异常或疑问，立即挂住读者。
2. 单章只讲一件事，完成一个小闭环，章末留钩子。
3. 情绪曲线一压一放，句子长短跟着心跳走。
4. 结尾收束处藏一句白话，给读者留回味。
5. 人物与场景设定提前固定成模板，单章生成时直接调用，把迭代成本压到最低。
