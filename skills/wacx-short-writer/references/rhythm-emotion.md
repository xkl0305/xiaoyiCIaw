# 节奏张力技法库（方法论整合 · 缺口A+B）

> **定位**：本文件补 `opening-hooks.md`（管第1章切入点）之后的第二层——章内/章间节奏与爽点力度的可操作技法，直击“读者黏性不足 / 爽点不够 / 爽点不够爆”不达标根因。两者维度不同，勿混：开篇钩子管“第一眼勾不勾”，本文件管“勾住后留不留、爽不爽”。
> **来源**：（《读者黏性引爆器》《故事张力爆破手》《大宁赘婿系统拆解报告》）。
> **机械闸局限**：张力/黏性为语义级，难机械化检测。本文件以参考 + 评分第2维 LLM 双检为主，不强行加不可靠脚本（避免误杀）。

---

## 一、读者黏性四技法（管“让读者持续阅读”）

### 1. 章节开篇信息炸弹
章前200字必须扔“危机 / 大喜 / 诱惑 / 八卦”级猛料，而非温吞衔接上章结尾。
- 底层逻辑：对碎片化注意力绝对尊重。第一句必须“啪”一下把读者拽进故事，放弃所有“前情提要”式温吞开头。
- 反例：上一章结尾主角出发，这章开头“第二天清晨，他吃完早饭，准备上路。” → 哑火。
- 正例：“他刚踏进城门，城墙上挂着的头颅，正是昨夜与他喝过酒的老周。”

### 2. 收获前置 / 爽点预支（目标梯度效应）
在读者期待“最终大奖”前，先给个小甜头。
- 原理：越接近目标行动动机越强。先预支阶段性爽感，既是给坚持的读者发“工资”，也悄悄抬高“最终阈值”，让大爽落地时更爆。
- 写法：得残卷 → 先让它揍个小反派成功；升小境界 → 先打脸一个当场嘲讽者。

### 3. 双线 / 多线叙事（信息差网状期待）
主线推进时，暗线同步铺垫（主角修炼，反派暗中布局；主角寻宝，外界势力风云变幻）。
- 原理：把“单点惊喜”升级为“网状期待”。每条线都是独立信息差来源，读者在不同线间跳取新情报，大脑被高密度信息刺激，分泌“我还想知道”的成瘾感。

### 4. 事件共鸣（开篇筛选与锚定）
用读者能瞬间理解并代入的“两难 / 共性事件”（失业、被看不起、救家人）开篇。
- 原理：最低成本完成读者筛选。共鸣 = “我懂你”，瞬间建情感契约；事件本身冲突也筛出好这口的受众。

## 二、张力四法 + 公式（管“爽点有力度”）

### 1. 但是法则
把“然后”全换成“但是”，在主角目标路上劈深渊、塞炸弹。
- 示例：拿宝物 → 但是守护兽是爱人；打败守护兽 → 但是宝物是致命诅咒；拿到宝物 → 但是家人正等杀人越货。
- 核心：制造求而不得、功亏一篑的拉扯感，让读者爽在主角的挣扎突破里。

### 2. 冲突加筹码
给冲突安上“必须赢”的理由，让输赢关乎主角最珍视之物。
- 示例：打架输了 → 妹妹被带走 / 宗门解散，而非只丢面子。
- 核心：张力大小看筹码重量，而非场面大小。

### 3. 信息不对称
玩信息差制造悬念，两种：
- 读者知道主角不知道：反派下毒，主角要喝，读者心悬嗓子眼。
- 主角知道读者不知道：主角绝境淡定，读者好奇“凭什么”，直到亮底牌（爽点爆发）。
- 核心：保留信息差，让剧情在意料外、情理中横跳。

### 4. 极限施压
把主角丢进“高压锅”，逼他做两难选择（坏与更坏、美好二选一），设死线。
- 示例：三天内突破境界，否则青梅竹马嫁仇人；一战暴露底牌，就被全世界通缉。
- 核心：让主角牺牲珍贵东西换生机，打造剧情高光。

**核心公式：张力 = 筹码 × 信息差 × 死线。** 三者任一为0，张力塌方。

## 三、节奏模板（管“爽点密度”）

- **321公式**（源自《大宁赘婿》拆解）：3章一小爽、2章一中爽、1章一大爽的节奏锚，把“爽点密集化”从原则量化成可排期的模板。
- **每章微高潮**：每章至少1个情绪高点 / 小爽点（反杀、解锁、打脸、信息揭露），禁纯过渡章。过渡章≤1且须埋新钩子。
- **情绪循环**：情绪铺垫 → 理智破局 → 阶层攀升，循环上升，避免原地踏步。

## 四、评分联动

- **短篇** 模块二第2维「节奏爽点」/ **长篇** 模块一第2维「节奏爽点」对以下者扣分（见各自 SKILL.md 第2维）：
  - 章首200字无信息炸弹 / 高情绪钩子
  - 连续章节无微高潮 / 爽点预支
  - 冲突无筹码加重（张力平淡）
  - 违反321节奏密度（长篇：连续多章无小高潮；短篇：连续2章无爽点）

## 五、单章五步闭环 SOP（节奏树构建师·方法论）

> 把「节奏」从原则变成写每章可照做的结构。与「三、节奏模板」互补：模板管密度，本 SOP 管单章内部起落。

单章内按五步推进（铺垫→矛盾升级→冲突爆发→余波处理→新钩子）：
1. **铺垫**：抛出本章最小冲突/疑问，建立情绪基线（对应 emotion-curve 单章开头50-250字）。
2. **矛盾升级**：加码，让读者觉得「要糟」（应用二、张力四法：但是法则/加筹码/信息差/极限施压）。
3. **冲突爆发**：高能场面写短，保持冲击力（爆点规模逐轮扩大）。
4. **余波处理**：主角/世界有进展，情绪回落但不平复。
5. **新钩子**：章末留悬念/危机/信息差，引出下一单元。

**三层级视角**：
- 单章节奏（章内起落，用上述五步）
- 小段节奏（5-10章一单元：铺垫→升级→爆发→余波→钩子）
- 大节奏（整书/大篇章情绪曲线）

**口诀**：高能写短，低能写有用——铺垫/过渡段落须推进角色或世界观（含具体进展），纯过渡≤1章且须埋新钩子。

# 情绪弹簧·蓄势技法库（方法论整合 · 情绪曲线增强）

> **定位**：本文件是 `emotion-curve.md`（压-小扬-压-爆循环）的「蓄势技法补丁」。emotion-curve 管「要不要压」，本文件管「怎么压得读者服气」。直击「爽点偏弱 / 委屈像演的」写作短板。
> **来源**：《情绪弹簧创作导师·智能体》。
> **机械闸局限**：蓄势为语义级，难机械化检测，以评分第4维 LLM 双检为主，不强行加脚本（避免误杀）。

---

## 一、核心理论：情绪的弹簧

- 网文卖情绪。爽文与虐文共用一套底层逻辑。
- **爽 = 压抑 + 释放**：先制造困境（压弹簧），再绝地反击（弹弹簧）。
- **虐文逆向杠杆**：先给希望（拉弹簧），再毁掉美好（松手打回去），让读者感受剧烈痛苦。

---

## 二、新手 vs 老手：敢不敢「压弹簧」

- **新手**：不敢压，舍不得让主角受委屈 → 爽点无力，委屈像演的。
- **老手**：有技巧地压，给主角戴上「镣铐」——因规则限制或保护他人而**暂时**受委屈，为后续爆发积蓄势能。
- **关键**：镣铐须有因果（规则所迫 / 主动选择 / 护人所累），而非无脑随机倒霉。

---

## 三、蓄势四问（写每章前自检 · 写作期硬校验点）

写压抑 / 委屈情节前，逐条确认：

1. **委屈有因果吗？** —— 不是随机倒霉，而是主角主动选择 / 规则所迫 / 保护他人导致（镣铐成立）。
2. **筹码够重吗？** —— 输的是主角最珍视之物（人 / 尊严 / 机会），非只丢面子。
3. **读者知道主角「能反」吗？** —— 埋信息差（读者比配角早知底牌），让压抑有盼头。
4. **释放有爆点吗？** —— 压多深，弹多高；反弹规模须逐轮扩大。

> 🔴 **四问任一不达标 → 该压抑段视为「无效委屈」，重写或补镣铐。** 否则第4维情绪曲线按「压抑无效 / 爽点蓄势不足」扣分。

---

## 四、题材化压弹簧技巧（按题材选「镣铐」）

- **都市脑洞爽文**：用社死制造极限推拉。权威（前老板 / 势利眼）面前丢尽脸，挑战权威后再打脸。
- **末世文**：用物资和背叛挑战人性底线。因信任 / 善良被亲近之人背叛掠夺，最后以牙还牙。
- **古言文**：用捧杀和反转撕碎绿茶。表面隐忍落入圈套，实则将计就计借力打力，智商碾压。
- **高武文**：用绝对实力粉碎阶级黑幕。先铺垫阶级固化不公（如宗门考核黑幕），主角以碾压性实力打破规则。
- **修仙文**：用降维打击治愈傲慢。先刻画门阀优越感与傲慢，主角用更高维力量 / 认知毁掉其引以为傲之物。
- **虐文（通用）**：先给希望（拉弹簧），再让主角陷入地狱（松手打回去）。

---

## 五、与现有节奏联动

- 与 `rhythm-tension.md` 张力公式互补：**张力 = 筹码 × 信息差 × 死线**，本文件提供「筹码」的具体锻造法（镣铐 + 重筹码 + 信息差盼头）。

# 情绪曲线设计

## 核心公式：每3章完成一次“压-小扬-压-爆”循环

| 章节 | 情绪阶段 | 读者心理 | 写作要点 |
|-----|---------|---------|---------|
| 第1章 | 压 | “这主角太惨/太憋屈了，我要看他翻身” | 建立同情，展示困境，暗示主角有独特优点 |
| 第2章 | 小扬 | “果然有反转！我就知道！” | 主角获得小胜利或重要信息，不解决根本问题 |
| 第3章 | 压→爆预告 | “靠！又被打压？下章必须打脸！” | 反派变本加厉，主角获得关键筹码，章末暗示反击 |

**循环应用**：第4-6章重复此模式，爆点规模逐轮扩大。

---

## 六大情绪标签对应节奏模板

### 1. 打脸爽文（扮猪吃虎/马甲掉落）
- 第1章（压）：主角因隐藏身份被嘲讽/欺负
- 第2章（小扬）：不经意展露实力，但被误认为运气
- 第3章（压→爆预告）：遭遇更强对手，章末暗示即将当众揭穿身份

### 2. 极致虐恋（追妻火葬场）
- 第1章（压）：女主被男主虐心/忽视
- 第2章（小扬）：女主觉醒，做出离开决定
- 第3章（压→爆预告）：男主追悔莫及，章末出现男主后悔的画面

### 3. 爆笑反套路（沙雕吐槽/神转折）
- 第1章（压）：主角陷入经典套路剧情
- 第2章（小扬）：用清奇脑回路破解套路
- 第3章（压→爆预告）：系统/原剧情试图纠正，章末留“这也能行？”悬念

### 4. 悬疑惊悚（细思极恐/规则怪谈）
- 第1章（压）：遭遇无法解释的诡异事件
- 第2章（小扬）：找到一点线索或规律
- 第3章（压→爆预告）：发现规律是陷阱，章末留细思极恐钩子

### 5. 治愈甜宠（日常温馨/双向奔赴）
- 第1章（压）：主角处于孤独/缺爱状态
- 第2章（小扬）：与CP产生温暖互动
- 第3章（压→爆预告）：出现小误会，章末CP做出心动举动

### 6. 脑洞大开（系统流/末日囤货）
- 第1章（压）：获得金手指但面临生存危机
- 第2章（小扬）：利用金手指解决小危机
- 第3章（压→爆预告）：发现金手指有代价，章末出现更大机遇

---

## 单章内部情绪拐点设计

单章1000-1400字（目标~1200）内至少2-3次情绪变化：

开头50-200字：延续或急转，快速建立本章情绪基调
中间600-800字：情绪逐步升级，至少一次小起伏
结尾200-400字：情绪到达本章峰值后急转，留下钩子

### 情绪拐点句式库

**从憋屈到暗爽**：
- “他低着头，嘴角却微微上扬——他们还不知道，自己惹了谁。”
- “所有人都以为她认命了，直到她拿起手机，拨出了一个号码。”

**从震惊到愤怒**：
- “直到看到那张照片，她才发现，这三年的眼泪都流给了骗子。”

**从绝望到希望**：
- “门锁转动的声音响起时，她握紧了水果刀。但进来的，是那张熟悉的脸。”

**从得意到恐惧**：
- “他以为自己赢了，直到转身看见那个人的眼睛。”

**从平静到震惊**：
- “我像往常一样打开门，然后看见了这辈子最不想看见的人。”

## 评论区诱导设计

在以下节点刻意留白：
1. **两难选择**：主角在两个都有道理的选项中犹豫，章末不写决定
2. **信息差**：让读者比主角多知道一点信息，但不全知道
3. **误解不解释**：主角被误解时不立刻解释
4. **配角高光**：给反派或配角一个令人同情的瞬间
5. **规则争议**：主角做出道德灰色地带的选择，不评价对错

## 蓄势技法补丁（⭐ 写作期硬校验·见 `tension-spring.md`）

emotion-curve 管「要不要压」，蓄势技法管「怎么压得读者服气」。写每章压抑 / 委屈段前，逐条过 **蓄势四问**（委屈有因果 / 筹码够重 / 读者知主角能反 / 释放有爆点），任一不达标即「无效委屈」须重写（详见 `references/tension-spring.md`）。题材化压法速查：都市用社死、末世用背叛、古言用捧杀、高武用阶级黑幕、修仙用降维打击、虐文用「希望→毁灭」逆向杠杆。

# 情绪承诺引擎（方法论整合 · 作品门面）

> **定位**：本书名 / 简介 / 文案设计模块，补全「写作期→成稿期」最后一道门面。读者点击前感受到的是「情绪承诺」而非「题材设定」。
> **来源**：《情绪承诺引擎·智能体》。
> **联动**：短篇 Phase 4 交付前须做「书名 / 简介情绪承诺自检」（见 `short-craft-guide.md` 情绪承诺小节）；长篇可作为通用成稿文案指引。

---

## 一、核心主张

- **读者买的不是你的故事设定，而是翻开前感受到的情绪。**
- 设定（修仙 / 霸总 / 末世）只是容器，情绪才是购买理由。
- **新手常错**：把题材当卖点（“重生修仙文”），不告诉读者“重生后吊打仇人的爽感”。
- **正确做法**：提炼最能引发 爽 / 甜 / 虐 / 燃 的核心情绪，用书名 + 简介「承诺」给读者。

---

## 二、情绪承诺公式

> **书名 / 简介 = 明确情绪词 + 具体场景 + 结果预期**

- 反例（题材卖点）：“穿越到游戏世界的升级流小说”
- 正例（情绪承诺）：“穿越后我靠抄诗成了文坛至尊”（爽感 + 逆袭）

---

## 三、情绪提炼三问（锁定核心情绪）

1. **最爽 / 最燃的一次是什么？** —— 定位高潮情绪。
2. **最委屈 / 最虐的瞬间呢？** —— 定位反差情绪。
3. **读者凭什么点开并留下？** —— 定位承诺情绪（即书名简介要前置传递的那一下）。

---

## 四、卖点对比测试（同设定三版）

对同一设定生成 3 个不同情绪导向的书名 + 简介：

- **虐恋版** / **爽文版** / **喜剧版** → 选最贴核心且市场空位的一版，避免与同赛道撞脸。

## 五、修改工坊（逐句批改）

- **书名**：删「题材词」，留「情绪词 + 反差 + 身份」。
- **简介**：前三行抛核心冲突 + 金手指 + 打脸预期，像预告片钩子勾人。
- **自检**：把“这是一篇 XX 文”改写成“这能让你感到 XX”，通过即合格。

---

## 六、与现有链路联动

- 短篇：Phase 4 交付前强制「书名 / 简介情绪承诺自检」（题材词 → 情绪词改写），详见 `short-craft-guide.md` 情绪承诺小节。
- 长篇：作为通用成稿文案指引，书名 / 简介 / 文案前置传递情绪承诺，提升开篇吸引力与成稿质量。
