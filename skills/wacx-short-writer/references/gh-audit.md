# 模块六·G类+H类审计

> 本文件为 wacx-short-writer 主 SKILL.md 外移的详细规则，按需读取。

### G类人物行为合理性检测

#### 11项检测规则

| 检测项 | 说明（含判定示例） | 优先级 |
|--------|------------------|--------|
| 反应违背人性 | 角色面对危机/死亡/背叛时的反应不符合常人本能（如面对亲人被杀毫无情绪波动） | 🔴 |
| 情绪反应过度/不足 | 同一刺激下的情绪强度与正常人有严重偏差（如被当众羞辱后毫无反应） | 🟡 |
| 决策不合常理 | 角色做出明显不利于自身、且无合理动机支撑的重大决定 | 🔴 |
| 生理常识缺失 | 伤口反应、疲劳状态、饥饿、寒冷等生理需求被忽略（如寒冬单衣无反应） | 🟡 |
| 恐惧反应缺失 | 面对暴力/威胁时无应激反应（如刀架脖子不害怕） | 🔴 |
| **感官极限（P0）** | **角色看到/听到/感知到超出正常人类感官极限（如黑暗中看清百米外细节→❌、听清隔楼低语→❌；昏暗/中距下“瞳孔收缩”不可读→❌；手机屏幕背对自己/远处一瞥看清单个尾数→❌；“扔进主角身体里能感知的”才是合法描写）** ；示例：抬眼看清对面楼顶的人手里拿的东西；昏暗包厢隔桌读“瞳孔收缩”；进门一瞥看清妻子手机账户尾数 | 🔴 |
| **认知极限（P0）** | **角色展示出不符合其经历/教育/职业背景的知识（如古代农民懂现代化学→❌）** | 🔴 |
| **信息极限（P0）** | **角色知道其不应知道的信息（如知道未发生的事、预知剧情转折→❌）** | 🔴 |
| **体力极限（P0）** | **角色在重伤/极度疲劳后依然行动如常（如中刀后狂奔十公里→❌）** | 🔴 |
| **记忆合理性** | **对刚刚发生的事件立即遗忘（无解释）；或记住太多不可能的细节（数年前某人的一句话一字不差）** | 🟢 |
| **转场完整性（P0·新增）** | **相邻场景（不同时间/地点切换）必须有≥1句时空锚点过渡（如“走出法院大门，夜风灌进外套”标识从法院回到家）；禁止硬切→如直接写“回到家，她坐在沙发上”而无场景过渡** ；示例：法庭审判结束→下一段直接写“回到家”（缺时空锚点过渡）；Ch3办公室→Ch4海滩（无交通工具/时间交代） | 🔴 |

### 正常人性基准速查表（⭐⭐ P0最高优先）

| 场景类型 | 正常人应有反应 | ❌ 常见不合理写法 |
|---------|-------------|-------------|
| 面临致命威胁 | 恐惧、想跑、肾上腺素飙升 | 冷静得像没事儿 |
| 重伤/流血 | 剧痛、虚脱、意识模糊 | 打完架还能散步聊天 |
| 刚经历暴力场面 | 手抖、反胃、失眠 | 转头就睡得很香 |
| **远距离观察（P0）** | **肉眼看清数百米外细节需走近或借助望远镜** | **抬眼看清对面楼顶的人手里拿的东西** |
| **信息获取（P0）** | **角色只能知道亲眼所见/亲耳所闻/他人告知的信息** | **角色知道从未发生的事、读心、预知未来** |
| **认知边界（P0）** | **角色的知识只能来自经历/教育/职业背景** | **古代人脱口而出现代术语** |
| **体力极限（P0）** | **受伤后体力下降、流血后虚弱、重伤不可能行动如常** | **中弹后继续跑十公里** |
| **超距离听觉（P0）** | **正常听力范围≈20米内普通对话，隔墙/隔楼的对话只能听到模糊声响** | **听清隔壁房间的低语、听到楼下三层的电话内容** |
| **微表情可读性（P0·新增）** | **昏暗/中距下“瞳孔收缩”不可读，“眼神一紧”级大表情可读；清晰光线+近距离(≤3米)可辨“瞳孔收缩/嘴角抽动”等微表情** | **昏暗包厢隔桌看清“瞳孔收缩”；弱光下描写“瞳孔放大→不可读”，应改“眼神一紧/目光一沉”** |
| **屏幕/文本可读性（P0·新增）** | **手机明文须朝向主角+足够近(≤1米)+有意识扫视才可读；屏幕朝外/一瞥看清账户尾数/背对屏幕→不可读** | **进门一瞥看清妻子手机账户尾数；主角背后屏幕亮起看到密码→不可读** |
| **预知行为（P0）** | **角色无法提前知道尚未发生的事件结果；会基于已知信息推测，但不确定** | **角色笃定“他一定会来”（无线索支撑）、提前知道陷阱在哪里** |
| **亲友背叛（P0）** | **震惊→愤怒/悲伤→决断** | **笑笑就过去了** |
| **被当众羞辱（P0）** | **愤怒/尴尬/反击冲动** | **毫无反应或过度理智** |
| **重大好消息/坏消息（P0）** | **兴奋→不敢相信→狂喜 / 否认→痛苦→接受** | **平淡如水 / 立即“消化”继续干活** |
| **长时间未进食/缺水（P0）** | **虚弱、注意力下降** | **毫无影响** |

### G+ 心理动机与因果链审计（⭐⭐ 新增·直击“剧情逻辑经不起推敲”）

> **核心理念**：G类覆盖“角色能不能做某事”（物理/信息/认知边界），但没覆盖“角色为什么会做某事”（心理动机）和“这件事为什么会发生”（情节因果）。  
> G+ 填补的是**软逻辑**——动机合理性、因果链完整度、人情世故真实性。  
> 执行时机：Phase 3 H类审计之后、十维评分之前，与H类并行执行。

#### G+ ① 心理动机合理性

| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| **动机→行为断裂** | 角色做了某件事，但前文没有建立足够动机（如一个谨慎人突然冒险潜入敌营，仅因为“好奇”） | 🔴 |
| **行为→后果缺失** | 角色做了关键行为，但后文没有展示该行为的必然后果（如主角撕毁合同，但后续无人追究） | 🔴 |
| **情绪开关缺失** | 角色情绪转变缺少触发事件（从愤怒→平静无过渡/无解释） | 🟡 |
| **动机强度失配** | 动机的强度与行为风险不成比例（为了50块钱赌命→❌；为了救孩子赌命→✅） | 🔴 |
| **选择空间不足** | 角色只有“做”或“不做”，没有“还有别的办法吗？”的思考过程 | 🟡 |

**通过标准**：无🔴项、🟡项≤1 → 心理动机合理性通过

#### G+ ② 因果链合理性

| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| **缺失中间环节** | A→C跳过了B（如“主角发现线索→立即知道凶手是谁”，中间缺少推理/查证/确认环节） | 🔴 |
| **因果倒置** | 把结果当成原因（如“因为他死了，所以他被杀”——死亡是结果不是原因） | 🔴 |
| **巧合过密** | 关键转折依赖偶然事件（连续2个关键转折靠偶遇/巧合完成） | 🟡 |
| **伏笔未回收** | 前文埋下的设定/物品/对话，到结尾未使用也未解释 | 🟡 |
| **情节合理性三问** | 逐段问：①这段剧情为什么发生？②为什么是现在发生？③为什么以这种方式发生？任一问无法回答→标记🔴 | 🔴 |

**通过标准**：无🔴项、🟡项≤2 → 因果链合理性通过

#### G+ ③ 社会情理合理性（中国本土）

| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| **关系面子失衡** | 角色在公开场合的言行不符合中国社会“给面子/留面子”的基本规则（如当众揭短后对方毫无反应） | 🔴 |
| **人情伦理跳跃** | 亲属/朋友/同事之间的互动跳跃了必要的人情环节（如多年仇人突然帮忙，没有任何中间台阶） | 🔴 |
| **组织行为失真** | 公司/学校/机关内部的权力关系和决策流程不符合实际（如实习生直接向CEO汇报→❌） | 🟡 |
| **时代背景硬伤** | 角色言行/消费/社会关系不符合设定时代的社会环境（如2010年农村老太太用手机看短视频→❌） | 🔴 |

**通过标准**：无🔴项、🟡项≤1 → 社会情理合理性通过

#### G+ 审计执行方式

**Phase 3 中与H类审计并行执行**：
1. 通读全卷，标记所有角色关键行为点
2. 对每个关键行为问：动机→行为→后果 是否完整？
3. 对每个关键情节转折问：原因→时机→方式 三问是否通过？
4. 对涉及社会互动的场景问：符合中国本土人情世故吗？
5. 输出「G+心理动机与因果链审计报告」
6. 🔴问题必须修复后进入十维评分；🟡问题标记为Phase 3 P0修复项

### H类·全卷逻辑一致性审计（⭐⭐ 横向跨章——补十维评分盲区）

> **核心理念**：十维评分是“纵向打分”（单章 vs 标准），不是“横向审计”（全卷 vs 全卷）。  
> 短篇因篇幅短、因果链紧密，跨章矛盾比长篇更致命——读者在10章内就会注意到时间线撞车或信息源漂移。  
> **这些跨章问题十维评分一个也发现不了。本审计专门补这个洞。**

### 三大审计动作（固定执行，不可省略）

**审计动作一：提取完整时间线**
```
1. 通读全卷所有章节，提取每一个带时间词的事件：
   - 绝对时间：日期/钟点/时刻
   - 相对时间：今天/明天/昨天/三天后
   - 时序关系：之后/同时/在此之前/三小时后
2. 构建全卷时间线图谱 → 逐项检查矛盾：
   🔴 同一时刻角色出现在两地
   🔴 相对时间自相矛盾（“三天前”←→实际只隔了一章）
   🔴 时间跨度不合理（几小时内发生太多事/几天无事发生）
   🔴 昼夜颠倒（白天→黑夜无过渡）
3. 输出「全卷时间线一致性报告」
```

**审计动作二：提取信息事实表**
```
1. 通读全卷，提取每个关键事实的完整信息链：
   | 事实ID | 事实内容 | 首次出现(章/场景) | 信息源交代 | 后续引用(章) | 引用时交代的信息源 | 一致？ |
   |--------|---------|----------------|-----------|------------|----------------|------|
   | F001 | 对手秘密 | Ch3/监听 | 电话录音 | Ch5/内心 | “自己想起” | ❌ |
2. 逐项检查：
   🔴 信息源不一致（同一事实不同章节来源不同）
   🔴 信息源缺失（角色知道不应知道的信息）
   🔴 信息质量矛盾（前文“猜测”，后文当“事实”用）
   🔴 信息遗忘（前文明确告知，后文角色忘了）
3. 输出「全卷事实一致性报告」
```

**审计动作三：常识通读（纯读者视角）——逐段执行4项具体检测**
```
1. 不看评分标准、不管字数限制、无视禁词列表
2. 从头到尾通读全卷，逐段执行以下4项检测（每段至少过1项，标记🔴/🟡）：
   a) 逻辑自洽检测（原“这段像话吗？”）
      - 事件A→事件B的因果链条中是否缺少中间环节？
      - 角色在该场景下的行为是否符合此前建立的人设？
      - 关键情节点是否有“凑巧/正好/刚巧”等巧合依赖？
      🔴标准：连续2个关键情节依赖巧合；角色行为与人设矛盾且无交代
   b) 直觉反应检测（原“这里怪怪的？”）
      - 读到这里有没有“诶？不对吧”的第一反应？
      - 某个细节是否让你觉得作者在“硬推剧情”？
      - 有没有一段话的信息量过大/过小，与上下文节奏不匹配？
      🔴标准：≥3处直觉不适（晕染/重复/突兀转换）；或≥1处“硬推剧情”（角色做不符合人设的事只为推动情节）
   c) 一致性检测（原“两个地方说的是一回事吗？”）
      - Ch1和Ch5对同一角色的外貌/性格/背景描述是否一致？
      - 前后文对同一事件的描述在细节、情绪、信息量上是否匹配？
      - 固定搭配/招牌动作/标志性物品是否在中途消失后又被提起？
      - **跨段同义复述检测**：相邻/跨段是否用不同措辞讲同一事件、同一反思、同一结论（如某段“八年”权衡在另一段以另一种说法重写一遍）→ 属改写式复述，成稿审阅不达标高频点
      🔴标准：同一事物前后描述矛盾；固定搭配中途消失且无交代；**跨段同义复述（不同措辞重复同一信息）**
   d) 隐性断层检测（原“特别关注”）
      - 时间黑洞：两幕之间是否有大段时间空白且无合理填充？
      - 信息bug：角色知道之前绝对不可能知道的信息？
      - 因果跳过：A直接到C，丢失了B（“发现线索→立即知道凶手”缺推理过程）
      - 设定漂移：前文确定的设定（规则/能力/关系）在后文被修改而无解释
      🔴标准：任一隐性断层存在即标记🔴
3. 输出「常识通读报告」（格式：段落号+检测项+🔴/🟡+具体描述）
```

### 审计执行时机

| 执行时机 | 方式 | 说明 |
|---------|------|------|
| **Phase 3 启动前（强制）** | **全卷通读** | 进入十维评分之前必须先跑完全卷审计并修复🔴矛盾 |
| Phase 4 交付前（复审） | 全卷通读 | 最后一次确认无横向矛盾 |

> **铁律**：Phase 3开始时，必须先执行全卷逻辑一致性审计并修复🔴矛盾，才能进入十维评分。
