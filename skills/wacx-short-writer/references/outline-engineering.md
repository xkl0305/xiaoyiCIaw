# 细纲生成与章节仿写工程（短篇版）

> 核心定位：细纲是把故事蓝图翻译成每日可执行指令的作战层。它以读者情绪为第一资产，用循环模板稳定结构，用情绪账本控制心跳，用章纲陪练消灭卡文。短篇细纲追求一张纸成型，起承转合点位钉死，情绪波形完整，写完即能开写。

## 一、细纲生成最佳实践

### 1.1 细纲必备六要素

每一个剧情单元（短篇中的一幕或一节）都应覆盖六个要素：

1. 场景目标：这一幕推进什么，主角要拿到什么具体结果。示例：主角在拍卖会上必须抢到那枚旧玉。
2. 冲突：谁与谁在较劲，靠哪种差值发力（阶级差、信息差、情感差）。示例：对手当众嘲笑他穷酸，他手里握着对方买不起的底牌。
3. 情绪节拍：读者在这一幕的情绪起点、拐点与落点。示例：从被羞辱的憋屈，走到揭底后的震惊。
4. 信息释放：这一幕放出的新信息与埋下的新雷。示例：放出“旧玉与主角身世有关”的半句线索。
5. 钩子：幕末留给读者的“然后呢”痒点。示例：侍者附耳一句“有人出十倍价截胡”，主角脸色骤变。
6. 人物弧光：至少一处性格呈现或转变。示例：主角赢了竞价后，反而把玉递还给了对手。

### 1.2 细纲的合理粒度

短篇细纲以“一张纸”为上限：

1. 全篇规划6-10个剧情点，每个剧情点用一句“场景+动机+行为+意外结果”概括。
2. 细纲只写做什么、为什么做、结果如何，不写对话与完整描写。
3. 粒度检验标准：看细纲能否在两分钟内讲完整篇，且讲得出情绪走向。能讲完，粒度就合适。
4. 一句话锁定核心矛盾，防止跑偏。示例：“主角必须在一炷香内证明自己是真少主，否则家产归养子”。

## 二、细纲与正文的关系：弹性施工图

细纲同时承担施工图与弹性框架两种职能，关键是分清写死与留活：

1. 写死的部分（约四成）：主线锚点、情绪峰值、幕末钩子、信息差埋设点、付费点位置、核心反转。
2. 留活的部分（约六成）：过渡叙述、对话细节、环境描写、次要角色的展开方式、临场的即兴发挥。
3. 操作原则：写死骨架保证不散，留活血肉保证正文有惊喜。正文动笔时若人物自然走向偏离细纲，优先跟随人物，回头修订细纲。
4. 比例自检：细纲细到能复述情绪，粗到给正文留出三成未知。大纲管方向，正文管沿途的捡拾。

## 三、情绪记账法

### 3.1 三本账

1. 情绪债权账：开篇第一幕就给主角记一笔终极委屈，越具体、越羞辱、越无回旋余地，读者入戏的押金越足。示例：婚礼当天，新郎当众宣布她只配当妾。
2. 打脸清单账：四列表格，分别是仇人姓名、侮辱事件、打脸方式、围观者反应。主角翻身之后，必须写围观者的身体动作、表情变化与漏嘴的话。
3. 情绪曲线账：为每一幕记录读者情绪值（-5到+5）、爽点位置、压抑与释放的节奏，防止开篇即高潮或一平到底。

### 3.2 记账驱动细纲的做法

1. 落笔前先画单篇情绪波形图，标出最高峰的位置，再倒推每一幕的走向，让所有小反转服务于大情绪。
2. 用321公式检查节奏：每3幕一个小爽点，冲突解决过程有2次拉扯，过渡叙述不超过1幕。
3. 压抑与释放的比例控制在四比六，开篇压抑越狠，中后段的释放越爽。
4. 账本复盘：写完觉得平淡，就回看每一幕，把曾经看不起主角的人塞回关键场面，让他亲眼见证打脸。

## 四、章节仿写工程

### 4.1 完整五步流程

1. 原章节精准拆解：通读原文三遍，标记情绪节点，提炼核心情绪（不超过10字）并做反向验证（删掉对应情节后章节是否失去吸引力）。示例：核心情绪定为“被轻视后的屈辱感”。
2. 五维结构拆解：逐维度分析原章节，每一维都要有原文片段对应。
3. 可复用公式提炼：把结构抽象为不含具体元素的“如果…那么…”公式，变量用方括号标注，全公式控制在100字内。
4. 结构移植：把原章节核心元素（场景、道具、权力体系、冲突类型）一对一替换为自有设定，验证动机、冲突逻辑、情绪内核保持一致。
5. 创新注入与合规审查：至少添加1个独家变量，随后做合规自查与效果优化。

### 4.2 五维结构

1. 开篇钩子：本章开场类型（危机、悬念、反差）与作用。
2. 情节节奏：起承转合边界、冲突引入点、3个以内小爽点、章末钩子位置。
3. 人设展现：每个出场人物通过什么事件、对话、行为强化了什么性格标签。
4. 金手指运用：能力的具体表现、解决的问题、产生的效果。
5. 情绪曲线：按时间顺序标记5-8个读者情绪变化节点。

### 4.3 独家变量三选一

1. 视角变量：把某段关键情节改为旁观者或反派视角。
2. 规则变量：为金手指加一个符合世界观的独特代价。示例：读心术每天只能用三句。
3. 意外变量：在高潮处插入一个符合设定的意外转折。

### 4.4 仿写与抄袭的边界检查清单

| 检查维度 | 自查问题 | 风险等级 |
| --- | --- | --- |
| 转折顺序 | 具体剧情转折顺序是否与原章节完全一致 | 低/中/高 |
| 关系逻辑 | 人物关系发展逻辑是否高度雷同 | 低/中/高 |
| 标志描写 | 是否直接照搬或高度相似的标志性描写 | 低/中/高 |

1. 三个维度任一项判为高风险，立即暂停修改，改后重新自查。
2. 通过标准：结构可复用、元素已换皮、情绪内核一致、独家变量生效、读者无法倒推出原书。

## 五、剧情推演与公式

### 5.1 剧情公式拆解

1. 通用公式：爆款剧情 =（人物 + 背景 + 契机 + 行动）× 核心吸引力。人物回答“谁”，背景回答“什么环境”，契机回答“什么转折事件”，行动回答“人物因此做了什么”。
2. 核心吸引力是贯穿并放大四元素的钩子。同样的退婚契机，核心吸引力不同，故事走向就不同。
3. 细纲应用步骤：先拆解一篇爆款得到公式骨架，再定位其核心吸引力，最后把自有元素填入骨架并保留或强化吸引力。

### 5.2 剧情循环公式的细纲应用

“危机-能力-解决-震惊-收获”五步循环是基础单元：

1. 短篇通常只走1-2个完整循环，把五步压缩到单篇内部，一章之内见分晓。
2. 示例分配：开头两幕制造危机与展示能力，第三幕遭遇挫折落入情绪低点，第四幕全力解决、震惊全场、收获奖励，末段埋下续篇钩子。
3. 循环收尾必须留一个开放口子，方便系列化续写。

### 5.3 三番四震的细纲标注

1. 原理：让同一类情绪或事件平行重复三次，第四次发生反转或强度陡增，利用读者的模式预期制造意外与爽感。
2. 应用前提：必须紧扣七情六欲，落脚点必须是人物之间情感关系的剧烈变化。
3. 细纲标注方法：在细纲中用“番1、番2、番3、震”标注。示例：主角三次登门求助都被彬彬有礼地拒绝（番1-3），第四次登门时对方突然跪下求主角帮忙（震）。
4. 配合情绪曲线账使用，把“震”点标注在情绪峰值处。

## 六、章纲陪练法

### 6.1 章纲三要素与情绪线

每章章纲只记四样东西：开头（快速进入情境的方式）、高潮（本章核心事件与爆点）、钩子（结尾痒点）、情绪线（情绪的流动轨迹）。

### 6.2 写作前5-10分钟口头推演

1. 动笔前不看稿纸，用口述把本章过一遍：开头从哪切入，高潮在哪个动作上，钩子落在哪句话。
2. 自问自答式拷问，答不上来就停笔改细纲。三个必问：本章的读者情绪是什么？冲突双方是谁在较劲？章末读者会好奇什么？
3. 写前看昨日：先复述上一章的结尾，保证情绪与信息衔接。写后谋下两章：当日收笔前把下两章的章纲要点写下来。
4. 五分钟推演的价值：把卡文消灭在细纲阶段，正文只负责把推演过的场景写活。

## 七、短篇细纲快速成型要点

1. 一张纸规划：按起承转合四段划分全篇，每段写三五行，整篇细纲不超过一页。
2. 起（约占一成）：开篇200字内抛出重磅开局（重生、退婚、捉奸等），直接进入冲突现场，把情绪债权第一时间记下。
3. 承（约占四成）：用一个剧情循环做骨架，逐步展示能力与信息差，埋下反转所需的所有细节。
4. 转（约占三成）：在全文30%-50%处设付费点钩子，把主角置于“真相即将揭晓”的临界点后戛然而止。
5. 合（约占两成）：反转收束，情绪释放，末句留余味或续篇钩子。
6. 情绪波形自检：按起-扬-抑-爆-余核对每一幕的情绪值，保证波形完整，杜绝一路平铺。
