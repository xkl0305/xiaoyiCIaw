# 宠物环境监控

## 技能说明

本技能用于监控宠物生活环境，重点关注：
- 室内温度（超过26°C时提醒）
- 室内湿度
- 空调联动建议

---

## 功能一：温度监控查询

### 功能说明

获取室内温湿度数据，判断温度是否异常，提供空调联动建议。

### 执行命令

```bash
node default-spec-skill/pet-care/bin/temperature-monitor.js
```

### 返回字段说明

| 字段 | 说明 |
|------|------|
| value | 温度值（°C） |
| humidity | 湿度值（%） |
| source | 数据来源（温湿度传感器/空调） |
| status | 状态（normal/abnormal/unavailable） |
| isAbnormal | 是否异常（>26°C） |
| shouldTurnOnAc | 是否应该开空调 |
| acSuggestion.deviceName | 建议开启的空调名称 |
| acSuggestion.suggestedTemp | 建议温度 |
| acSuggestion.reason | 建议原因 |

### 温度异常阈值

| 阈值 | 说明 |
|------|------|
| > 26°C | 温度偏高，建议降温 |
| 10-26°C | 温度适宜 |
| < 10°C | 温度偏低（宠物怕冷） |

---

## 功能二：空调联动

### 功能说明

当温度异常时，提供空调控制建议，用户确认后可远程开启空调。

### 联动流程

1. 检测到温度 > 26°C
2. 在简报中提示温度偏高
3. 用户确认后调用 `control_device` 开启空调
4. 设置目标温度为 26°C

---

## 触发示例

- "家里温度多少"
- "要不要开空调"
- "热不热"
- "温度正常吗"

---

## 回复示例

温度正常：
```
🌡️ 室内温度：24°C，湿度60%
✅ 温度适宜，宠物生活舒适
```

温度异常：
```
🌡️ 室内温度：28.5°C
⚠️ 温度偏高，宝贝可能觉得热了

💡 建议开启客厅空调，设置温度26°C
```

---

## 数据来源优先级

1. **温湿度传感器** - 数据最准确
2. **空调内置温度传感器** - 作为备用

如果都没有，则返回"温度数据暂不可用"。
