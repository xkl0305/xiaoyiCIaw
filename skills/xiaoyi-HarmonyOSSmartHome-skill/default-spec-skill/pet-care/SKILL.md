# 宠物照护技能

## 技能说明

本技能用于宠物日常养护的智能管理，当主人不在家时能随时了解宠物的生活状态。

---

## 子技能路由

本技能包含以下子技能，根据用户请求路由到对应的子技能：

| 子技能 | 触发关键词 | 说明 |
|--------|------------|------|
| [pet-status](pet_status/SKILL.md) | 宠物怎么样、猫砂盆、喂食器 | 宠物状态全景查询 |
| [pet-feeder](pet_feeder/SKILL.md) | 喂一下、喂食、出粮 | 手动喂食控制 |
| [pet-brief](pet_brief/SKILL.md) | 宠物简报、宠物报告 | 宠物环境简报生成 |
| [pet-environment](pet_environment/SKILL.md) | 温度、热、空调 | 环境监控与联动 |

---

## 主入口调度

所有功能通过统一的 CLI 入口调用：

```bash
node default-spec-skill/pet-care/bin/pet-care-claw.js <command>
```

### 可用命令

| 命令 | 说明 |
|------|------|
| `get_pet_status` | 获取宠物状态全景 |
| `get_pet_devices` | 获取宠物设备列表 |
| `control_feeder` | 远程触发喂食 |
| `get_pet_brief` | 生成宠物环境简报 |
| `get_pet_care_data` | 获取宠物照护全量数据 |

## 支持能力清单

### 1. 宠物状态全景查询
- 获取家中宠物相关设备（猫砂盆、喂食器）的综合状态
- 查询猫砂盆今日使用次数和最后使用时间
- 查询喂食器今日出粮次数和最后出粮时间
- 获取室内当前温度和湿度
- 获取宠物大致位置（通过摄像头或定位设备）

### 2. 温度监控与提醒
- 实时监控室内温度
- 当温度超过26°C时主动提醒
- 提供空调联动建议

### 3. 手动喂食控制
- 远程手动触发喂食器出粮
- 支持指定出粮量
- 返回喂食结果

### 4. 宠物环境简报
- 当主人不在家时，生成宠物生活环境简报
- 包含温度、喂食、猫砂盆使用等综合状态
- 提供异常提醒和改善建议

---

## 不支持能力清单

- ❌ 宠物健康诊断（需要兽医专业知识）
- ❌ 宠物视频监控和双向语音（使用摄像头技能）
- ❌ 宠物自动饮水机控制
- ❌ 宠物定位设备的地图展示
- ❌ 定时自动喂食计划

## 温度异常处理流程

当检测到温度超过26°C时：

1. 在返回结果中标记 `isAbnormal: true`
2. 提供 `shouldTurnOnAc: true` 标志
3. 在 `acSuggestion` 中提供空调控制建议
4. 用户确认后，调用 `control_device` 开启空调

---

## 注意事项

1. **设备识别**：宠物设备通过 prodId 关键字识别（如含"litter"、"feeder"等）
2. **数据延迟**：设备快照数据可能有延迟，精确定时状态使用 `control_device (GET)`
3. **离线处理**：设备离线时返回提示，不执行控制操作
4. **多设备支持**：支持多个同类型设备，默认选择第一个
5. **隐私保护**：禁止向用户暴露设备ID等敏感信息
