# 宠物环境简报

## 技能说明

本技能生成宠物独处时的生活环境简报，以温情的方式汇报：
- 猫砂盆使用情况
- 喂食器喂食情况
- 室内温湿度状态
- 宠物位置（如可获取）
- 异常提醒和改善建议

---

## 功能一：生成宠物环境简报

### 功能说明

当主人不在家时，自动生成宠物生活环境简报，帮助主人了解宠物独自在家的情况。

### 执行命令

```bash
node default-spec-skill/pet-care/bin/pet-care-claw.js get_pet_brief
```

### 返回字段说明

JS文件返回的原始数据字段：

| 字段 | 说明 |
|------|------|
| summaryPrefix | 简报摘要前缀（如"主人外出期间"） |
| isOwnerAway | 主人是否不在家 |
| catLitter | 猫砂盆状态数据 |
| feeder | 喂食器状态数据 |
| temperature | 温度状态数据 |
| petLocation | 宠物位置数据 |
| alerts | 告警类型列表 |
| suggestions | 建议类型列表 |
| generatedAt | 生成时间 |

### 告警类型 → 描述文本映射

JS文件返回 `alerts` 数组，值为告警类型代码，需映射为温情化描述文本：

| 告警类型 | 触发条件 | 温情化描述 |
|----------|----------|------------|
| TEMP_ABNORMAL | 室内温度 > 26°C | 室内温度{value}°C，超过26°C，宝贝可能觉得热了 |
| CAT_LITTER_OFFLINE | 猫砂盆离线 | {deviceName}离线了，无法监测使用情况 |
| FEEDER_OFFLINE | 喂食器离线 | {deviceName}离线了，有事在外也能远程喂食哦 |
| CAT_LITTER_NOT_USED | 猫砂盆今日未使用 | 猫砂盆今日未使用，可以留意下毛孩子的状态 |
| NOT_FED | 今日尚未喂食 | 今日尚未喂食，记得检查下喂食器 |

### 建议类型 → 描述文本映射

JS文件返回 `suggestions` 数组，值为建议类型代码，需映射为温情化描述文本：

| 建议类型 | 触发条件 | 温情化描述 |
|----------|----------|------------|
| TURN_ON_AC | 温度 > 26°C | 建议开启{deviceName}，设置温度{temp}°C，让毛孩子凉快些 |
| LOW_FEED_COUNT | 喂食次数 < 1次/天 | 喂食次数偏少，可以考虑手动补喂一下 |

### 状态数据 → 描述文本映射

| 数据类型 | 字段 | 描述逻辑 |
|----------|------|----------|
| 猫砂盆 | online=false | {deviceName}当前离线 |
| 猫砂盆 | useCount=0 | {deviceName}今日尚未使用，记得观察下毛孩子是否正常 |
| 猫砂盆 | useCount>0 | {deviceName}今日已使用{useCount}次 |
| 喂食器 | online=false | {deviceName}当前离线 |
| 喂食器 | feedCount=0 | {deviceName}今日尚未喂食 |
| 喂食器 | feedCount>0 | {deviceName}今日已喂食{feedCount}次，最近一次是{lastFeedTime} |
| 温度 | isAbnormal=true | 室内温度{value}°C，湿度{humidity}%，温度偏高 |
| 温度 | isAbnormal=false | 室内温度{value}°C，湿度{humidity}%，温度适宜 |
| 宠物位置 | 有数据 | 毛孩子现在{location}休息 |
| 宠物位置 | 无数据或离线 | （不显示） |

## 简报组装规则（温情化）

### 1. 内容优先级

告警信息 > 状态详情 > 改善建议

### 2. 无数据则忽略

- 没有告警类型 → 不显示告警模块
- 没有状态数据 → 不显示该状态项
- 没有建议类型 → 不显示建议模块

### 3. 温情化表达

- 称谓：使用"毛孩子"、"宝贝"
- 语气：温柔、关怀、自然
- 避免：直接罗列技术参数、生硬描述

### 4. 格式化输出示例

```
🐾 宠物环境简报
════════════════════════════════════════
生成时间：1月15日 15:00

主人外出期间，宠物生活情况如下：

⚠️ 室内温度28.5°C，超过26°C，宝贝可能觉得热了

• 智能猫砂盆今日已使用3次
• 智能喂食器今日已喂食2次，最近一次是08:00
• 室内温度28.5°C，湿度65%，温度偏高
• 毛孩子现在客厅沙发休息

💡 建议开启客厅空调，设置温度26°C，让毛孩子凉快些

════════════════════════════════════════
```

### 5. 语音播报格式化

提醒：{告警描述1}。提醒：{告警描述2}。
状态：{状态1}。{状态2}。{状态3}。
建议：{建议1}。

## 与家庭简报的区别

| 对比项 | 家庭简报 | 宠物环境简报 |
|--------|----------|--------------|
| 关注对象 | 全家成员 | 宠物 |
| 重点数据 | 安防、能耗、环境 | 猫砂盆、喂食、温度 |
| 特色功能 | 家人动态 | 宠物位置 |
| 称呼 | - | 毛孩子、宝贝 |
