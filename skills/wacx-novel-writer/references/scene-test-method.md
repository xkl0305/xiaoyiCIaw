# 场景测试法（人物反应卡+五大高压测试场）

> 本文件为深度扩展，按需读取。适用：角色行为推演、剧情自然生成、防人设崩塌、卡文破局，长短篇通用。核心主张：剧情不是编出来的，是角色在高压下自己走出来的。

## 一、核心认知：让角色替你写剧情

写作者常犯的错是把角色当作剧情提线木偶——先定情节，再让角色硬演，结果生硬、失真、人设崩塌。场景测试法反其道而行：先锁定角色的内核与应激模式（人物反应卡），再把角色投入设计好的高压场景，观察他的必然反应，角色的反应（选择/对话/失控）自然产生冲突与转折，直接转化为正文。

## 二、前置工具：人物反应卡（四项设定）

写任何主要角色前先填卡，这是防人设崩塌的紧箍咒：
- **致命标签**：角色最核心的性格烙印（一句话，如“宁折不弯的赌徒”）
- **底线**：绝不可触碰的原则（碰了会暴走）
- **软肋**：一碰就痛的弱点（最容易被利用的缝隙）
- **惯用手段**：应对危机的本能反应（第一反应是逃、是战、还是算计？）

## 三、五大高压测试场

把角色依次投入以下场景，观察其必然反应，测试结果即剧情：

1. **诱惑场**——测试“标尺”与底线。诱惑要大到读者都会动摇，看角色如何守住或突破。守住显品格，突破显真实。
2. **羞辱场**——测试“面质结构”与“施控方式”。适合爽文，看角色如何应对当众践踏并反击：是隐忍布局、当场翻脸，还是用更高明的方式反杀？
3. **两难场**——测试“软肋”与“期盼”。选项要痛且合理、代价延迟爆炸，逼角色在珍惜之物间做残酷抉择。
4. **失控场**——测试“立体性”。失控点必须紧扣“致命标签”：让失控既意外又必然。一个永远冷静的人，只有在触碰底线时才会失控——这才是立体。
5. **无人作证场**——测试“真实动机”。剥离社会目光，看角色在没有观众时的本真反应，防止角色沦为“表演型人格”（只在别人面前做好事）。

## 四、应用流程

1. 构建人物反应卡，锁定角色内核
2. 按当前剧情节点选用适配的高压场景（组合使用亦可）
3. 推演角色反应：他会选什么？说什么？在哪里失控？哪里口是心非？
4. 将测试结果按篇章落位到正文，剧情自然流淌，避免硬编

## 五、自查清单（角色行为/剧情转折交付前）

- □ 角色是否有人物反应卡（致命标签/底线/软肋/惯用手段）？
- □ 关键转折是否源于角色在压力下的必然反应（而非作者硬推）？
- □ 角色失控是否紧扣致命标签（既意外又必然）？
- □ 是否有无人作证场景检验角色的真实动机（防表演型人格）？
- □ 诱惑/羞辱/两难场景是否“痛且合理”（不廉价）？
