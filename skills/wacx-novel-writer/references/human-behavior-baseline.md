# 人类行为基准参考手册（normal human behavior baseline）

> **用途**：在小说写作中判断角色行为是否符合正常人类能力边界。除非有明确的超能力/异能/魔法设定支撑，角色不得突破以下描述的人类天然能力上限。
> **加载时机**：Phase 2 每章写作前的S15.5逻辑审计、Phase 3 A2.5逻辑审计、以及G类检测项自查时。
> **优先级**：⭐⭐ P0最高优先——角色行为合理性高于爽点/情绪承诺/字数/钩子。

---

## 一、感官能力边界（Sensory Limits）

### 视觉

| 情景 | 正常人极限 | ❌ 小说中常见不合理 |
|------|-----------|-------------------|
| 白天看清人脸细节 | 50-100米内可辨认熟人面孔 | “抬眼看清百米外楼下那人袖口的纽扣” |
| 白天看清文字 | 10-20米内可读招牌大字 | “看清对面楼顶广告牌上的小字” |
| 夜间看清事物 | 仅能辨认轮廓（满月下≈10米内模糊人影） | “夜色中看清对方表情”“月光下数清对方的睫毛” |
| 透过障碍物 | 不可穿透 | “隔着窗帘看清屋内”“透过树林看到几百米外” |
| 运动中看清高速物体 | 无法看清子弹/箭矢轨迹 | “眼看对方一刀砍来，侧身避开”（真能看清不会中刀） |
| 黑暗适应 | 入暗室需10-30秒逐渐适应 | “从强光下冲入暗室，立即看清一切” |

### 听觉

| 情景 | 正常人极限 | ❌ 常见不合理 |
|------|-----------|-------------|
| 安静环境对话 | 正常说话≈20米内可听清 | — |
| 嘈杂环境对话 | 3-5米内勉强听清 | “在集市/战场上听清远处低语” |
| 隔墙听音 | 隔墙只能听模糊声响，听不清字句 | “隔着两堵墙听清屋内的对话内容” |
| 楼下听楼上 | 只能听脚步/家具响动，“听清说话内容”几乎不可能 | “楼下的人听清了三楼房间里的对话” |
| 长距离听力 | 100米外基本听不清普通声量的说话声 | “百米外听到对方的自言自语” |
| 剧烈运动中听力 | 风声/脚步声干扰，听力大幅下降 | “奔跑中头也不回地听清身后二十米外的低语” |

### 嗅觉/触觉/味觉

| 情景 | 正常人极限 | ❌ 常见不合理 |
|------|-----------|-------------|
| 远距离嗅觉 | 正常情况下3-5米可闻到明显气味 | “数十米外闻到对方身上的香皂味” |
| 精确触觉辨析 | 指尖可辨材质细节 | “隔着手套摸出纸上写了什么字” |
| 味觉辨析 | 可分辨酸甜苦辣咸 | “尝一口就知道用了哪一年的陈皮”（除非是专业品鉴师设定） |

## 二、认知能力边界（Cognitive Limits）

### 知识来源

| 原则 | 说明 | ❌ 常见不合理 |
|------|------|-------------|
| **知识必须来源合理** | 角色的所有知识必须来自其亲身经历、所受教育、工作背景或他人告知 | “一个唐朝农民突然冒出来一句现代化学术语” |
| **时代限制** | 角色不能知道其所在时代尚未发现/发明的知识 | “古代人说'细菌''病毒''DNA'” |
| **职业限制** | 角色不能掌握其职业领域之外的深度专业知识，除非有合理涉猎交代 | “一个县城小贩精通国际政治和地缘战略” |
| **教育限制** | 没上过学的角色不应该有系统的学术知识 | “文盲角色引用古文或专业法律条文” |
| **语言限制** | 角色不会知道其从未学过的语言 | “中国乡村老大爷突然能听懂日语” |

### 推理能力

| 原则 | 说明 | ❌ 常见不合理 |
|------|------|-------------|
| **推理需基于已知信息** | 角色只能基于现场证据和自身知识推理 | “仅凭一句模棱两可的话就推断出完整阴谋” |
| **推理结果允许错误** | 正常人的推理不一定对，会自疑、会推翻 | “永远百分之百正确的直觉推断” |
| **专业推理需要专业知识** | 刑侦/医学/工程等专业推理需要对应的背景知识 | “普通人看一眼就知道了法医鉴定结果” |

## 三、信息边界（Information Limits）

### 不可获取的信息类型

| 信息类型 | 说明 | ❌ 常见不合理 |
|---------|------|-------------|
| **上帝视角** | 角色不知道其他地点正在发生的事情 | “主角在A城知道了B城密室里的对话” |
| **读心术（无设定）** | 角色不知道别人的内心想法 | “他看她的眼神就知道她在想什么”（读心） |
| **预知（无设定）** | 角色不能提前知道尚未发生的事件 | “他预感到明天会出事”——如果事件真发生了，这是预知，需设定支撑 |
| **全知全能** | 角色不能在没有信息源的情况下知道任何未参与的事情 | 主角知道反派的所有计划（无线索支撑） |
| **隔空信息** | 角色不能获得其物理距离之外、无人传递的信息 | “他在千里之外知道了家乡发生的事”（除非有电报/电话/通信且已交代） |

### 信息获取的合理路径

```
信息获取方式矩阵：
角色获得一条信息 → 必须有明确的源头
├→ 亲眼所见（需满足视觉条件：距离、光线、障碍物）
├→ 亲耳所闻（需满足听觉条件：距离、噪音、遮挡）
├→ 他人告知（需交代是谁、何时、何地、为何告知）
├→ 书面来源（书信/文件/报纸——需交代如何获得该书面材料）
├→ 亲身经历（角色在过去亲身经历过）
├→ 推理得出（需交代推理的前提条件和推理过程）
└→ 违反以上任意一条 → G类·信息极限违规 🔴
```

## 四、体力与生理边界（Physical Limits）

### 受伤后的合理反应

| 伤势程度 | 正常人应有反应 | ❌ 常见不合理 |
|---------|-------------|-------------|
| 轻伤（划伤/擦伤） | 疼痛、流血、包扎后可以继续行动但受影响 | — |
| 中度伤（刀伤/撞击） | 剧痛、大量流血、行动受限、可能晕眩 | “中了一刀还能跑五公里” |
| 重伤（贯穿伤/骨折） | 剧痛至无法行动、意识可能模糊、必须立即救治 | “肋骨断了还照常打架” |
| 致命伤（内脏损伤） | 数分钟内失去行动能力、意识消失 | “心脏位置中弹后还能将反派反杀” |
| 头部受伤 | 晕眩/意识模糊/失去平衡 | “被打晕后一分钟就清醒继续战斗” |
| 多处受伤 | 叠加效应：一处伤痛会放大整体虚弱感 | “身上七八处伤还生龙活虎” |

### 疲劳与耐力

| 情景 | 正常人极限 | ❌ 常见不合理 |
|------|-----------|-------------|
| 持续战斗 | 全力搏斗2-3分钟后就会力竭 | “打了半小时还越战越勇” |
| 长时间奔跑 | 常人极限800米-2公里全力跑，之后需休息 | “追了十公里气都不喘” |
| 不进食饮水 | 12-24小时后明显体力/注意力下降 | “三天不吃不喝依然精神抖擞” |
| 不睡眠 | 24小时后出现明显认知和体力下降；48小时后出现幻觉 | “三天不睡依然头脑清醒” |
| 寒冷环境 | 15℃以下需衣物保暖；0℃以下长时间暴露会失温 | “寒冬腊月只穿单衣毫无影响” |
| 炎热环境 | 35℃以上长时间暴露会中暑 | “在大太阳下暴晒一天毫无不适” |

### 水中/高空/极端环境

| 情景 | 正常人极限 | ❌ 常见不合理 |
|------|-----------|-------------|
| 屏气时间 | 常人在水下30秒-1分钟（未经训练） | “主角潜水五分钟还能战斗” |
| 高空坠落 | 三层楼以上大概率重伤/死亡 | “从五楼跳下拍拍灰就站起来” |
| 冷水浸泡 | 10℃以下水中15分钟内失温 | “跳进冰河游了半小时上岸没事” |
| 徒手攀爬 | 需要手部力量和合适着力点 | “徒手爬光滑墙面” |

## 五、场景速查表（快速判断）

当写作时不确定某行为是否合理，查下表：

```
角色要做这件事 → 查↓
├→ 用眼睛看远处 → 白天>100米细节？→ 🔴 感官越界
├→ 在黑暗中视物 → 无夜视设定？→ 🔴 感官越界
├→ 隔墙/隔楼听对话 → 听清字句？→ 🔴 感官越界
├→ 知道不该知道的信息 → 无合理信息源？→ 🔴 信息越界
├→ 预知未来事件 → 无设定支撑？→ 🔴 信息越界
├→ 说出专业领域知识 → 符合角色背景？→ 否→ 🔴 认知越界
├→ 重伤后继续战斗 → 中/重度伤？→ 🔴 体力越界
├→ 长时间战斗无疲劳 → 超过体力极限？→ 🔴 体力越界
└→ 以上都正常 → ✅ 通过
```

## 六、特殊情况说明

### 超能力/异能/魔法设定下的处理

如果角色确实有超能力设定（如修仙者、异能者、魔法师等），以下规则适用：

1. **设定必须明确告知读者**：在角色第一次展示超常能力时，要有明确的交代（如“天灵根”“狼人血脉”“变种人”）
2. **设定有代价/限制**：即使是超能力者，也需要消耗精力/法力/能量，不可能无限制使用
3. **设定内逻辑未受影响**：超能力者仍然不应该知道其设定中不允许知道的信息（如异能者不会天然全知全能）
4. **队友仍为正常人**：如果主角是异能者，其正常队友仍受人类极限约束

### 时代背景的特殊考量

| 时代 | 常见知识水平（参考值） |
|------|---------------------|
| 古代（唐宋元明清） | 识字率低；普通农民不知朝廷运作；医学知识基于中医 |
| 近代（清末民初） | 部分西学传入但民间有限；少数精英留学海外 |
| 现代/当代 | 互联网一代信息获取面广但深度不足；专业领域仍需专业教育 |
| 未来/科幻 | 由作品设定决定，但必须自洽 |

> **编写说明**：本文档中的数值为参考值，具体应用时可根据剧情需要做适当弹性。核心原则是“不要让读者觉得'这人怎么可能做到这个'”。如果读者会有此感受，即为G类违反。
