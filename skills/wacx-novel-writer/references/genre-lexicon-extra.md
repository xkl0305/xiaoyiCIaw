# 题材专属素材速查手册（长篇版）

> 本手册汇整题材专属素材，覆盖玄幻仙侠、克苏鲁哥特、赛博朋克、无限流、恐怖、古言与人设七大板块，供长篇连载写作时直接取料。
> 定位为可随查随用的题材素材速查卡，重清单、轻理论，写作卡壳时按表取材、按公式组材即可续写。

## 一、玄幻/仙侠速查

### 1.1 神通术法七大类速查表

设计公式：术法名称 + 效果描述 + 叙事价值。先定名称，再写效果，最后点明它在剧情中的用途；同类术法可叠加组合成高光战斗。

| 类别 | 代表术法（名称+效果） | 叙事价值 |
|---|---|---|
| 基础神通 | 八九玄功：变化无穷、肉身成圣；言出法随：言语即法则 | 立角色底蕴，展示道行深浅 |
| 攻击术法 | 御电奔雷：召雷轰敌；五色神光：刷落一切法宝；翻天印：无上镇压 | 战斗爽点与碾压瞬间 |
| 防御辅助 | 金刚不坏：肉身不破；袖里乾坤：收摄万物；定身术：定住对手 | 反杀铺垫与绝境翻盘 |
| 遁术变化 | 五行遁术：借金木水火土而行；筋斗云：一念千里；胎化易形：易容变形 | 追踪、逃脱与身份伪装 |
| 特殊秘术 | 天眼通：洞察虚实；他心通：读心；钉头七箭书：远程咒杀 | 智斗博弈与信息差 |
| 修炼进阶 | 三昧真火：焚尽万邪；夺舍：换体续命；御剑飞行 | 升级主线与境界跃迁 |
| 终极术法 | 龙象般若功：力可撼山；神咒汰除：净化一切 | 终局底牌与决战收束 |

组合思路：一个高光场景至少三种术法联动，例如定身术控制、五行遁术走位、御电奔雷终结。术法库可跨卷反复组合，旧元素新搭配即为新冲突。

### 1.2 玄幻魅力人设要点

十大类型：励志王者、孤傲修士、霸道枭雄、绝智谋士、红尘浪客、禁忌疯批、万年老苟、世外高人、铁血守护、混沌恶魔。

塑造公式：类型标签 + 核心特质 + 戏剧价值。特质用四字短语强化记忆点，例如励志王者「燃魂涅槃、破而后立」，孤傲修士「我命由我、逆劫而仙」，万年老苟「稳字当头、扮猪吃虎」。

三个要点：人设特质决定行为逻辑；多人设组合制造冲突群像；每类人设预留一个可成长的弧光点，长卷中随境界升级逐渐兑现。

## 二、克苏鲁与哥特速查

### 2.1 克系核心符号清单

| 符号 | 用法 |
|---|---|
| 不可名状与未知之惧 | 不正面描写怪物，用目击者的恐惧侧写 |
| 理智侵蚀与魔之呢喃 | 用幻觉、耳语、记忆混乱表现精神代价 |
| 禁忌知识与活体档案 | 知识即毒药，知道越多越接近疯狂 |
| 深海与旧日支配者 | 克苏鲁、拉莱耶、深潜渔妇作为终极威胁 |
| 邪教眷族与神秘组织 | 星之眷、眷族充当代理人冲突 |
| 高维智慧与梦之门 | 梦境、门、螺旋作为入口意象 |

氛围落点写法：先给日常，再让一个细节「不正常」，最后让角色意识到自己早已被注视。克系网文融合方向：诡异复苏、东方玄幻、玄幻脑洞、全民天灾。上手难度高，适合长篇中期技法成熟后引入，作为隐藏世界观逐层揭开。

### 2.2 哥特核心符号清单

| 类别 | 元素 | 用法 |
|---|---|---|
| 哥特建筑 | 厄舍府、阴森古堡、螺旋楼梯、地窖密室 | 封闭空间制造压抑感 |
| 吸血鬼 | 德古拉、血月、永恒黑夜 | 欲望与禁忌的化身 |
| 终结美学 | 棺材、断碑、面纱、骷髅 | 死亡意象转为抒情 |
| 颓废贵族 | 天鹅绒帷幕、蕾丝手套、荆棘王冠、午夜钟声 | 没落家族的气场 |
| 宗教仪式 | 彩绘玻璃窗、修道院、咒语献祭 | 仪式感与宿命感 |

哥特氛围三件套：复古阴森的空间、仪式化的动作、一件带有诅咒的旧物。哥特符号适合长篇的家族史与宿命线，旧物可跨卷埋设因果。

| 类别 | 元素 | 用法 |
|---|---|---|
| 义体改造 | 人体改造、神经织网、电子义眼、碳纤维义肢 | 身体即商品，写代价与失控 |
| 赛博空间 | 硅脑、蜂巢意识、视网膜投影 | 信息战与意识战场 |
| 巨型企业 | 大企业控制、数字奴役、寿命债券、呼吸税 | 资本压迫具象化 |

世界观张力公式：科技高度 × 人性温度的反差。技术越发达，人情越稀缺；义体越强，记忆越廉价。长线冲突从「高科技承诺自由、实际加深奴役」中生发，企业阴谋可作为贯穿全书的暗线。

## 四、无限流速查

### 4.1 三大底层架构
世界观决定格局与真实性，系统设计决定记忆点，副本单元剧决定单篇可读性。先定舞台，再立灵魂，后铺单元，三层互为支撑。

### 4.2 系统设计四要素
规则：进入退出、通关目标、奖励惩罚，须清晰自洽。
人格：有序中立、绝对理性、恶意玩弄，人格决定故事基调。
起源：高等文明实验场、濒死世界自救程序、强者内心投影、规则漏洞，起源即终极母题。
规则漏洞智斗：文字游戏、优先级冲突、边界模糊、规则对规则，可复合使用，是主角发挥空间所在。

### 4.3 五条串联副本主线策略
身份之谜、终极归宿、能力拼图、因果纠缠、组织对抗。选一条贯穿，副本即主线拼图，每卷补齐一块。

### 4.4 七步副本设计流程
1 定类型与核心概念；2 搭规则框架（含一两条特殊规则）；3 设计冲突层级（外部威胁、内部矛盾、道德困境）；4 构建解谜路径（显性、隐性、误导信息）；5 埋设反转伏笔；6 填充细节与氛围；7 处理结算与主线衔接。

### 4.5 新人开篇
开篇即高潮，首个副本快速抓住读者；小切口深挖掘，从一个规则挖出深冲突；保持规则敬畏，主角在规则内找漏洞而非随意开挂。

### 5.2 中式恐怖要点
十三类覆盖礼教、丧葬、红白、鬼怪、阴间、空间、自然、巫蛊、心理、罪业、身体异化、社会批判等维度。核心符号：民俗禁忌（族规私刑、沉塘、献祭河神）、老宅（深宅大院、义庄、废寺破庙）、纸扎（纸扎人、寿衣、纸钱）、红白事（冥婚、鬼新娘、红白撞煞）、巫蛊（符咒、降头、问米）。
氛围写法：戏台空场、唱腔忽止，人群越是热闹，禁忌越要沉默。恐怖靠「熟悉的日常突然失灵」，长篇可让每卷揭一层禁忌真相。

| 人设 | 核心特质 | 塑造手法 |
|---|---|---|
| 挂王 | 天赋逆天、气运加身 | 用他人震惊反应侧面烘托 |
| 跑跑 | 稳健发育、藏锋守拙 | 底牌留到绝境再亮 |
| 病娇 | 偏执情深、爱即毁灭 | 温柔与占有并存 |

| 白切黑 | 戏看风云、暗执棋局 | 台词无害、行动狠辣 |

### 7.2 反差疯批美人
塑造公式：表象特质 + 内核疯批 + 行为落点。例如暴走萝莉：纯真伪装、天真残酷、冷血杀戮；致命花魁：媚骨权术、勘破虚妄、股掌兵戈；骨瓷人偶：瓷面冰心、牢笼掌控、提线戏命。要点：外在越无害，爆发越惊人；每次越界行为都要有内在动机支撑。

### 7.3 魅力反派
塑造公式：特质 + 动机 + 格局。例如病孤美人：病娇狂气、优雅残忍、掌缘生灭；幕后黑手：执棋布网、借刀杀人、怙恶不悛；深渊古神：不可名状、维度吞噬、精神污染。要点：动机要让读者理解，手段要让人无法认同，退场要有仪式感。长篇可让反派与主角共享同一困境、选择相反手段，形成镜像对决。

### 7.4 无限流F4
战术：日常笑眯眯套情报，推眼镜时布局已到第五层，擅长破局与阴人；输出：暴躁老哥，凭野兽直觉撕出生路；吐槽：话痨乌鸦嘴怕死谨慎，总能卡BUG，绝境靠逆天运气改命；辅助：平时睡不醒，关键时一针见血洞悉唯一生路。四职能互补且自带冲突，天然形成副本化学反应。

## 八、长篇创作联动要点

- 素材可持续供给：术法库、剧情机制库、宴会库、人设库均可跨卷复用，旧元素新组合即为新冲突，保证百万字体量下素材不枯竭。
- 世界观与剧情联动：设定要长出剧情，资源稀缺引发争夺，规则漏洞催生智斗，旧日支配者牵出隐藏真相，每个大设定都预留连锁反应的引线。
- 长线埋线：从首个副本开始埋悬念，副本之间互为拼图，中期揭晓终极真相，向宏大目标收束；克系禁忌、企业阴谋、系统起源均宜作全书暗线。
- 节奏管理：紧张副本与舒缓日常交替，术法升级、人设成长、主线推进三线并行，宴会卷作舒缓期，副本卷作高潮期，交替推进防审美疲劳。
