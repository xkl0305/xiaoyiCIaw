# 角色档案模板

每个重要角色都应有独立档案，便于全自动模式下保持一致性。

## 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 姓名 | 角色全名 | 林晚舟 |
| 年龄 | 当前年龄 | 28岁 |
| 性别 | 男/女/其他 | 女 |
| 身份/职业 | 公开身份 | 刑侦支队副队长 |
| 隐藏身份 | 秘密/双重身份 | 三年前任总队长之女 |
| 外貌特征 | 辨识度高的一两个点 | 左眉有道疤，说话语速快 |
| 性格关键词 | 3个以内 | 果断、隐忍、护短 |
| 说话风格 | 口头禅/语气/用词习惯 | 短句为主，喜欢用反问句 |
| 核心动机 | 这个角色最想得到的 | 查出三年前父亲死亡的真相 |
| 当前状态 | 位置/情绪/物品/关系 | 在上海出差，愤怒，持有证据U盘 |
| 活跃伏笔 | 该角色未解决的悬念 | 父亲死亡真相、U盘内容未知 |

## 断点续读时角色档案更新清单

每完成一章，检查以下字段是否需要更新：
- [ ] 当前状态（位置/情绪/物品/关系）
- [ ] 活跃伏笔（新增或已回收）
- [ ] 角色关系（是否有变化）
- [ ] 性格表现（本章行为是否符合设定）

## 人设记忆点（塑记忆·方法论）

> 让角色过目不忘，读者能情感投射。补「角色档案模板」之上的「记忆烙印」。

- **人设烙印法**：定核心标签 → 重复强化 → 封神宣言引爆（如李淳罡「天不生我…」）。一句话让角色被记住。
- **三层代入法**：感官代入（具体身体反应）→ 情感代入（共情困境）→ 逻辑代入（认同选择）。
- **记忆钢印 + 冲突链 + 摄像机焦点转移**：用标志性动作/口头禅做记忆钢印；每次出场都卷入冲突链；群像戏用摄像机焦点在角色间转移，避免路人感。
- **反派压迫感**：智商在线、手段凌厉、动机自洽（禁区执念/纯粹恶），刺激读者情绪推动主角行动。
- **反派反差魅力**：有情有义或纯粹执念的立体反派（痴情/纯粹恶中带原则），比脸谱恶人更难忘。
- **反派落幕仪式**：退场需震撼（疯癫/悲壮/成全），用强情绪场景收束而非悄悄消失。
- **人设雷区（⭐ 新增·烂俗套路负面清单）**：①全能王禁（身份能力须明确单一，禁“会制盐又会吹玻璃还背全本红楼梦”的万能设定）；②顶级人物过度集中禁（校花校霸学霸全挤主角班/小县城，须合理分配地图、换场景开新剧情）。
- **落点**：Phase 2 人物塑造时，至少给主角 1 处记忆烙印（标签+宣言/钢印动作），配角各有功能标签+独立追求；反派须有压迫感+退场仪式。
