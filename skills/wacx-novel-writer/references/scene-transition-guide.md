# 场景切换节奏控制

## 场景类型与节奏

| 场景类型 | 节奏 | 字数占比 | 核心功能 |
|---------|------|:--------:|---------|
| 动作场景 | 快（短句、短段） | 20-30% | 推进冲突、制造爽点 |
| 对话场景 | 中（交替） | 35-45% | 揭示信息、推动关系 |
| 内心场景 | 慢（长句） | 15-25% | 情感沉淀、角色成长 |
| 环境场景 | 慢（描写） | 5-10% | 氛围营造、情绪暗示 |

## 场景转换信号

### 时间转换
- “三小时后” / “清晨六点” / “两天后”
- 避免：无信号直接跳跃

### 地点转换
- “他推开那扇门，来到了……” / “镜头一转，……”
- 避免：读者不知道角色在哪里

### 视角转换
- 切换到另一角色的内心（谨慎使用）
- 必须明确标记新视角角色

### 事件转换
- “就在这时” / “与此同时” / “就在她准备离开时”
- 用于连接并行事件

## 场景节奏公式

### 快节奏场景（动作/战斗）
```
短句 + 短段 + 少描述 + 多动作 + 无内心独白
例：“他拔剑。转身。刺。血溅到墙上。没有停顿。”
```

### 慢节奏场景（情感/思考）
```
长句 + 多描述 + 内心独白 + 感官细节
例：“他坐在窗前，看着外面的雨一滴一滴落在玻璃上。那一刻，他突然想起了很多年前母亲说的话。”
```

### 中节奏场景（对话/谈判）
```
对话为主 + 穿插动作 + 偶尔内心反应
例：“你以为我会相信你？”他把文件扔在桌上。她没有抬头，只是把手指在茶杯边缘绕了一圈。“那就别看文件。看这个人。”她把一张照片推过来。

## 场景长度控制

| 场景长度 | 适用场景 | 注意事项 |
|---------|---------|---------|
| <200字 | 过渡场景、快速切换 | 每章最多1-2个 |
| 200-500字 | 标准对话/动作 | 最常见 |
| 500-1000字 | 重要场景（告白/对峙） | 需要有节奏变化 |
| >1000字 | 高潮场景 | 必须有“快-慢-快”变化 |

## 场景检查清单

每章写完后检查：
- [ ] 本章有多少个场景？（建议2-4个）
- [ ] 场景之间是否有明确转换信号？
- [ ] 场景节奏是否有变化？（不要全是快节奏或全是慢节奏）
- [ ] 每个场景是否都推动了剧情或深化了人物？
- [ ] 有无纯过渡场景？如有，是否足够简洁？
- [ ] 高潮场景是否有足够的“蓄力”（压→爆的节奏）？
