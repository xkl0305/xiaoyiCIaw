# 对话灵气与去AI腔（S11 专节 ⭐⭐）

> **方法论锚点（权威源）**：本专节整合自两条权威依据，作为本技能对话写法的硬约束来源——
> ① **「网文方法论」四条规则**：对话灵气塑造师 / 提升对话描写的高级感 / 网文对话创作智能体 / AI小说高频词汇过滤AI腔；
> ② **《透明人审计》实战教训**：来自真实稿件审阅中暴露的“对话木偶化/标签剧本体/回忆段误用即时标签”等高频失分点，作为硬约束的实战校准。
> 下列所有硬约束、红线、检测阈值均源自上述两条，修改本专节须回溯权威源，不得凭空放宽。

---

## 一、为什么要单独立这一节

机械的「A说：“”B说：“”」是 AI 味最暴露的伤口之一：它把活人写成提线木偶，读者一眼就出戏。
对话不是“传递信息的容器”，而是**人物在冲突中带着情绪、习惯、肢体动作说话**。这一节把“写得活”变成可执行的硬约束与可机械校验的红线。

---

## 二、四大灵气手法（写法库）

| 手法 | 作用 | 角色专属示例词库 |
|------|------|------------------|
| **动作卡位法** | 用角色专属动作代替「某某说」标签——既标明说话人，又传递情绪 | 探头、咂嘴、捋工牌绳、点工牌、丢纸、转笔、横臂一拦、翻纸、搓衣角、攥拳、拍桌 |
| **神态神韵法** | 用眼神 / 微表情替代「说」 | 瞪、眯眼、撇嘴、笑意淡了、高跟鞋一拧、嘴角绷紧 |
| **情境穿插法** | 用环境 / 物品 / 声音打断对话做缓冲 | 鞋跟敲瓷砖、笔尖划纸、表针咔咔、水管滴水、远处闷雷 |
| **语感辨识法** | 角色专属语言风格 / 口头禅，让“谁在说话”不看标签也分得清 | 老王「透明人」梗、杜伟「有人管就好」复读、角色方言/术语偏好 |

**核心思路**：标签（说/道）是兜底，不是默认。能靠动作、神态、情境、语感取代标签的，一律取代。

## 三、硬约束（P0 级——写作时必须满足，不可违反）

### A. 动作卡位硬约束
- **禁止连续 ≥2 句纯「X说：“” / X：“”」标签对话**而不夹任何动作 / 神态 / 情境描写。
- **每 3 句对话内至少 1 处动作卡位或神态 / 环境穿插**（即任意连续 3 个说话轮次中，至少有 1 轮带动作/神态/环境）。
- **按情绪选动作替代「说」**：
  - 愤怒 → 攥拳 / 拍桌 / 横臂一拦
  - 轻蔑 → 咂嘴 / 撇嘴 / 高跟鞋一拧
  - 从容 → 转笔 / 理绳 / 翻纸
  - 紧张 → 搓衣角 / 捋工牌绳 / 丢纸

### B. 去AI腔对话红线
- **连续 >3 次「说 / 道」必须替换引导动词**（嘀咕 / 冷笑 / 反问 / 喃喃 / 沉吟 / 截口 / 抢白 / 嗤笑……按情境选取）。
- **禁止剧本体问答**：A：“…” B：“…” 连续出现、中间无任何动作 / 神态 / 环境间隔，视为 AI 腔，必须打散。

### C. 语境适配规则
- **回忆 / 概述段落禁用即时对话标签**：`点头说记下了` → 改为 `记在了心里`；用叙述收束，不挂“说”标签。
- **实时场景可用动作承接**：动作。`+`引号（如：他横臂一拦。“先别急。”），让动作与对话在同一节拍里落地。

---

## 四、引导动词替换表（去「说道」家族单调重复）

| 情绪 / 情境 | 可替换引导动词（替代“说 / 道”） |
|------------|-------------------------------|
| 压低 / 私密 | 嘀咕、喃喃、压低声音、凑近 |
| 对抗 / 讽刺 | 冷笑、嗤笑、反问、截口、抢白、撇嘴 |
| 迟疑 / 思索 | 沉吟、顿了顿、犹豫、咕哝 |
| 激动 / 强势 | 提高嗓门、喊、打断、拍案 |
| 微表情驱动 | 瞪、眯眼、挑眉、抿嘴（动作即引导，无需“说”） |

**禁止**：连续 A说：“” B说：“” 的问答剧本体；「说道」家族（说道 / 说道道 / 说道着）单调重复超过 3 次。

## 五、检测方法固化（三位一体对话质检）

与 `detect_ai_flavor.py`（引号 / 冒号合规）及对话归属一致性（夺句）互补，构成
**「冒号合规 + 夺句 + 动作密度」三位一体对话质检**：

| 质检维度 | 负责方 | 越界即阻断 |
|----------|--------|------------|
| 冒号合规 | `detect_ai_flavor.py`（引号非中文双引号）+ 本脚本 ASCII `:` 冒号检测 | 引号违规 / ASCII 冒号 |
| 夺句（归属） | 写作时确保每句对话归属唯一说话人，审阅口吻逐句核对 | 归属歧义 |
| 动作密度 | `scripts/detect_dialogue_ai.py`（本专节机械闸） | 见下 |

### `detect_dialogue_ai.py` 机械闸（退出码 1 = 阻断，0 = 放行）
1. **连续纯标签对话计数**：相邻说话轮次若连续 ≥2 句为纯「X说：“” / X：“”」且无动作/神态/环境穿插 → 违规（对应 A 第 1 条）。
2. **动作密度窗口计数**：任意连续 3 个说话轮次中 0 处动作/神态/环境穿插 → 违规（对应 A 第 2 条）。
3. **连续「说 / 道」计数**：相邻轮次连续 >3 次以「说 / 道」作引导动词 → 违规（对应 B 第 1 条）。
4. **ASCII 冒号违规**：`X:`（半角）紧接中文引号作对话标签 → 应改为全角 `X：`。

任一越界 → 退出码 1，须回写迭代；全过 → 0，放行。脚本输出含违规行号与计数，便于定点修改。
