# 网文大纲 5 种经典结构（原创方法论）

> 本文件为深度扩展，按需读取。适用：长篇/中长篇（10 万+字）创作开篇选结构，5 大经典结构模板可直接套用。原创方法论，非翻译。

## 一、核心认知：大纲是地图

“我就喜欢写到哪算哪”——这么说的作者十个里面九个烂尾。AI 写作尤其需要大纲：AI 没有“灵感”，你不给地图，它就瞎跑。大纲不是枷锁，是让你不迷路的地图。

## 二、5 大经典结构（按题材适配）

### 结构 1：三幕式（最通用）

**适合类型**：短篇、中篇、有明确起承转合的长篇

**结构要点**：
- 第一幕（25%）：建置——介绍角色和世界，制造“打破日常”的事件（触发事件），角色被迫走上旅程
- 第二幕（50%）：对抗——角色朝目标前进遇到阻碍，中间点是“假胜利”或“假失败”的大转折，后半段阻碍加倍，跌入“最低谷”
- 第三幕（25%）：解决——角色用成长后的自己解决最终危机，故事收尾

**原创大纲示例（玄幻）**：
- 第一幕：废柴主角被退婚 → 偶然获得传承 → 决定变强
- 中间点：宗门大比中大放异彩 → 但被发现用了禁术 → 被逐出宗门
- 最低谷：独自流浪 → 被追杀 → 重伤濒死 → 悟出真正的力量
- 第三幕：回归宗门 → 揭露反派阴谋 → 最终决战 → 成就一方强者

### 结构 2：升级打怪流（网文最常用）

**适合类型**：玄幻、修仙、系统文

**结构要点**：循环结构——每个弧段都是一次“遇到更强的对手 → 修炼变强 → 打败对手 → 进入新地图”

**核心循环**：
```
新地图/新势力 → 低调装逼 → 结仇 → 修炼突破 → 打脸 → 获得奖励 → 更大的舞台
```

**原创大纲框架**：
- 卷一（修炼入门）：出生地图 → 等级：练气期 → 反派级别：地方恶霸
- 卷二（宗门争斗）：宗门 → 等级：筑基期 → 反派级别：内门长老
- 卷三（外出历练）：秘境/外域 → 等级：金丹期 → 反派级别：其他宗门天才
- ……每卷等级翻倍，舞台翻倍

**关键提示**：每个循环里要有一个“超出预期”的元素——不能纯套路。比如卷三的反派原来是主角失散的兄弟。每卷标注“差异化元素”，避免读者审美疲劳。

### 结构 3：悬疑推理流（线索驱动）

**适合类型**：悬疑、推理、惊悚

**结构要点**：从结局倒推——先确定真相，再拆线索，最后才写主角视角

**原创大纲步骤**：
1. 先确定真相（凶手是谁/动机/手法）
2. 把关键线索拆成 5-10 条
3. 确定每条线索出现的时机
4. 安排 2-3 条红鲱鱼（误导线索）
5. 最后才写“主角的视角”按顺序呈现

**原创大纲示例**：
- 真相：管家杀的，动机是遗产，手法是在咖啡里下慢性毒药
- 线索 1（第 3 章）：死者每天只喝管家泡的咖啡
- 线索 2（第 5 章）：管家有药学背景
- 红鲱鱼（第 4 章）：死者的情人有大笔债务
- 揭示（第 10 章）：主角在管家房间找到药瓶

### 结构 4：群像叙事流（多主角）

**适合类型**：权谋、宫斗、多势力对抗

**结构要点**：同时推进 3-5 条主角线，关键节点交汇——群像最难的写法

**原创大纲框架**：
```
主线 A（王子复仇）：章 1 → 章 3 → 章 6 → 章 9 → 章 12
主线 B（公主暗棋）：章 2 → 章 4 → 章 7 → 章 10 → 章 12
主线 C（刺客觉醒）：章 3 → 章 5 → 章 8 → 章 11 → 章 12
交汇点：章 6（A 和 C 第一次碰面）、章 9（B 和 A 联手）、章 12（三线汇合大决战）
```

**关键提示**：
- 群像大纲**必须画时间轴**——确保三条线的时间是同步的
- 否则会出现“A 线已经过了三天，B 线还在同一天”的 bug
- 推荐在 `00-卷规划.md` 中明确每卷推进哪条主线

### 结构 5：无限流/副本制（单元剧）

**适合类型**：无限流、副本文、规则怪谈

**结构要点**：主线 + 单元的混合结构——每个副本/世界是独立小故事，主线贯穿所有副本

**原创大纲框架**：
- 主线：主角被选中进入游戏 → 每通过一个副本获得一个线索 → 最终拼出游戏背后的真相
- 副本 1（生存类）：荒岛求生 → 3 章
- 副本 2（推理类）：密室杀人 → 4 章
- 副本 3（战斗类）：异世界战争 → 5 章
- 幕间：每个副本之间 1 章主线推进

**关键提示**：每个副本的调性可以不同（恐怖/搞笑/热血），但主角的成长弧线要贯穿始终——能力+心理两个层面都要标注每个副本后的变化。

## 三、三级大纲系统接入

**总纲**（1000-2000 字）：对应上面任一“结构框架”——整本书的主线走向

**卷纲**（每卷 200-500 字）：每个大弧段的详细规划，包括本卷节奏类型（铺垫/爆发/收束）

**章节蓝图**（每章 50-200 字）：每章的具体内容指令，包括：本章爽点/钩子位置/对话占比/字数预估

**推荐工作流**：
1. 选择一个结构模板，花 1-2 小时写总纲
2. 把总纲拆成 5-10 卷，每卷写 200-500 字的卷纲
3. 开始写之前，把当前卷的章节蓝图写好（每章 50-200 字）
4. AI 按照蓝图生成，你负责审核
5. 这样“创作”集中在规划层面（最有价值），“执行”交给 AI

## 四、结构选型决策树

```
Q1：是否追求“一个明确起承转合”的完结？
├─ 是 → 结构 1（三幕式）
└─ 否 → Q2

Q2：是否有“等级/地图/能力成长”的核心设定？
├─ 是 → Q3
│   ├─ 主角靠等级碾压 → 结构 2（升级打怪流）
│   └─ 主角靠副本通关 → 结构 5（无限流/副本制）
└─ 否 → Q4

Q3：故事核心是“找真相/破谜案”？
├─ 是 → 结构 3（悬疑推理流）
└─ 否 → Q5

Q4：是否同时有 3 个以上主要角色各自有独立线？
├─ 是 → 结构 4（群像叙事流）
└─ 否 → 结构 1（三幕式）
```

## 五、自查清单（大纲交付前）

- □ 总纲是否选定 5 大结构之一（不要混搭）？
- □ 总纲长度是否在 1000-2000 字（不要过短也不要过长）？
- □ 是否拆分到卷纲（每卷 200-500 字）？
- □ 是否拆分到章节蓝图（每章 50-200 字）？
- □ 每个循环/转折点是否标注“差异化元素”？
- □ 群像类是否画了时间轴（三线同步）？
- □ 无限流是否标注了每副本主角成长（能力+心理）？
- □ 悬疑是否从结局倒推（先真相后线索）？
- □ 三级大纲是否完整无缺漏？
