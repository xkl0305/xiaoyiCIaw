# 读者试读仿真（Phase 2.5·前10章试读调整）

> 本文件为深度扩展，按需读取。适用：长篇前10章定调期（2万字关键节点）的多视角读者反馈仿真，自动按共性反馈改前10章并作为后续写作参照。**核心红线：不得跑偏大纲和圣经。**

## 一、核心认知：为什么要做试读仿真

前10章是决定性窗口——读者追读/弃读的关键节点。后续100章写得再好读者不追也是白写。现有 Phase 3 的 H类审计（跨章逻辑）+ G类审计（人物行为）+ 十维评分都是**机械化规则评判**，缺口在“读者真实感受”这一维。LLM 模拟不同人设读者能填补这个缺口，加速反馈循环（不用真的找人试读）。

但 LLM 模拟读者有三个固有陷阱：
1. **共性陷阱**：多个读者易趋同，缺真实多样性 → 用差异化画像库破解
2. **过度修改陷阱**：反馈可能让作者反复改稿，偏离自己的核心风格 → 圣经/大纲不可改动硬线破解
3. **题材错配陷阱**：严肃向作品被爽文读者反馈误判 → 画像库按题材匹配破解

## 二、5人读者画像库（按题材匹配）

**匹配规则**：根据 Phase 0 确定的题材，从下表选 5 个画像。严肃向/思想性题材优先选 A/B/C + D（对照）+ E（边界）；爽文/快节奏题材优先选 D/A/B + C（深度反馈）+ E。

| 画像 | 年龄段 | 文化程度 | 阅读目的 | 核心敏感度 | 反馈维度权重 |
|------|--------|---------|---------|----------|------------|
| **A·思想共鸣型** | 25-35 | 高等教育 | 寻找思考价值 | 主题深度/辩证/价值观 | 思想性40% 文笔25% 节奏15% 爽感10% 虐感10% |
| **B·情感共情型** | 20-40 | 中高 | 被打动/被虐 | 情感触发点/人物弧光/虐点力度 | 虐感30% 情感35% 文笔20% 思想性10% 节奏5% |
| **C·质感文笔型** | 30-50 | 高 | 读文学享受 | 文笔质感/文学性/留白/呼吸感 | 文笔50% 思想性20% 情感20% 节奏5% 爽感5% |
| **D·节奏爽感型** | 18-30 | 中 | 追读爽文 | 节奏/钩子/爽点/转折密度 | 节奏30% 爽感30% 钩子20% 代入感10% 文笔10% |
| **E·冷感现实型** | 35-60 | 中高 | 看现实映射 | 逻辑自洽/人物真实/价值观 | 逻辑30% 人物真实30% 思想性20% 节奏10% 文笔10% |

**画像差异化保证**：年龄跨 18-60、文化跨中-高、目的跨娱乐-思考-质感到现实、敏感度跨纯爽感到纯思想性——5 人组合后形成完整读者光谱。

## 三、试读 SOP（6步）

### Step 1：画像匹配（Phase 0 完成后即可定）
- 根据 Phase 0 确定的题材/类型/调性，从画像库选 5 个
- 严肃向/思想性/虐向：A+B+C+D+E（光谱最全）
- 爽文/快节奏：D+A+B+C+E（爽感为基底+思想+质感对照）
- 通用泛题材：A+B+D+C+E（均衡光谱）

### Step 2：逐读者试读
- 每个虚拟读者读前10章，按其画像的“反馈维度权重”独立给分
- **每个读者必须给出恰好 3 条具体反馈**（不是泛泛而谈，是“第N章某段有什么问题”或“前10章整体感觉如何”）
- 反馈格式：「针对片段：[章节号/段名] / 我的感受：[具体描述] / 改进建议：[可操作]」

### Step 3：共性汇总
- 提取 **≥3 个读者都提到** 的反馈点（5人里至少3人 = 共性）
- 单一读者的个人偏好不视为共性（如 D 觉得“爽感不够”，但只有他一个人提，不算共性）
- 共性反馈按“出现人数”排序：5人全提 > 4人提 > 3人提

### Step 4：P0 调整项提炼（最多 5 条）
从共性反馈中提炼**结构性 P0 调整项**，规则如下：
- 仅针对**共性 + 关键缺陷**（非锦上添花）
- 每条 P0 必须对应具体章节/段落
- 每条 P0 必须给出**可操作的修改建议**（不是“写得更好”，而是“第3章某段改为何种处理”）
- 最多 5 条 P0（防止过度修改）

### Step 5：自动应用 P0（小修而非大改）
- 自动应用 P0 到前 10 章对应段落
- 限定：单次应用改动量不超过前10章总字数的 10%（约 2000 字），保持前10章结构稳定
- **应用前必须经过“圣经过滤层”**（详见第四节）
- 被圣经拒采纳的 P0 项记录到《偏差清单》而非强行应用

### Step 6：全局报告输出
- 输出文件：`progress/phase2.5-readers-test-report.md`
- 报告内容：5 个读者画像 + 5×3 条反馈 + 共性提炼 + P0 应用清单（含圣经过滤结果）+ 偏差清单 + 后续写作参照清单
- 后续 Phase 2（11+章）自动加载此报告作为参照输入

## 四、圣经/大纲不可跑偏硬线（⭐ 核心红线）

**优先级：圣经 > 大纲 > 试读反馈**。试读反馈**永远不能**改动以下 7 类圣经锚定内容：

| 圣经锚定项 | 不可被反馈改变的示例 |
|----------|------------------|
| **主角人设核心** | 性格/价值观/驱动力/致命标签/底线 |
| **核心冲突引擎** | 主角驱动力 × 世界阻力（已锁定的核心矛盾） |
| **故事类型** | 严肃向/爽文/悬疑/言情等（一旦确定不可改） |
| **主题方向** | 探讨的思想主题、价值观辩证方向 |
| **关键伏笔** | 已规划的贯穿伏笔、悬念、麦格芬大钩子 |
| **人物关系骨架** | 三差值理论的核心关系、阵营手牌 |
| **结局方向** | 整体结局走向（BE/HE/HE中虐等） |

**圣经过滤规则**（应用 P0 前必须逐条比对）：
1. 每条 P0 调整项都要对照上述 7 类锚定项
2. 若 P0 涉及**任何一项**锚定 → 标记为“被圣经拒采纳”，记录原因，**绝不应用**
3. 若 P0 不涉及锚定但与**大纲细纲冲突**（如改变章序、删并核心场景）→ 标记“与大纲冲突”，记录偏差，**不应用**
4. 仅**与圣经/大纲均不冲突的 P0**才进入自动应用队列

**反例（违规情境）**：
- ❌ “A读者建议主角加入反派阵营” → 触及核心冲突引擎 + 主题方向 → 拒采纳
- ❌ “B读者觉得故事不够爽，建议加入升级打脸元素” → 触及故事类型 → 拒采纳
- ❌ “D读者建议把悬疑题材改为甜宠” → 触及故事类型 → 拒采纳
- ❌ “E读者觉得主角太冷血，建议加情感戏” → 若圣经已定“冷硬主角”则拒采纳

**正例（合规情境）**：
- ✅ “5人共性：第3章主角动机交代不清” → 不触及圣经，可应用（加一段内心独白或前置动作）
- ✅ “4人共性：第7章转折无铺垫” → 不触及圣经，可应用（加2-3句环境/对话铺垫）
- ✅ “3人共性：第9章对话占比过低” → 不触及圣经，可应用（重写部分对话）

## 五、共性反馈提取规则

- **强共性**（5/5 或 4/5）：自动进入 P0 候选
- **弱共性**（3/5）：进入 P0 候选但优先级低，与强共性并列时按强优先
- **非共性**（≤2/5）：记录但不视为 P0，仅在报告里展示供后续参考
- **冲突反馈**（同一段被读者既说“过长”又说“过短”）：以**多数方意见为准**，少数方记录为偏差

## 六、作为后续写作的参照

**自动加载规则**：
- Phase 2（11+章）的 S1-S5 步骤增加：从 `progress/phase2.5-readers-test-report.md` 读取 P0 应用清单与偏差清单
- 写后续章节时若涉及 P0 已修过的同类问题 → 自动应用同类修复策略
- 写后续章节时若涉及“被拒采纳”的反馈方向 → 显式标注“已注意到读者偏好 A，但根据圣经保持原方向”，并在迭代中观察是否真的需要调整

**报告保存期**：贯穿整个长篇生命周期，作为 Phase 3 终审的补充输入之一

## 七、自查清单（试读阶段交付前）

- □ 5 个读者画像是否按题材匹配（差异化覆盖读者光谱）？
- □ 每个读者是否给出恰好 3 条具体反馈（非泛泛而谈）？
- □ 共性反馈是否按≥3/5 标准提炼？
- □ P0 调整项是否≤5条、是否均可操作、是否对应具体段落？
- □ 每条 P0 是否经过圣经过滤层（7 类锚定项逐一比对）？
- □ 被圣经拒采纳的 P0 是否记录到偏差清单（而非强行应用）？
- □ 全局报告是否输出到 `progress/phase2.5-readers-test-report.md`？
- □ 后续 Phase 2 是否自动加载报告作为参照输入？
- □ 单次改动量是否≤前10章总字数10%（约 2000 字）？
