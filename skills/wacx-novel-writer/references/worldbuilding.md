# 世界观五维架构 SOP（长篇圣经先行）

> **来源**：《小说开荒领航员》《破关-防崩-去水感-抓痛点》
> **定位**：长篇「框架松散、写崩、中期疲软」的根因补丁。与 `volume-planning.md`（卷规划骨架）、`foreshadowing-system.md`（伏笔系统）互补——本文件管「世界怎么立」，那两个管「结构怎么搭、伏笔怎么埋」。

## 一、五维架构法

1. **世界类型与势力格局**：宗门林立 / 帝国争霸 / 末世废土 / 赛博都市……明确势力分布与权力缝隙（主角崛起空间从哪来）。
2. **力量体系**：等级 / 进阶路径 / 天花板（筑基 → 结丹 → 元婴式清晰阶梯，让读者有「变强可视化」期待）。
3. **职业 / 社会体系**：门派 / 家族 / 职业分工 / 阶层流动规则（社会越有缝隙，主角越能钻营）。
4. **物品 / 资源体系**：丹药 / 法宝 / 货币 / 材料的等级与稀缺逻辑（驱动欲望与冲突的硬通货）。
5. **规则体系（底层逻辑）**：世界运行的硬法则 / 物理约束 / 特殊限制（如灵气复苏规则、系统契约条款）——这是金手指与冲突的合法边界。

## 二、核心冲突引擎

- **公式**：核心矛盾 = 主角驱动力（想要什么：复仇 / 求道 / 搞钱 / 守护）× 世界阻力（势力 / 规则 / 敌人 / 资源垄断）。
- 二者咬合即故事主轴。驱动力越尖锐、阻力越结构性，冲突越不可调和、追读越强。
- **主角塑造**：外貌 / 性格 / 原生家庭 / 童年阴影 → 行为模式；明确结局变化（从 X 变成 Y）。
- **主旨（进阶可选）**：故事想表达的主题（如「我命由我不由天」「能力越大责任越大」），有主旨能与读者深度共鸣。

## 三、划阶段铁大纲

- 500 字内划阶段，每阶段一个大转折（例：获魔功 → 被封杀 → 魔界反杀）。
- 阶段内不抠细节，避免沉默成本；阶段间用「未达目标 → 升级 → 新目标」衔接（见 `outline-blueprint.md` 锚点推演法）。

## 四、验证三阶段（写前自检）

1. **锚点自洽**：从阶段结果锚点倒推逻辑桥梁，链条不断裂（见 `outline-blueprint.md` 逆推锚点法）。
2. **防崩校验**：套娃循环 / 三线并行 / 伏笔回收 / 故事细胞分裂不散（见 `outline-blueprint.md`）。
3. **主题纯净**：支线不偏离主旨，偏离则删（见 `outline-blueprint.md` 全局审视）。

## 五、落点

- **Phase 0 世界观五维构建增强**：未定五维不进 Phase 1。
- 与 `volume-planning.md`（卷规划骨架）、`foreshadowing-system.md`（伏笔）互补，不重复。
- 验证三阶段可并行于 `outline-blueprint.md` 的大纲构建血肉流程。
