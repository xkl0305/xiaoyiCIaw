# 逻辑审计 8 大类 33 项检测规则（完整版）

> 外移自 wacx-novel-writer 模块七。SKILL.md 仅内联 8 大类名称与 G/H 类 P0 定义；本文件为完整 33 项明细与 H 类三大审计动作。
> 目标：自动发现逻辑矛盾/前后不一致/因果断裂，Phase 2 逐章拦截（S15b）+ Phase 3 全文扫描（A2.5 + H 类横向审计）。只做校验，不做评分。

---

## G. 人物行为合理性（⭐⭐ P0 最高优先，11 项）

| 检测项 | 说明（含判定示例） | 优先级 |
|--------|------------------|--------|
| 反应违背人性 | 角色面对危机/死亡/背叛时的反应不符合常人本能（如面对亲人被杀毫无情绪波动、被背叛后立即原谅） | 🔴 |
| 情绪反应过度/不足 | 同一刺激下的情绪强度与正常人有严重偏差（如被当众羞辱后毫无反应、小事崩溃） | 🟡 |
| 决策不合常理 | 角色做出明显不利于自身、且无合理动机支撑的重大决定（如主动放弃明显优势、明知陷阱还要跳） | 🔴 |
| 生理常识缺失 | 伤口反应、疲劳状态、饥饿、寒冷等生理需求被忽略（如寒冬单衣无反应、三天不食无影响） | 🟡 |
| 社交常识违背 | 正常社会交往中不该说的话/做的事（如第一次见面就掏心掏肺、对上级出言不逊无后果） | 🟡 |
| 恐惧反应缺失 | 面对暴力/威胁时无应激反应（如刀架脖子不害怕、被群殴不恐惧、面对死亡威胁冷静得像在喝茶） | 🔴 |
| 记忆合理性 | 对刚刚发生的事件立即遗忘（无解释）；或记住太多不可能的细节（数年前某人的一句话一字不差） | 🟢 |
| **感官极限（P0）** | 角色看到/听到/感知到超出正常人类感官极限的事物（如黑暗中看清百米外细节、听清隔楼低语、集市中捕捉远处低语），且无超能力设定支撑 | 🔴 |
| **认知极限（P0）** | 角色展示出不符合其经历/教育/职业背景的知识（如古代农民懂现代化学、乡村少年脱口专业医学术语、文盲引法律条文） | 🔴 |
| **信息极限（P0）** | 角色知道其不应知道的信息（如知道从未发生的事、知道他人内心想法、预知未发生的转折），且无合理信息源交代 | 🔴 |
| **体力极限（P0）** | 角色在重伤/极度疲劳/长时间战斗后依然行动如常（中刀狂奔十公里、骨折照常打架、三天不睡仍清醒、打半小时越战越勇） | 🔴 |

## A. 人物一致性（4 项）
| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| 性格矛盾 | 同一角色不同章节行为与其核心性格设定冲突（无合理铺垫） | 🔴 |
| 状态矛盾 | 角色位置/伤势/持有物品在同一时间线内无法同时满足 | 🔴 |
| 关系矛盾 | 角色间关系前后变化不合逻辑（刚结仇突然无条件信任） | 🟡 |
| 能力矛盾 | 角色获得新能力后突然变回无能力状态（无交代） | 🔴 |

## B. 时间线一致性（3 项）
| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| 时间跳跃 | 事件顺序颠倒或时间倒流（无闪回/倒叙标注） | 🔴 |
| 年龄/年代矛盾 | 角色年龄或年代背景与设定不符 | 🔴 |
| 同日事件冲突 | 同一天内角色出现在不可能同时到达的两地 | 🔴 |

## C. 伏笔与回收（3 项）
| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| 未回收伏笔 | 前文埋设但未在后文回应的重要线索 | 🟡 |
| 矛盾回收 | 伏笔回收内容与埋设时暗示的信息冲突 | 🔴 |
| 烂尾线索 | 关键悬念长期无跟进（超过10章） | 🟡 |

## D. 因果链断裂（3 项）
| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| 巧合驱动 | 关键剧情转折依赖不合理巧合（无铺垫） | 🔴 |
| 动机缺失 | 重要决策/行为缺少合理动机支撑 | 🔴 |
| 结果超前 | 结果发生在原因之前（时间倒置或无因有果） | 🔴 |

## E. 世界观/设定一致性（3 项）
| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| 设定冲突 | 同一规则在不同章节描述不一致 | 🔴 |
| 背景矛盾 | 时代背景、社会环境与章节设定冲突 | 🟡 |
| 地理矛盾 | 角色移动路线与地理常识冲突 | 🟡 |

## F. 章节内自洽（2 项）
| 检测项 | 说明 | 优先级 |
|--------|------|--------|
| 单章时间矛盾 | 同一章内时间线混乱 | 🔴 |
| 单章逻辑断裂 | 同一章内事件因果不成立 | 🔴 |

## H. 全卷逻辑一致性审计（⭐⭐ 横向跨章——补十维评分盲区）

十维评分是“纵向打分”（单章 vs 标准），跨章问题（时间线矛盾/信息源矛盾/因果链断裂）十维发现不了。本审计专门补洞。

### 三大审计动作（固定执行，不可省略）

**审计动作一：提取完整时间线**
1. 通读全卷所有章节，提取每个带时间词的事件（绝对时间/相对时间/时序关系）
2. 构建全卷时间线图谱（Ch1: 时间→事件→时间→事件…）
3. 逐项检查：同一时刻角色出现在两地 / 相对时间自相矛盾 / 时间跨度不合理 / 昼夜颠倒
4. 输出「全卷时间线一致性报告」

**审计动作二：提取信息事实表**
1. 通读全卷，提取每个关键事实的完整信息链（事实ID/内容/首次出现/信息源交代/后续引用/引用时信息源/是否一致）
2. 逐项检查：信息源不一致 / 信息源缺失 / 信息质量矛盾 / 信息遗忘
3. 输出「全卷事实一致性报告」

**审计动作三：常识通读（纯读者视角）**
1. 不看评分标准、不管字数、无视禁词，从头通读一次
2. 只问三个问题：这段像话吗？这里怪怪的？两处说的是一回事吗？
3. 标记隐性断层：时间黑洞 / 信息bug / 因果跳过 / 设定漂移
4. 输出「常识通读报告」

### 审计执行时机
| 时机 | 方式 | 说明 |
|------|------|------|
| **Phase 3 启动前（强制）** | 全卷通读 | 进入十维评分前必须先跑；🔴问题先修复再评分 |
| Phase 2 卷完成后（可选） | 本卷通读 | 每完成一卷建议跑一次 |
| Phase 4 交付前（复审） | 全卷通读 | 最后一次确认无横向矛盾 |

### 审计输出格式
```markdown
## 全卷逻辑一致性审计报告
### 🟥 致命矛盾（必须修复）
1. [时间线] Ch2说“三天后”，Ch3实际发生在“第二天”——相差一天 → 建议：统一
### 🟨 潜在风险（建议修复）
1. [常识] Ch5凌晨修完，Ch6下午涂装——中间半天无交代 → 建议：加过渡
### 🟩 轻微问题（可选修复）
1. [设定] Ch14说“唯一会修的人”，Ch18出现另一个 → 建议：改“少数之一”
```

### 与十维评分的关系
| 项目 | 十维评分 | 全卷逻辑一致性审计 |
|------|---------|-----------------|
| 视角 | 纵向（单章 vs 标准） | 横向（全卷 vs 全卷） |
| 单位 | 每章独立 | 跨章对比 |
