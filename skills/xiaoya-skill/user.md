# user — 用户数据

查询用户在喜马拉雅平台的收听历史、订阅、画像偏好等信息。

## 工具列表

| 工具名 | 说明 | 典型场景 |
|--------|------|----------|
| `queryUserListenHistory` | 查询用户收听历史 | "我最近听了什么" |
| `getUserInfo` | 查询用户画像偏好 | "我的收听偏好是什么" |
| `querySubscribedAlbum` | 查询用户订阅专辑 | "我订阅了哪些专辑" |

## queryUserListenHistory

**功能**：分页查询用户收听历史。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pageNo` | integer | 否 | 第几页，从1开始 |
| `pageSize` | integer | 否 | 每页条数，默认20，最大100 |

**回包**：格式化文本，收听历史列表。

示例：
```
1. 声音ID:123；声音标题：《title》；最近收听时间:2023-01-01 00:00:00；还剩余5分钟没有收听；专辑ID:456；专辑标题:xxx;主播ID:789,主播昵称:xxx
```

## getUserInfo

**功能**：查询用户画像偏好。

**请求参数：**

无。

**回包**：格式化文本，用户画像信息。

示例：
```
用户昵称: xxx
用户当前的地理位置为:北京
性别为：男，年龄为：25-30岁
用户喜欢收听如下分类的专辑：音乐、有声书
```

## querySubscribedAlbum

**功能**：查询用户订阅的专辑。

**请求参数：**

无。

**回包**：格式化文本，订阅专辑列表。

示例：
```
1. 【专辑ID】:123,【专辑名称】：《title》， 【创建时间】:2023-01-01 00:00:00；【最近一次收听时间】:2023-05-01 00:00:00,【用户收听时长】：100分钟,【收听进度】:50%,【专辑下的声音总条数】：20；专辑最近一次的更新时间:2023-06-01 00:00:00,更新的声音ID:456,更新的声音标题：《最新声音》；
```

## 工作流

1. 用户问"我最近听了什么" → `queryUserListenHistory`
2. 用户问"我的订阅" → `querySubscribedAlbum`
3. 用户问"我的喜好/画像" → `getUserInfo`
4. 展示收听历史：编号列表，展示声音标题、专辑、最近收听时间

## 数据展示规范

- **内部标识不得暴露**：回包中的 `专辑ID`、`声音ID`、`用户ID` 等内部标识仅用于内部上下文记忆或构造深度链接，**面向用户展示时不得主动以纯文本形式暴露**。重点展示标题、主播、最近收听时间、收听进度等用户感知度高的信息
