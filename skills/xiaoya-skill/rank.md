# rank — 榜单浏览

查询喜马拉雅平台各类收听榜单，发现热门内容。

## 工具列表

| 工具名 | 说明 | 典型场景 |
|--------|------|----------|
| `queryRankList` | 查询单个榜单 | "看看全站热播榜" |
| `batch_query_rank_lists` | 批量查询多个榜单（最多10个） | "同时看看小说热门和悬疑热门" |

## queryRankList

**功能**：查询单个榜单，返回专辑或声音列表。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `rankName` | string | 是 | 榜单名称，须与下列规范名一致 |

**支持的榜单名称（部分）**：

- 全站类：`全站热播`、`全站新品`、`全站口碑`、`全站完结`、`全站飙升`、`全站免费`、`全站VIP`、`全站畅销`
- 小说类：`小说热门`、`小说新品`、`小说免费`、`小说口碑`、`小说完结`、`小说都市`、`小说玄幻`、`小说悬疑`、`小说历史`
- 悬疑类：`悬疑热门`、`悬疑新品`、`悬疑免费`、`悬疑口碑`、`悬疑完结`、`悬疑恐怖惊悚`、`悬疑刑侦推理`
- 广播剧类：`广播剧热播`、`广播剧新品`、`广播剧免费`、`广播剧口碑`、`广播剧完结`
- 历史类：`历史热门`、`历史新品`、`历史免费`、`历史口碑`、`历史完结`、`历史中国史`、`历史世界史`
- 相声类：`相声热播`、`相声新品`、`相声免费榜`、`相声口碑榜`、`相声完结榜`
- 儿童类：`儿童热播`、`儿童新品`、`儿童口碑`、`儿童完结`、`儿童侦探冒险`、`儿童校园成长`
- 音乐类：`音乐热播`、`音乐新品`、`音乐免费`、`音乐口碑`、`音乐完结`
- 商业财经类：`商业财经热播`、`商业财经新品`、`商业财经免费`、`商业财经投资理财`
- 更多见完整榜单列表...

**回包**：结构化 JSON，包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `rankName` | string | 榜单名称 |
| `contentType` | integer | 内容类型：2=专辑，1=声音 |
| `total` | integer | 返回条数（最多20） |
| `albums` | array | 专辑列表（contentType=2 时有值） |
| `tracks` | array | 声音列表（contentType=1 时有值） |

**albums[] 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `albumId` | long | 专辑 ID |
| `albumTitle` | string | 专辑标题 |
| `category` | string | 分类 |
| `author` | string | 主播昵称 |
| `coverUrl` | string | 封面图地址 |
| `albumPlayCount` | long | 播放量 |
| `rating` | double | 评分 |
| `albumIsPaid` | boolean | 是否付费 |
| `albumIsVip` | boolean | 是否 VIP |
| `totalTracks` | integer | 总声音数 |
| `albumIsFinished` | boolean | 是否完结 |

**tracks[] 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `trackId` | long | 声音 ID |
| `trackTitle` | string | 声音标题 |
| `albumId` | long | 所属专辑 ID |
| `trackPlayUrl` | string | 播放地址 |
| `duration` | integer | 时长（秒） |
| `trackPlayCount` | long | 播放量 |
| `trackIsPaid` | boolean | 是否付费 |

**错误响应**：

| 场景 | error 信息 |
|------|-----------|
| rankName 缺失 | `rankName is required` |
| rankName 无效（无法匹配） | `invalid rankName: xxx` |
| 榜单数据为空 | `rank list data is empty: xxx` |
| RankingService 异常 | `rank list query error: xxx` |

## batch_query_rank_lists

**功能**：批量查询多个榜单（最多10个）。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `rankNames` | string[] | 是 | 榜单名称列表（最多10个） |
| `topK` | integer | 否 | 每个榜单返回数量，最大50 |

**回包**：格式化文本，多个榜单的排行榜内容。

示例：
```
批量榜单查询结果（共查询 2 个榜单）

【榜单1：全站热播】
榜单类型：专辑榜单
更新时间：2023年01月01日

排行榜（前20名）：
1. 排名：第1名 | {专辑名:xxx;专辑ID:123;主播:xxx;...}
   上榜理由：播放量持续增长，用户好评如潮

查询统计：
- 总查询榜单数：2
- 成功查询数：2
- 失败查询数：0
```

## 工作流

1. 用户问"看看 xxx 榜" → `queryRankList`
2. 用户问"同时看看几个榜" → `batch_query_rank_lists`
3. 展示榜单结果：编号列表，展示标题、主播、播放量、分类；附上跳转链接（客户端根据实际环境选择 `iting://` 或网页链接）

## 数据展示规范

- **禁止重排**：榜单结果必须按服务端返回的原始顺序输出，不得以任何方式重新排序（如按播放量、评分等二次排序）。仅当用户主动明确要求重排时（如"按播放量从高到低排"），方可按用户指定的维度重新排序
- **内部标识不得暴露**：回包中的 `专辑ID`、`声音ID`、`用户ID` 等内部标识仅用于内部上下文记忆或构造深度链接，**面向用户展示时不得主动以纯文本形式暴露**。重点展示标题、主播、播放量、分类、简介等用户感知度高的信息
