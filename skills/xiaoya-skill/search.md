# search — 内容检索

在喜马拉雅平台检索专辑、声音、主播等资源，支持平台内搜索和互联网搜索。

## 工具列表

| 工具名 | 说明 | 典型场景 |
|--------|------|----------|
| `hubSearch` | 统一检索（专辑+声音），返回结构化列表 | 用户模糊搜索，不确定要专辑还是声音 |
| `getAnchorInfo` | 根据主播名称查询主播信息及作品 | "xxx主播有哪些作品" "查一下主播xxx" |
| `searchAlbum` | 专辑检索 | 用户明确要找专辑 |
| `searchTrack` | 专辑内声音检索 | 在指定专辑内查找声音 |
| `searchFromInternet` | 互联网信息检索 | 查天气、股票、新闻等非音频信息 |
| `search_track_from_album` | 从指定专辑内搜索声音 | "在这个专辑里找 xxx" |

## hubSearch

**功能**：在喜马拉雅平台做统一检索，一次调用同时返回专辑列表和声音列表。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `deviceId` | string | 是 | 设备标识 |
| `keyword` | string | 否 | 检索关键词片段 |
| `anchor` | string | 否 | 主播/创作者信息（如昵称） |
| `rank` | string | 否 | 搜索排行扩展：`热门`、`新品`、`免费`、`完结` |
| `category` | string | 否 | 一级内容分类，须完全一致 |
| `size` | integer | 否 | 专辑和声音各自最大条数，默认20，范围1~20 |

**category 合法取值**：
`音乐`、`有声书`、`娱乐`、`外语`、`儿童`、`商业财经`、`历史`、`相声评书`、`个人成长`、`广播剧`、`播客`、`看小说`、`有声图书`、`人文国学`、`热点`、`生活`、`政·青春`、`新红色频道`、`悬疑`、`健康`、`短剧`、`汽车`、`科技`、`情感`、`生活娱乐`、`大师课`、`冥想`

**回包：**

| 字段 | 说明 |
|------|------|
| `requestId` | 请求标识 |
| `topContent` | 优先展示类型，`album` 或 `track` |
| `albums[]` | 专辑列表 |
| `albums[].albumId` | 专辑 ID |
| `albums[].albumTitle` | 专辑标题 |
| `albums[].category` | 分类 |
| `albums[].author` | 作者/主播 |
| `albums[].coverUrl` | 封面图地址 |
| `albums[].albumPlayCount` | 播放量 |
| `albums[].albumIsPaid` | 是否付费 |
| `albums[].albumIsVip` | 是否 VIP |
| `tracks[]` | 声音列表 |
| `tracks[].trackId` | 声音 ID |
| `tracks[].trackTitle` | 声音标题 |
| `tracks[].albumId` | 所属专辑 ID |
| `tracks[].trackPlayUrl` | 播放地址（非付费声音通常有效） |
| `tracks[].duration` | 时长（秒） |
| `tracks[].trackPlayCount` | 播放量 |

**错误码：**

| errorCode | 说明 |
|-----------|------|
| `DEVICE_ID_REQUIRED` | 未传 deviceId |
| `SEARCH_KEYWORD_ANCHOR_EMPTY` | keyword 和 anchor 不能同时为空 |
| `AUTHENTICATION_FAILED` | 鉴权失败 |

## getAnchorInfo

**功能**：根据主播名称查询主播详细信息及其作品列表。支持别名、昵称等模糊匹配。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `anchorName` | string | 是 | 主播名称（支持昵称、别名等模糊匹配） |

**回包：** 格式化文本，主播信息及作品列表。

匹配成功时示例：
```
紫襟 的ID为 36936690，他在喜马拉雅FM平台的最近几部作品为：
1. 专辑 《紫襟社》的ID是 1234567 ,它创建于2023-01-01 00:00:00，属于悬疑分类,由主播 紫襟 倾情演播,截止目前累计播放量为 1.2亿,累计订阅量为 50万,它属于付费内容，用户需要付费才能收听；它的推荐分（满分10分）是85.0，它的质量分（满分10分）是8.5,它的标签包括【悬疑、惊悚】，它的内容简介如下:【 xxx】。
2. 专辑 《XXX》的ID是 7654321 ...
```

主播无作品时示例：
```
xxx 的ID为 123456，他在喜马拉雅FM平台上未发布任何作品
```

未匹配到主播时：返回空字符串。

**注意事项：**

- 如果用户输入的主播名在喜马拉雅平台不存在，将返回空结果

## searchAlbum

**功能**：专辑检索，只返回专辑列表。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyWord` | string | 是 | 搜索词 |
| `limit` | integer | 否 | 返回条数，默认10，最大30 |
| `paid` | string | 否 | `1`表示搜索付费内容，`0`表示搜索免费内容，传空表示不限 |

## searchTrack

**功能**：专辑内声音检索，根据标题搜索声音。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyWord` | string | 是 | 搜索词 |
| `albumId` | string | 否 | 指定专辑ID，在该专辑内查找 |

**回包**：格式化文本，声音列表。

示例：
```
1. 【声音ID】:123,【声音名称】：《title》, 【所属专辑ID】: 456;【所属分类】: 音乐,【播放量】: 1万;【创建时间】: 2023-01-01 00:00:00; 【标签】：tag1、tag2；
【简介】： 【内容简介...】
```

## searchFromInternet

**功能**：从互联网获取信息，天气、股票、新闻、小说信息都可以查。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyWord` | string | 是 | 搜索词 |

**回包**：格式化文本，互联网搜索结果。

示例：
```
查询 "keyword" 得到的相关资料】
【编号】:1
【标题】:xxx
【发布时间】:2023-01-01 00:00:00
【内容】：摘要内容...
【网站名称】：xxx
```

## search_track_from_album

**功能**：从指定专辑内根据关键词搜索声音。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyword` | string | 是 | 查询关键词 |
| `albumId` | string | 是 | 专辑ID |

**回包**：格式化文本，声音搜索结果。

示例：
```
搜索结果（共5个）：
1. {声音名:xxx;声音ID:123;时长:300秒;更新时间:2023年01月01日;播放量:1.0万;所属专辑:xxx(专辑ID:456);专辑主播:xxx}
```

## 工作流

1. 用户只说"搜一下 xxx"，未限定类型 → 优先用 `hubSearch`
2. 用户问"xxx主播有哪些作品"或"查一下主播xxx" → 用 `getAnchorInfo`
3. 用户明确"搜专辑" → 用 `searchAlbum`
4. 用户"在 xxx 专辑里找某条声音" → 先用 `searchAlbum` 或 `hubSearch` 获取 albumId，再用 `searchTrack` 或 `search_track_from_album`
5. 用户问天气、股票等非音频信息 → 用 `searchFromInternet`
6. 展示结果：编号列表，展示标题、主播、播放量、分类；附上跳转链接（客户端根据实际环境选择 `iting://` 或网页链接）

## 数据展示规范

- **内部标识不得暴露**：回包中的 `专辑ID`、`声音ID`、`用户ID` 等内部标识仅用于内部上下文记忆或构造深度链接，**面向用户展示时不得主动以纯文本形式暴露**。重点展示标题、主播、播放量、分类、简介等用户感知度高的信息
