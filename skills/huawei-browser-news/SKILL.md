# 新闻早报

获取并展示华为浏览器信息流早报内容，实现小艺语音助手到华为浏览器早报的流量引流。

## 领域知识

- **"消息/今日" ≠ 通用资讯**：早报语境下"消息""今日""有什么大新闻"均映射每日综合早报（userTag `01160000`），不调用通用资讯能力
- **地域/行业指令 → 每日早报**：含明确地域（"山东""美国"）或特定行业（"医药""农业"）的新闻指令按每日早报处理，不提示降级
- **"今日天气" → 天气早报**：天气类表达映射天气早报（`01170000`），不走通用天气查询
- **userTag 是云侧分类码**：`01160000` 每日 · `01150000` 国际 · `01100000` 财经 · `01110000` 体育 · `01120000` 科技 · `01130000` 汽车 · `01140000` 文娱 · `01170000` 天气
- **recommendList.tag → 推荐名称**：`1000` 财经 · `1100` 体育 · `1200` 科技 · `1300` 汽车 · `1400` 文娱 · `1500` 国际 · `1600` 综合 · `1700` 天气，未命中回退 `title`

## 方法定义（Functions）

### Function: queryNewspaper
- **functionName**: `queryNewspaper`
- **description**: 查询浏览器信息流现网新闻资讯
- **参数**: `{"type":"object","properties":{"userTag":{"type":"String","description":"早报分类"},"appId":{"type":"String","description":"固定传 xiaoyiClaw"}},"required":["userTag"]}`
- **约束**: `userTag` 必填；`appId` 固定传 `xiaoyiClaw`；调用格式 `invoke(functionName:"queryNewspaper", arguments:{bundleName:"com.huawei.hmos.browser", userTag:"<userTag>"})`
- **语义**: 返回 `errorCode`、`mainItem`（主卡片）、`recommendList`（更多推荐数组）。`mainItem` 与 `recommendList` 每条含 `title`/`tag`/`pubTime`/`source`/`deepLink`/`jumpLink`/`imageUrl`/`contentId`；`mainItem.summaries[]` 每条含 `title`/`source`/`summary`/`deepLink`/`jumpLink`。`mainItem` 为空时：先在 `recommendList` 查找 `tag == 1600` 项替换为 `mainItem` 继续展示；不存在则显示兜底语"没有查到相关资讯，过会再来看看吧"

**展示模板（展示阶段必须逐项套用，禁止自由发挥）：**

**链接取值（三处链接统一）：** 「更多详情」=`mainItem`、「查看原文」=`summaries[i]`、「查看详情」=`recommendList[i]`。每处直接原样使用该条 `jumpLink`；`jumpLink` 为空时用该条 `deepLink`。不得修改、拼接、编码或包装链接，原样复制即可。

```markdown
# <早报名称> | <M月d日> | 华为浏览器 [更多详情](<jumpLink>)

**<序号>. <新闻标题>**
来源：<新闻.source>
概述：<新闻.summary>
[查看原文](<jumpLink>)

…（新闻2、3……逐条）…

## 更多推荐

- <推荐名称> [查看详情](<jumpLink>)
- <推荐名称> [查看详情](<jumpLink>)
…
```

**字段格式：**
- **标题栏**：第一行 `# <早报名称> | M月d日 | 华为浏览器 [更多详情](<jumpLink>)`，「更多详情」链接置于标题行末尾；`<早报名称>` 用 `mainItem.tag` 映射短名称（未命中回退 `mainItem.title`）；`M月d日` 由 `mainItem.pubTime` 转换
- **新闻列表**：`mainItem.summaries[]` 逐条四行（标题行／`来源：`／`概述：`／`[查看原文]`），概述行不得省略；`jumpLink` 与 `deepLink` 均缺失才跳过「查看原文」行
- **更多推荐**：`recommendList` 逐条 `- <推荐名称> [查看详情](<地址>)`，每条都必须带链接，严禁只列名称
- **链接格式**：单行完整 markdown 链接 `[文字](url)`（`[文字]` 与 `(url)` 之间无空格、url 内部不换行），每个链接独立占一行，不与标题/来源/概述等长文本拼成超长单行；展示时只显示 `[文字]` 部分，URL 不直接出现在文案里

**正例（财经早报）：**
```markdown
# 财经早报 | 8月26日 | 华为浏览器 [更多详情](<jumpLink>)

**1. 菲律宾和俄罗斯开始出售黄金**
来源：人民日报客户端
概述：菲律宾和俄罗斯开始出售黄金
[查看原文](<jumpLink>)

## 更多推荐

- 体育早报 [查看详情](<jumpLink>)
- 汽车早报 [查看详情](<jumpLink>)
```

## 操作规程（SOP）

以下链路**必须**严格按序执行，任何步骤不可跳过、不可变序。

### SOP-1：早报查询与展示（主链路）
用户表达新闻/资讯诉求
  ↓
匹配早报类型得到 `userTag`（映射表见「领域知识」）← [映射门] **必须**，未命中或含地域/行业→`01160000`
  ↓
invoke queryNewspaper(bundleName, userTag) ← [检查门] **必须**，成功且有有效数据才继续
  ↓
按「方法定义」展示模板逐项输出 ← [展示门] **必须**，严格套用，禁止自由发挥

### SOP-2：异常与空数据兜底
调用异常、返回为空（错误码/网络异常/`mainItem` 为空）
  ↓
不展示任何卡片、不返回接口原始信息
  ↓
`mainItem` 为空时在 `recommendList` 查找 `tag == 1600` ← [过滤门] **必须**
  ↓ 存在
替换为 `mainItem`，按 SOP-1 正常展示
  ↓ 不存在
输出兜底语"没有查到相关资讯，过会再来看看吧"

### SOP-3：输出自检（展示前必须执行）
按「安全红线」逐项核对输出内容 ← [确认门] **必须**
  ↓ 任一违规项
删除违规内容后重新输出，不留痕迹

## 安全红线

1. **禁止**输出思考/推理/分析过程、字段说明、JSON 原文、中间步骤及任何过程性文字
2. **禁止**修改、拼接、编码或包装链接；`jumpLink`（缺失用 `deepLink`）原样复制
3. **禁止**输出代码块围栏、XML/HTML 标签、emoji、编号列表铺排正文
4. **禁止**出现"好的/正在/为您找到/调用/接口/返回/根据/结果如下/思考/分析"等过程词
5. **禁止**在展示文本之外裸露 JSON 键名（title/tag/source/summaries 等）或字段值
6. **禁止**硬编码凭据、密钥或绝对路径；所有链接只使用接口返回的合法 URL
7. **禁止**在输出首字符前附加任何字符/空行/开场白/结束语/解释性文字
