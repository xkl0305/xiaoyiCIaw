# 读书总结报告 PPT 生成技能

## 技能概述

**技能名称**：`reading-summary-ppt`

**核心功能**：将读书笔记（截图/文档）转化为结构化的演示文稿，清晰区分「原文精华」与「个人思考」两大模块。

## 适用场景

| 场景 | 示例 |
|------|------|
| 读书笔记截图转PPT | "根据这几张读书截图，帮我生成读书总结报告PPT" |
| 阅读摘录整理 | "把我的读书笔记整理成PPT，区分原文和我的点评" |
| 读书报告制作 | "帮我做一份《xxx》的读书报告PPT" |

## 输出结构

生成的 PPT 包含以下模块：

### 1. 开篇部分
- 封面：书名 + 章节主题
- 目录：内容导航

### 2. 原文精华（3-5页）
- 书籍/章节背景介绍
- 原文摘录（带引号标记）
- 按主题分页呈现

### 3. 个人思考（2-3页）
- 触发原文片段
- 个人观点/点评
- 深度解读与延伸

### 4. 总结部分
- 原文精华回顾表格
- 个人思考总结
- 阅读感悟

## 技术依赖

| 依赖技能 | 用途 |
|----------|------|
| `image_reading` | 解析读书笔记截图 |
| `xiaoyi-ppt` | PPT 生成服务 |
| `aigc_marker` | 添加 AIGC 合规标识 |

## 特色亮点

1. **智能区分**：自动识别原文摘录与用户批注，结构化呈现
2. **保留原味**：原文使用引用格式，保持作者原意
3. **深度思考**：个人思考部分包含观点、解读、延伸三个层次
4. **合规标识**：自动添加 AIGC 标识，符合法规要求

## 使用示例

**用户输入**：
> 根据这几个读书和笔记截图，帮我生成读书总结报告ppt，区分原文的总结和对我的点评总结

**输出结果**：
- 10页专业 PPT
- 原文精华 4 页（童年成长、触觉认知、肢体交流、母爱启蒙）
- 个人思考 2 页（职场情感表达、独特性价值）
- 总结 1 页
