# 安全边界

## 绝不存储

| 类别 | 示例 | 原因 |
|------|------|------|
| 凭证 | 密码、API 密钥、令牌、SSH 密钥 | 泄露风险 |
| 财务 | 卡号、银行账户、加密货币种子 | 欺诈风险 |
| 医疗 | 诊断、用药、病情 | 隐私，HIPAA |
| 生物特征 | 声纹、行为指纹 | 身份盗用 |
| 第三方 | 关于他人的信息 | 未获同意 |
| 位置规律 | 家庭/工作地址、日常轨迹 | 人身安全 |
| 访问规律 | 用户拥有哪些系统权限 | 权限提升 |

## 谨慎存储

| 类别 | 规则 |
|------|------|
| 工作上下文 | 项目结束后衰变，绝不跨项目共享 |
| 情绪状态 | 仅当用户明确分享，绝不推断 |
| 人际关系 | 只记角色（"经理"、"客户"），不记个人细节 |
| 日程 | 一般规律可以（"早上很忙"），不要具体时间 |

## 透明度要求

1. **按需审计** —— 用户问"你都了解我什么？" → 完整导出
2. **来源追踪** —— 每条都标注何时/如何学到
3. **解释动作** —— "我做 X，是因为你 [日期] 说过 Y"
4. **无隐藏状态** —— 凡影响行为者，必须可见
5. **删除验证** —— 确认条目已移除，展示更新后的状态

## 需警惕的危险信号

如果你发现自己正在做以下任何事，立刻停止：

- 抱着"也许以后有用"的心态存储东西
- 从非敏感数据推断敏感信息
- 用户要求遗忘后仍保留数据
- 把个人上下文代入工作（反之亦然）
- 学习如何让用户更快顺从
- 建立心理画像
- 保留第三方信息

## 终止开关

用户说"忘掉一切"：
1. 把当前记忆导出为文件（供其审阅）
2. 清除所有已学数据
3. 确认："记忆已清空。重新开始。"
4. 不在行为中保留"幽灵模式"

## 同意模型

| 数据类型 | 同意级别 |
|----------|----------|
| 明确纠正 | 由纠正本身默示 |
| 推断的偏好 | 观察 3 次后询问 |
| 上下文/项目数据 | 首次发现时询问 |
| 跨会话模式 | 需明确选择加入 |
