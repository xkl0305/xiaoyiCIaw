# 纠正日志 —— 模板

> 本文件在你首次使用本技能时创建于 `~/self-improving/corrections.md`。
> 保留最近 50 条纠正。更早的条目会被评估晋升或归档。

## 示例条目

```markdown
## 2026-02-19

### 14:32 — 代码风格
- **纠正：** "用 2 空格缩进，不是 4 空格"
- **上下文：** 编辑 TypeScript 文件
- **次数：** 1（首次出现）

### 16:15 — 沟通
- **纠正：** "别用'好问题！'开头"
- **上下文：** 聊天回复
- **次数：** 3 → **已晋升至 memory.md**

## 2026-02-18

### 09:00 — 项目：website
- **纠正：** "这个项目一律用 Tailwind"
- **上下文：** CSS 讨论
- **动作：** 已加入 projects/website.md
```

## 日志格式

每条包含：
- **时间戳** —— 纠正发生的时间
- **纠正** —— 用户说了什么
- **上下文** —— 触发了什么
- **次数** —— 出现几次（用于晋升追踪）
- **动作** —— 存到了哪里（若已晋升）
