# 自我反思日志

追踪已完成工作的自我反思。每条记录智能体通过评估自身输出所学到的东西。

## 格式

```
## [日期] — [任务类型]

**我做了什么：** 简要描述
**结果：** 发生了什么（成功、部分、失败）
**反思：** 我对自己工作的观察
**教训：** 下次怎么做不同
**状态：** ⏳ 候选 | ✅ 已晋升 | 📦 已归档
```

## 示例条目

```
## 2026-02-25 — 构建 Flutter 界面

**我做了什么：** 用开关控件做了一个设置页
**结果：** 用户说"间距看起来不对"
**反思：** 我只关注了功能，没视觉检查成品
**教训：** 给用户看之前，永远先截图并评估视觉平衡
**状态：** ✅ 已晋升至 domains/flutter.md
```
