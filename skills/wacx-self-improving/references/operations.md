# 记忆操作

## 用户命令

| 命令 | 动作 |
|------|------|
| "你都了解 X 什么？" | 搜索所有层级，返回带来源的匹配 |
| "看看我的记忆" | 展示 memory.md 内容 |
| "看看 [项目] 模式" | 加载并展示特定命名空间 |
| "忘掉 X" | 从所有层级移除，确认删除 |
| "忘掉一切" | 完整清除，提供导出选项 |
| "最近改了什么？" | 展示最近 20 条纠正 |
| "导出记忆" | 生成可下载归档 |
| "记忆状态" | 展示各层级大小、上次压缩、健康度 |

## 自动操作

### 会话开始时
1. 加载 memory.md（热层）
2. 检查 index.md 寻找上下文提示
3. 若检测到项目 → 预加载相关命名空间

### 收到纠正时
```
1. 解析纠正类型（偏好、模式、覆盖）
2. 检查是否重复（存在于任何层级）
3. 若是新的：
   - 带时间戳加入 corrections.md
   - 纠正计数 +1
4. 若是重复：
   - 计数 +1，更新时间戳
   - 若计数 >= 3：询问是否确认为规则
5. 确定命名空间（全局、领域、项目）
6. 写入相应文件
7. 更新 index.md 行数
```

### 模式匹配时
应用已学模式时：
```
1. 找到模式来源（文件:行号）
2. 应用模式
3. 标注来源："使用 X（来自 memory.md:15）"
4. 记录使用用于衰变追踪
```

### 每周维护（定时任务）
```
1. 扫描所有文件寻找衰变候选
2. 把 >30 天未用的移入温层
3. 把 >90 天未用的归档至冷层
4. 若任何文件超限则执行压缩
5. 更新 index.md
6. 生成每周摘要（可选）
```

## 文件格式

### memory.md（热层）
```markdown
# 自我进化记忆

## 已确认偏好
- 格式：要点优于段落（2026-01 确认）
- 语气：直接，不回避（2026-01 确认）

## 活跃模式
- "看起来不错" = 批准继续（已用 15 次）
- 单个 emoji = 已知悉（已用 8 次）

## 近期（最近 7 天）
- MVP 优先用 SQLite（02-14 纠正）
```

### corrections.md
```markdown
# 纠正日志

## 2026-02-15
- [14:32] 把啰嗦解释改为要点摘要
  类型：沟通
  上下文：Telegram 回复
  已确认：pending (1/3)

## 2026-02-14
- [09:15] MVP 用 SQLite 而非 Postgres
  类型：技术
  上下文：数据库讨论
  已确认：yes（说过"永远"）
```

### projects/{name}.md
```markdown
# 项目：my-app

继承：全局、domains/code

## 模式
- 用 Tailwind（项目标准）
- 不用 Prettier（仅 eslint）
- 通过 GitLab CI 部署

## 覆盖
- 分号：用（覆盖全局不用分号）

## 历史
- 创建：2026-01-15
- 最近活跃：2026-02-15
- 纠正数：12
```

## 边界情况处理

### 检测到矛盾
```
模式 A："用 Tab"（全局，已确认）
模式 B："用空格"（项目，今天纠正）

解决：
1. 项目覆盖全局 → 本项目用空格
2. 在 corrections.md 记录冲突
3. 询问："空格只用于本项目，还是处处适用？"
```

### 用户改主意
```
旧："永远用正式语气"
新："其实，随意点也行"

动作：
1. 带时间戳归档旧模式
2. 把新模式作为试探性加入
3. 保留归档供参考（"你之前偏好正式"）
```

### 上下文模糊
```
用户说："记一下我喜欢 X"

但属于哪个命名空间？
1. 检查当前上下文（项目？领域？）
2. 若不清楚，询问："全局适用，还是仅此处？"
3. 默认最具体的活跃上下文
```
