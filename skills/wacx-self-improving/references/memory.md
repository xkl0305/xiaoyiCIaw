> 本文件在你首次使用本技能时创建于 `~/self-improving/memory.md`。
> 控制在 ≤100 行。最常用的模式放在这里。

## 示例条目

```markdown

- 代码风格：显式优于隐式
- 沟通：直接，不啰嗦
- 时区：Europe/Madrid

## 模式（从纠正晋升而来）
- 一律使用 TypeScript 严格模式
- 优先 pnpm 而非 npm

## 项目默认值
- 测试：Jest，覆盖率 >80%
- 提交：约定式提交格式
```

## 用法

智能体会：
1. 每个会话都加载本文件
2. 当某模式 7 天内被使用 3 次时新增条目
3. 30 天未用的条目降级至温层
4. 绝不超出 100 行（自动压缩）
