# 🎨 主题包系统 v2.5

## ✨ 什么是主题包？

主题包是一个完整的世界观套装，让用户可以完全自定义手账的呈现方式。核心设计理念：

> **内核永远固定（卡路里计算），外壳可自由更换（展示方式）**

## 🧩 字符手账主题架构 (text_handbook_generator.py)

### 硬编码设计理念
> v2.5字符手账系统采用**硬编码THEMES字典**设计，符合Skill项目"零配置启动"的最佳实践。

**为什么用硬编码？**
- ✅ 零依赖，启动即运行
- ✅ 性能最优，无文件IO
- ✅ 版本一致性，避免JSON文件丢失或损坏
- ✅ Skill发布时更可靠

### THEMES字典结构
```python
THEMES = {
    'healing_forest': {...},      # 治愈森林
    'space_explorer': {...},      # 星际探索
    'dragon_new_year': {...},     # 龙年新春
}
```

### 新增主题方法（3步完成）
1. 在THEMES字典中新增主题配置（复制现有主题修改）
2. 在get_attribute_type()中新增属性分类逻辑
3. 在各处if theme == 'xxx'分支中添加新主题的处理

## 💡 核心特性

### 1. 三系统独立但统一
每个主题有自己的：
- **命名系统**：7张卡片标题、5项营养术语
- **属性系统**：4种分类 + 智能推断规则
- **话术系统**：7张卡片陪伴语录
- **角色系统**：角色名 + 图标 + 陪伴文案
- **贴纸系统**：主题专属贴纸组合

### 2. 对比展示
- 📊 **原始数据手账**：纯数据，所有主题都一样
- ✨ **主题化手账**：经过命名、话术、分类优化的专属手账
- 用户一眼就能看到主题包带来的差异

### 3. 智能分类引擎
每张餐卡基于营养数据自动分类：
- 治愈森林：碳水 > 40g = 开心食物，蛋白质 > 20g = 能量食物
- 星际探索：热量 > 550kcal = 高燃燃料，蛋白质 > 25g = 星际补给
- 龙年新春：热量 > 550kcal = 开运美食，蛋白质 > 25g = 吉祥佳肴

## ⚠️ 注意：两套系统并行

v2.5目前存在**两套独立的手账系统**：

| 系统 | 入口文件 | 主题存储方式 | 适用场景 |
|-----|---------|------------|---------|
| 📝 字符手账系统 | text_handbook_generator.py | 硬编码THEMES字典 | Skill发布、快速演示 |
| 🖼️ 图片手账系统 | gen_card.py | JSON文件 + loader | 本地运行、自定义扩展 |

**两套系统内核一致（卡路里计算），仅展示层不同。**
