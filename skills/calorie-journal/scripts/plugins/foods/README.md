# 食物数据扩展包目录

把你的扩展数据JSON文件放到这个目录下，系统会自动加载！

---

## 📦 扩展包格式规范

```json
{
  "name": "扩展包名称",
  "version": "1.0",
  "description": "描述信息",
  "author": "作者名称（可选）",
  "foods": {
    "食物名称": {
      "cal": 热量值,
      "protein": 蛋白质值,
      "fat": 脂肪值,
      "carbs": 碳水化合物值,
      "fiber": 膳食纤维值,
      "source": "数据来源（如：中国食物成分表第6版）"
    }
  }
}
```

## 🎯 官方推荐扩展包

### 1. 中国疾控中心食物成分表扩展包

**文件命名**：`cdc_food_database.json`

**数据来源**：中国疾病预防控制中心营养与健康所
- 官方查询平台：https://fq.chinafcd.org
- 书籍：《中国食物成分表 标准版 第6版》

**包含数据**：1300+ 种中国常见食物营养数据

---

### 2. 地方特色美食扩展包（示例）

**文件命名**：`local_specialty_foods.json`

**包含数据**：地方特色菜肴、小吃、民族食品等

## 💡 使用示例

### 第一步：创建你的扩展数据文件

例如创建 `my_foods.json`：

```json
{
  "name": "我的私人食物数据库",
  "version": "1.0",
  "description": "我常吃的一些食物数据",
  "author": "你的名字",
  "foods": {
    "兰州拉面": {
      "cal": 120,
      "protein": 6.0,
      "fat": 3.5,
      "carbs": 20.0,
      "fiber": 1.2,
      "source": "中国食物成分表第6版"
    },
    "热干面": {
      "cal": 153,
      "protein": 4.4,
      "fat": 5.8,
      "carbs": 22.1,
      "fiber": 1.5,
      "source": "中国食物成分表第6版"
    }
  }
}
```

### 第二步：放入本目录

将 `my_foods.json` 复制到 `plugins/foods/` 目录下

### 第三步：重启引擎

系统会自动检测并加载，无需修改代码！

## ⚠️ 注意事项

1. **版权声明**：《中国食物成分表》数据版权属于中国疾病预防控制中心营养与健康所，个人非商业用途可自由使用
2. **数据格式**：确保JSON格式正确，所有数值单位为 **每100克**
3. **不覆盖原则**：扩展数据不会覆盖核心内置的100种食物，核心数据优先级更高
4. **命名冲突**：多个扩展包包含同一食物时，以先加载的为准
