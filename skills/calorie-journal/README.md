## 🎨 完整主题包系统（核心卖点）

### 什么是主题包？

一个完整的世界观套装，用户可以100%自定义生成属于自己的手账风格。每个主题包包含6大模块，全部通过JSON配置，零代码即可完成：

| 模块 | 配置文件 | 可自定义内容 |
|---|---|---|
| 📝 命名系统 | `naming.json` | 7张卡片标题、5大营养素名称和图标 |
| 🎭 角色设定 | `character.json` | 陪伴角色、性格、台词、触发条件 |
| 😊 情绪分类 | `emotion.json` | 食物情绪分类名称、颜色、匹配规则 |
| 💬 话术系统 | `quotes.json` | 治愈语录库、场景化暖心文案 |
| 🎨 视觉风格 | `style.json` | 配色方案、字体、布局 |
| 🎪 贴纸库 | `stickers.json` | 贴纸种类、样式、触发条件 |

### 如何制作你的专属主题？

```bash
# 1. 复制内置主题模板
cp -r scripts/theme_packs/default scripts/theme_packs/my_amazing_theme

# 2. 修改6个JSON配置文件
# 零代码，只需编辑文本

# 3. 一键加载使用
loader.load_theme("my_amazing_theme")
```

**完整制作指南：** `scripts/theme_packs/HOW_TO_MAKE_THEME.md`

## 📦 功能模块导航（4大系统 × 12项核心能力）

### 1. 🎨 卡片生成系统
**何时调用**：用户描述餐食后自动生成卡片
**核心能力**：
- 7张公交卡式精美卡片（早餐/午餐/加餐1/加餐2/运动/基础消耗/总结）
- 5大类纯代码手绘贴纸（装饰/主题/食物/运动/状态）
- 2套内置主题系统（治愈森林 / 星际探索）
- 治愈系3档文案：探索中 / 刚刚好 / 很充足 / 很满足
**详见**：`scripts/gen_card.py`

---

### 2. 🧠 食物理解系统
**何时调用**：识别食物名称、计算营养、匹配情绪标签
**核心能力**：
- 7级智能搜索Fallback架构（逐级降级永不失败）
- 食物情绪占星师（6种情绪分类，基于营养学权威依据）
- 疾控中心1300+种食物数据可插拔扩展（中国食物成分表第6版）
- TianAPI可插拔集成（中文家常菜/外卖全覆盖）
- 烹饪方式系数修正 + 外卖加成系数自动估算
**详见**：`scripts/food_search_engine.py` / `scripts/search_engine_v2.py`

---

### 3. 🐾 陪伴互动系统
**何时调用**：生成总结卡片时自动匹配
**核心能力**：
- 7只食物小动物盲盒（基于当日真实营养数据动态匹配）
- 运动温和提醒机制（基于WHO《身体活动指南2020》）
- 温暖陪伴语录（每餐一句治愈文案）
- 完整情绪统计（所有分类完整显示，动态布局适配）
**详见**：`scripts/animal_blind_box.py` / `scripts/food_mood_analyzer.py`

---

### 4. 🧪 质量保障系统
**何时调用**：每次生成前自动运行，无需额外操作
**核心能力**：
- 7维度数据完整性自检（平台/尺寸/结构/类型/范围/合理性/分级）
- 100%跨平台兼容（零Emoji字体依赖，Linux/Windows/Mac全适配）
- 营养目标权威校准（基于《中国居民膳食指南2022》蛋白质1.5g/kg标准）
- 贴纸布局全局优化（统一右上角，永不遮挡文字）
**详见**：`scripts/gen_card.py`（DataSelfChecker类）

- 温暖治愈的饮食记录体验

**有什么数据，生成什么卡片

- 今天没运动？不显示运动卡
- 吃了5顿？生成5张卡
- 数据越少，页面越干净

拒绝冗余，拒绝为了凑数而生成无意义的内容。
