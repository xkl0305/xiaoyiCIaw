## 📦 食物数据扩展系统

### 设计理念

我们默认只内置100种最常见食物，这是一个**权衡决策**：
- ✅ 覆盖90%日常饮食场景
- ✅ 毫秒级查询速度
- ✅ 零网络依赖
- ✅ 项目体积极小

对于需要更多食物数据的高级用户，我们提供了**可插拔的扩展系统**。

---

### 快速开始：3步启用疾控中心完整数据

#### 第1步：准备扩展数据文件

将你的食物数据整理为JSON格式，放入 `scripts/plugins/foods/` 目录。

**文件格式**：

```json
{
  "name": "我的食物扩展包",
  "version": "1.0",
  "description": "描述",
  "foods": {
    "食物名称": {
      "cal": 热量(kcal/100g),
      "protein": 蛋白质(g/100g),
      "fat": 脂肪(g/100g),
      "carbs": 碳水化合物(g/100g),
      "fiber": 膳食纤维(g/100g),
      "source": "数据来源"
    }
  }
}
```

💡 **提示**：我们已经在目录中提供了 `cdc_food_database_sample.json` 示例文件，包含20种来自疾控中心的食物数据，你可以参考其格式。

#### 第2步：放入扩展目录

将你的JSON文件复制到：

```
scripts/
└── plugins/
    └── foods/               ← 把JSON文件放在这里
        ├── README.md
        └── your_data.json  ← 你的扩展文件
```

#### 第3步：自动加载

系统会在启动时**自动检测并加载**该目录下的所有JSON文件。无需修改任何代码！

## 🔌 TianAPI 高级配置

### 什么是TianAPI

天聚数行TianAPI是国内专业的食物营养数据API服务，支持：
- ✅ 家常菜、外卖识别
- ✅ 10000+种中文食物覆盖
- ✅ 图片识别功能
- ✅ 免费额度可供个人使用

### 获取API Key

1. 访问：https://www.tianapi.com
2. 注册账号
3. 找到「食物营养成分」API
4. 申请获取你的API Key

### 在项目中配置

**方式1：运行时动态配置（推荐）**

```python
from search_engine_v2 import FoodSearchEngineV2

engine = FoodSearchEngineV2()
engine.set_tianapi_key("你的API_KEY_HERE")
```

**方式2：环境变量配置**

```bash
# Linux/Mac
export TIANAPI_KEY="你的API_KEY_HERE"

# Windows
set TIANAPI_KEY="你的API_KEY_HERE"
```

### 成本控制

TianAPI的免费额度对于个人日常使用完全足够。如果超出：
- 按量付费价格低廉（几分钱一次调用）
- 可以随时关闭：`engine.set_tianapi_enabled(False)`
- 系统会自动降级到下一级数据源，用户无感知

## ⚡ 性能优化建议

### 扩展食物数量建议

| 扩展食物数量 | 查询速度 | 内存占用 | 推荐场景 |
|---|---|---|---|
| 0-500种 | <1ms | <1MB | ✅ 推荐 |
| 500-1000种 | 1-2ms | 1-2MB | 🟡 可以接受 |
| 1000种以上 | 2-5ms | 2-5MB | ⚠️ 不推荐 |

> 💡 **建议**：即使扩充也控制在500种以内，只添加你真正常用的食物。数据再多，90%场景下你还是只用那几十种。

## ❓ 常见问题

### Q1：添加扩展数据后会影响原有功能吗？

**A**：不会！扩展系统采用「非侵入式设计」：
- ✅ 扩展数据不会覆盖核心内置食物
- ✅ 核心100种食物优先级最高
- ✅ 即使扩展数据有问题，核心功能不受影响
- ✅ 随时可以删除扩展文件恢复默认状态

---

### Q2：TianAPI调用失败怎么办？

**A**：系统会自动降级，用户完全无感知：

```
查询失败 → 自动切换到Open Food Facts → 自动切换到智能估算
```

整个过程毫秒级完成，用户不会察觉到任何异常。

---

### Q3：可以同时加载多个扩展包吗？

**A**：可以！系统会自动加载 `plugins/foods/` 目录下所有 `.json` 文件：

```
plugins/foods/
├── cdc_food_database.json   # 疾控中心数据
├── local_specialty.json     # 地方特色菜
└── my_favorites.json        # 我常吃的食物
```

如果多个包包含同一食物，以先加载的为准。

---

### Q4：如何临时禁用某个扩展包？

**A**：两种方式：
1. 将文件后缀改为 `.json.disabled`
2. 直接删除该文件

系统只会加载 `.json` 后缀的文件。

---

### Q5：升级项目版本时，我的扩展数据会丢失吗？

**A**：不会！`plugins/` 目录是用户专属目录，升级项目时：
- ✅ 不会覆盖用户的扩展数据
- ✅ 可以完整保留你的私有数据
- ✅ 版本升级不影响数据兼容性
