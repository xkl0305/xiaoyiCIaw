# V111.23 总复扫报告

## 这次发现的核心问题

1. 人格视觉虽然已经有 semantic_scene，但实际触发入口仍主要读取 `message`，也就是偏向用户输入。
2. `persona_visual_intent_predictor.py` 仍以 phrase contains 为主，近似词/用户说话习惯覆盖不够。
3. `NO_EXTERNAL_API / OFFLINE_MODE` 与用户的日常模式冲突；用户要求一直在线、端侧能力和小艺能力常连，不要每次都授权在线。
4. `scene_image_detector.py` 仍可保留为可选图像理解，但不是人格视觉自动出图主触发链。

## 本次 V111.23 已处理

1. 新增 `persona_visual_turn_observer.py`：优先观察龙虾/assistant 输出，再回退用户输入。
2. 升级 `persona_visual_intent_predictor.py`：加入近似词、别称、模糊匹配，不再死卡一个词。
3. 修改 `mainline_hook.py`：支持 `assistant_message / lobster_message / reply_text` 自动触发。
4. 修改 `persona_visual_auto_generation_bridge.py`：根据 observer 选择的文本触发出图，保留头像种子图强一致。
5. 新增 `online_runtime_policy.py`：默认一直在线、端侧和小艺能力常连、无逐项在线授权。
6. 修改 `openclaw.json`：`NO_EXTERNAL_API=false`、`OFFLINE_MODE=false`、`ONLINE_MODE=true`、`CONNECTED_RUNTIME_ALWAYS_ON=true`。
7. 新增 V111.23 gate，验证 assistant/lobster 输出能自动触发。

## 仍保留的合理项

- 支付、删除、签署等高风险动作仍应保留治理门，不等于彻底无确认。
- seedream 真实生成仍需要 provider 凭证；缺凭证时只允许安全失败，不允许伪造生成图。
