# 嵌套环形图 `[chart t:doughnut]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。支持多层嵌套环形，每层独立数据和标签。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:doughnut` | 必填 | - |
| `d:` | 单层 `v1,v2,v3`；多层 `v1,v2\|v3,v4,v5`（`\|` 分层） | - |
| `l:` | 标签（多层用 `\|` 分隔） | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 单层环形

```tokui
[chart t:doughnut l:"手机,电脑,平板" d:"45,35,20" c:"#1677FF,#52C41A,#FAAD14" h:350 title:"设备占比" /]
```

### 2. 双层嵌套（`\|` 分隔内外层）

```tokui
[chart t:doughnut l:"手机,电脑,平板|iOS,Android,Windows,Linux" d:"40,35,25|30,45,15,10" h:400 legend title:"设备与系统嵌套" /]
```

### 3. 三层嵌套

```tokui
[chart t:doughnut l:"A类,B类|A1,A2,B1,B2|细节1,细节2,细节3,细节4,细节5,细节6" d:"60,40|35,25,20,20|10,25,15,10,20,20" h:450 legend title:"三层嵌套分布" /]
```
