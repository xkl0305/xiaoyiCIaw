# 02 - 状态、反馈与交互组件

> ⚠️ 本分册穷举所有状态反馈与交互组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `callout` | 自闭合/容器 | `t`, `tt`, `tx`/裸内容 | 警示框。`t`：`info`/`success`/`warning`/`error`/`tip` |
| `spin` | 自闭合 | `t`, `s`, `tx` | 加载指示器。`t`：`spinner`/`dots`/`pulse` |
| `skeleton` | 自闭合 | `t`, `rows`, `w`, `h` | 骨架屏。`t`：`text`/`card`/`avatar`/`image` |
| `shimmer` | 自闭合 | `t`, `rows` | 闪光骨架。`t`：`text`/`card`/`avatar` |
| `empty` | 自闭合 | `tx`, `icon`, `s` | 空状态。`icon`：`default`/`box`/`folder`/`search`；`s` 自定义图源 |
| `result` | 自闭合 | `t`, `tt`, `tx` | 结果页。`t`：`success`/`error`/`warning`/`info` |
| `barcode` | 自闭合 | `tx`, `l`, `s` | Code128 条码。`s`：`sm`/`md`/`lg` |
| `qrcode` | 自闭合 | `tx`, `l`, `s`, `ec` | QR 二维码。`ec`：`L`/`M`/`Q`/`H` |
| `dot` | 自闭合 | `t`, `tx`, `s`, `pulse` | 状态点。`t`：`success`/`warning`/`error`/`info`/`primary` |
| `badge` | 自闭合 | `count`, `overflow`, `dot`, `t`/`status`, `tx`, `pill`, `size`, `title` | 徽标 |
| `badge-box` | 容器 | `t`/`status`, `dot`, `count`, `overflow`, `tx`/`label`, `size` | 包裹子元素+角标 |
| `toast` | 自闭合 | `id`, `t`, `tx`, `duration`, `pos` | 全局 Toast。`pos`：`top`/`bottom` |
| `notification` | 自闭合 | `id`, `t`, `tt`, `tx`, `duration`, `pos`, `clk` | 全局通知。`pos`：`top-right`/`top-left`/`bottom-right`/`bottom-left` |
| `progress` | 自闭合 | `v`, `t`, `l`, `s`, `stripe`, `status`, `id` | 进度条。`v` 0-100；`t`：`line`/`circle`/`span`；`status`：`success`/`error` |
| `stat` | 自闭合 | `tt`, `v`, `pre`, `suf`, `trend`, `anim`, `dec`, `id` | 统计数字。`trend`：`up`/`down` |
| `countdown` | 自闭合 | `target`/`dur`, `fmt`, `tx`, `l`, `s`, `clk`, `id` | 倒计时。`fmt`：`dhms`/`hms`/`ms`/`s` |
| `thumb` | 自闭合 | `t`, `v`, `s`, `clk` | 赞/踩。`t`：`up`/`down` |
| `toggle` | 自闭合 | `tx`, `chk`, `clk`, `s`, `dis` | 切换按钮 |
| `toggle-group` | 容器 | `multi`, `s`, `clk` | 切换按钮组。子项 `toggle` |
| `copy` | 自闭合 | `id`, `tx`, `tt` | 复制到剪贴板 |
| `upd` | 自闭合 | `id` + 更新键 | 动态更新已渲染组件（详见公共规范 §8） |
| `tooltip` | 自闭合 | `tt`, `pos`, `tx`/裸内容 | 文字提示。`pos`：`top`/`bottom`/`left`/`right` |
| `popover` | 容器 | `tx`, `tt`, `pos`, `w`, `trig` | 气泡卡片。`trig`：`click`/`hover` |
| `popconfirm` | 自闭合 | `tt`, `tx`, `clk`, `t`, `pos`, `ok-text`, `cancel-text` | 确认气泡 |
| `hover-card` | 容器 | `pos`, `w`, `delay` | 悬停卡片。子项 `hover-trigger` + `hover-content` |
| `hover-trigger` | 容器 | — | `hover-card` 触发区 |
| `hover-content` | 容器 | — | `hover-card` 内容区 |
| `input-tag` | 容器 | `ph`, `n`, `id`, `max`, `tags`, `clk`, `l` | 标签输入框 |
| `dropdown` | 容器 | `tx`/`tt`, `v` | 下拉菜单。子项 `dd-item` |
| `dd-item` | 自闭合 | `tx`, `clk`, `dis`, `v` | 下拉菜单项 |
| `backtop` | 自闭合 | `t`, `v`, `tx`, `s`, `bottom`, `right`, `container` | 回到顶部 |
| `pagination` | 自闭合 | `page`, `total`, `count`, `show-total`, `s`, `clk` | 分页 |
| `breadcrumb` | 自闭合 | `items`, `sep`, `clk`, `v` | 面包屑。`items` 逗号路径 |
| `calendar` | 自闭合 | `month`, `v`, `tt`, `marks`, `sel`/`selected`, `range`, `ranges` | 日历 |
| `watermark` | 容器 | `tx`, `s`, `font`, `c`, `gap`, `ro` | 水印 |
| `avatar` | 自闭合 | `s`, `tx`, `size`, `bg`, `fc` | 头像 |
| `file` | 自闭合 | `n`, `s`, `t`, `u`, `tt` | 文件卡片。`t`：`pdf`/`word`/`excel`/`ppt`/`image`/`zip`/`code`/`default` |
| `chat-input` | 容器 | `ph`, `clk`, `dis`, `max`, `auto`, `rows` | 对话输入框 |
| `msg-actions` | 容器 | `clk`, `copy`, `regenerate`, `like`/`dislike`, `delete`, `visible` | 消息操作栏 |

---

## DSL 示例

```
[callout t:info tx:这是一条提示信息]
[callout t:warning tt:警告 请注意操作安全][/callout]

[progress v:75 l:上传进度 stripe id:up1]
[stat v:12580 tt:总用户 l:+12% trend:up]
[dot t:success tx:运行中 pulse]

[badge count:5 tx:消息]
[empty tx:暂无数据 icon:search]

[dropdown tx:请选择]
[dd-item tx:选项A clk:optA]
[dd-item tx:选项B clk:optB]
[/dropdown]

[breadcrumb items:"首页,产品,详情" sep:">"]
[pagination page:1 total:100 count:10 clk:onPage]
```
