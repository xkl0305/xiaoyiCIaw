# 热力图 `[chart t:heatmap]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。用颜色深浅表示数值大小。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:heatmap` | 必填 | - |
| `d:` | 矩阵数据，逗号分隔，按行展开 | - |
| `rows:` | 行标签，逗号分隔 | - |
| `cols:` | 列标签，逗号分隔 | - |
| `l:` | 等同 `rows:`（行标签别名） | - |
| `min:` | 最小值（色阶起点） | 自动 |
| `max:` | 最大值（色阶终点） | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

---

## DSL 示例

### 1. 基础热力图（3×3 矩阵）

```tokui
[chart t:heatmap d:"1,2,3,4,5,6,7,8,9" rows:"行1,行2,行3" cols:"列A,列B,列C" h:300 title:"基础矩阵" /]
```

### 2. 自定义色阶范围

```tokui
[chart t:heatmap d:"10,25,35,40,55,60,70,85,95,30,45,50" rows:"Q1,Q2,Q3,Q4" cols:"华东,华南,华北" min:0 max:100 h:350 title:"区域季度完成率" /]
```

### 3. 用 `l:` 代替 `rows:`

```tokui
[chart t:heatmap d:"5,8,3,7,2,9,6,4,1" l:"周一,周二,周三" cols:"上午,下午,晚上" h:300 title:"活跃度热力" /]
```
