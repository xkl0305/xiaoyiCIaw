# 03 - 思考与计划组件

> ⚠️ 本分册穷举所有思考与计划组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `think` | 容器 | `tt`, `open` | 思考块（折叠），默认展开 |
| `think-chain` | 容器 | `tt`, `status`, `open` | 推理链。`status`：`running`/`done` |
| `think-step` | 容器 | `status`, `tt`, `dur` | 推理步骤。`status`：`done`/`running`/`pending`/`error` |
| `plan` | 容器 | `tt` | 执行计划。子项 `plan-step` |
| `plan-step` | 自闭合 | `status`, `tt`, `desc` | 计划步骤。`status`：`pending`/`doing`/`done`/`error`/`skipped` |
| `agent` | 容器 | `name`, `status`, `action`, `duration`, `id` | 智能体状态。`status`：`idle`/`running`/`paused`/`done`/`error` |

---

## DSL 示例

```
[think tt:分析过程]
[p 用户需要一个数据看板...]
[/think]

[think-chain tt:推理链 status:running]
[think-step tt:理解需求 status:done dur:1.2s]
[think-step tt:设计方案 status:running]
[think-step tt:生成代码 status:pending]
[/think-chain]

[plan tt:执行计划]
[plan-step tt:初始化项目 status:done]
[plan-step tt:实现核心功能 status:doing]
[plan-step tt:编写测试 status:pending]
[plan-step tt:部署上线 status:pending]
[/plan]

[agent name:助手 status:running action:分析数据 id:ag1]
```
