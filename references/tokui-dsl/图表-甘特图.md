# 甘特图 `[chart t:gantt]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。展示项目任务的时间安排和进度。

数据通过 `tasks:` 属性提供（**不用 `d:`**）。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:gantt` | 必填 | - |
| `tasks:` | 任务数据 `名称,开始,结束,进度\|名称,开始,结束,进度`（`\|` 分任务，`,` 分字段） | - |
| `l:` | 列头标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `mode:` | 时间刻度：`day`/`week`/`month` | `day` |
| `start:` | 项目开始日期（如 `2025-06-01`） | 自动 |
| `end:` | 项目结束日期 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

## 容器模式

省略 `tasks:`，用子节点声明：

| 子节点 | 说明 |
|--------|------|
| `[task name:名称 start:天数 end:天数 progress:百分比/]` | 一个任务条 |
| `[ms name:名称 date:日期/]` | 里程碑标记 |

---

## DSL 示例

### 1. 基础甘特图（属性模式，`tasks:` 用 `\|` 分任务）

```tokui
[chart t:gantt tasks:"需求分析,0,5,100|UI设计,3,8,80|前端开发,5,15,50|后端开发,5,18,30|测试验收,15,20,0" h:400 title:"项目进度" /]
```

### 2. 指定时间范围 + 周视图

```tokui
[chart t:gantt tasks:"策划,0,7,100|设计,5,14,60|开发,10,30,25|测试,25,35,0" start:2025-07-01 end:2025-08-15 mode:week h:400 title:"产品迭代计划" /]
```

### 3. 容器模式（子节点声明 + 里程碑）

```tokui
[chart t:gantt h:400 title:"项目甘特图"
  [task name:"需求分析" start:0 end:5 progress:100/]
  [task name:"UI设计" start:3 end:8 progress:80/]
  [task name:"前端开发" start:5 end:15 progress:50/]
  [task name:"后端开发" start:5 end:18 progress:30/]
  [task name:"测试验收" start:15 end:20 progress:0/]
  [ms name:"上线发布" date:2025-06-30/]
]
```

### 4. 自定义颜色

```tokui
[chart t:gantt tasks:"第一阶段,0,10,100|第二阶段,8,20,60|第三阶段,18,30,20" c:"#1677FF,#52C41A,#FAAD14" h:350 title:"阶段规划" /]
```
