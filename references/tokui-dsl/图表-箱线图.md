# 箱线图 `[chart t:box]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。展示数据的统计分布（五数概括）。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:box` | 必填 | - |
| `d:` | `min,q1,med,q3,max;min,q1,med,q3,max`（`;` 分组，`,` 分五值） | - |
| `l:` | 组标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

---

## DSL 示例

### 1. 基础箱线图（每组五个值：最小值, Q1, 中位数, Q3, 最大值）

```tokui
[chart t:box l:"A组,B组,C组" d:"1,5,10,15,20;2,6,12,18,25;3,8,14,20,28" h:400 title:"成绩分布" /]
```

### 2. 自定义颜色

```tokui
[chart t:box l:"2023年,2024年" d:"10,25,50,75,90;15,30,55,80,95" c:"#1677FF,#52C41A" h:400 title:"年度对比" /]
```

### 3. 多组数据

```tokui
[chart t:box l:"产品A,产品B,产品C,产品D" d:"5,15,25,35,50;10,20,30,40,55;8,18,28,38,48;12,22,32,42,52" c:"#FF4D4F,#1677FF,#52C41A,#FAAD14" h:450 title:"产品评分分布" /]
```
