# 进度环 `[chart t:progress]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。显示百分比的圆环。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:progress` | 必填 | - |
| `d:` | 百分比数值（0~100） | - |
| `c:` | 主色（`#` 开头） | 自动 |
| `thickness:` | 环宽（px） | `20` |
| `show-value` | 显示百分比数值 | `true` |
| `label:` | 底部标签文字 | - |

> 另支持通用属性：`title:`、`w:`、`h:`。

---

## DSL 示例

### 1. 基础进度环

```tokui
[chart t:progress d:68 h:200 c:"#52C41A" label:"完成进度" /]
```

### 2. 自定义环宽 + 颜色

```tokui
[chart t:progress d:85 thickness:30 h:250 c:"#1677FF" label:"下载进度" /]
```

### 3. 隐藏数值只显示标签

```tokui
[chart t:progress d:42 show-value:false h:180 c:"#FAAD14" label:"审核中" /]
```

### 4. 满进度（100%）

```tokui
[chart t:progress d:100 h:200 c:"#52C41A" label:"已完成" /]
```
