# 饼图 `[chart t:pie]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:pie` | 必填 | - |
| `d:` | `v1,v2,v3` | - |
| `l:` | 标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `size:` | 饼图大小比例（0~1） | `0.8` |
| `label-pos:` | 标签位置：`outside`/`inside`/`none` | `outside` |
| `leader-line` | 显示引导线（标签在外时有效） | `false` |
| `show-percent` | 显示百分比 | `false` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础饼图

```tokui
[chart t:pie l:"直接访问,邮件营销,联盟广告,视频广告,搜索引擎" d:"335,310,234,135,1548" h:400 title:"访问来源" /]
```

### 2. 自定义颜色 + 图例

```tokui
[chart t:pie l:"技术部,市场部,运营部,财务部" d:"40,25,20,15" c:"#1677FF,#52C41A,#FAAD14,#FF4D4F" h:400 legend title:"人员分布" /]
```

### 3. 标签在内 + 显示百分比

```tokui
[chart t:pie l:"手机,电脑,平板,其他" d:"45,30,15,10" label-pos:inside show-percent h:400 title:"设备占比" /]
```

### 4. 引导线 + 标签在外

```tokui
[chart t:pie l:"华东,华南,华北,西南,西北" d:"350,280,220,150,80" leader-line h:450 legend title:"区域销售分布" /]
```

### 5. 调整大小比例

```tokui
[chart t:pie l:"已完成,进行中,未开始" d:"65,25,10" c:"#52C41A,#FAAD14,#FF4D4F" size:0.6 h:300 show-percent title:"任务进度" /]
```
