# 矩阵图 `[chart t:matrix]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。用矩阵形式展示行列交叉数据。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:matrix` | 必填 | - |
| `d:` | `v1,v2\|v3,v4`（`\|` 分行，`,` 分列） | - |
| `l:` | 行/列标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

---

## DSL 示例

### 1. 基础矩阵图（`\|` 分行）

```tokui
[chart t:matrix l:"产品A,产品B,产品C" d:"10,20,30|15,25,35|20,30,40" h:300 title:"产品评分矩阵" /]
```

### 2. 自定义颜色

```tokui
[chart t:matrix l:"华东,华南,华北,西南" d:"80,65,70,55|72,88,60,45|90,75,82,68" c:"#1677FF,#52C41A" h:350 title:"区域业绩矩阵" /]
```

### 3. 2×2 简单矩阵

```tokui
[chart t:matrix l:"高,低" d:"85,30|20,65" h:250 title:"优先级矩阵" /]
```
