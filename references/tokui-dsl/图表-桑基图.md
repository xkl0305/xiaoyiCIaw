# 桑基图 `[chart t:sankey]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Canvas 自定义渲染。展示流量在不同节点间的分配关系。

数据通过 `nodes:` + `flows:` 两个属性提供（**不用 `d:`**）。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:sankey` | 必填 | - |
| `nodes:` | 节点列表，逗号分隔 | - |
| `flows:` | 流量数据 `来源-目标:值,来源-目标:值`（`,` 分流，`-` 连接，`:` 分值） | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`animation`。

## 容器模式

省略 `nodes:`/`flows:`，用子节点声明：

| 子节点 | 说明 |
|--------|------|
| `[flow from:来源 to:目标 value:值/]` | 一条流量连接 |

---

## DSL 示例

### 1. 基础桑基图（属性模式）

```tokui
[chart t:sankey nodes:"来源A,来源B,中间X,中间Y,去向P,去向Q" flows:"来源A-中间X:100,来源A-中间Y:50,来源B-中间X:80,来源B-中间Y:70,中间X-去向P:120,中间X-去向Q:60,中间Y-去向P:80,中间Y-去向Q:40" h:400 title:"流量分配" /]
```

### 2. 自定义颜色

```tokui
[chart t:sankey nodes:"搜索,广告,直达,页面A,页面B,购买,离开" flows:"搜索-页面A:200,搜索-页面B:100,广告-页面A:150,广告-页面B:80,直达-页面A:50,页面A-购买:180,页面A-离开:220,页面B-购买:100,页面B-离开:80" c:"#1677FF,#52C41A" h:450 title:"用户路径" /]
```

### 3. 容器模式（子节点声明）

```tokui
[chart t:sankey h:400 title:"能源流向"
  [flow from:"煤炭" to:"发电" value:400/]
  [flow from:"煤炭" to:"工业" value:200/]
  [flow from:"天然气" to:"发电" value:300/]
  [flow from:"天然气" to:"民用" value:150/]
  [flow from:"发电" to:"工业用电" value:350/]
  [flow from:"发电" to:"民用电" value:200/]
  [flow from:"发电" to:"损耗" value:150/]
]
```
