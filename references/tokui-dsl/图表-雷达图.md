# 雷达图 `[chart t:radar]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。多维度数据对比，也称蛛网图。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:radar` | 必填 | - |
| `d:` | 单系列 `v1,v2,v3`；多系列 `v1,v2\|v3,v4` | - |
| `l:` | 维度标签（每个轴一个） | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `begin-zero` | 强制从零开始 | `false` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 基础雷达图

```tokui
[chart t:radar l:"销售,管理,IT,客服,研发,市场" d:"65,59,90,81,56,55" h:350 title:"能力评估" /]
```

### 2. 自定义颜色

```tokui
[chart t:radar l:"速度,力量,技巧,耐力,智慧" d:"85,70,90,65,80" c:"#FF4D4F" h:350 title:"球员能力" /]
```

### 3. 多系列对比（`|` 分隔 + 图例）

```tokui
[chart t:radar l:"销售,管理,IT,客服,研发,市场" d:"65,59,90,81,56,55|28,48,40,19,96,27" c:"#1677FF,#FF4D4F" h:400 legend title:"员工A vs 员工B" /]
```

### 4. 从零开始

```tokui
[chart t:radar l:"产品,研发,设计,测试,运维" d:"80,95,70,85,90|60,75,85,65,70" begin-zero c:"#52C41A,#FAAD14" h:400 legend title:"团队能力雷达" /]
```
