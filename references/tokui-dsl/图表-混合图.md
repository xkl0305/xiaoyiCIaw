# 混合图 `[chart t:mix]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。将多种图表类型（如柱状+折线）叠加在同一坐标系。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:mix` | 必填 | - |
| `d:` | 按类型组合 `类型:值,值\|类型:值,值`（`\|` 分系列，每个系列前缀类型名） | - |
| `l:` | x 轴标签 | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

---

## DSL 示例

### 1. 柱线混合（最常见的组合）

```tokui
[chart t:mix l:"Q1,Q2,Q3,Q4" d:"bar:100,200,150,300|line:80,180,120,250" c:"#1677FF,#FF4D4F" h:400 legend title:"营收柱状+趋势折线" /]
```

### 2. 柱状+面积混合

```tokui
[chart t:mix l:"一月,二月,三月,四月,五月" d:"bar:120,80,150,200,170|area:100,90,130,180,160" c:"#1677FF,#52C41A" h:400 legend title:"销量+趋势面积" /]
```

### 3. 多系列混合

```tokui
[chart t:mix l:"2021,2022,2023,2024" d:"bar:200,350,400,500|bar:150,280,320,450|line:180,300,350,480" c:"#1677FF,#52C41A,#FF4D4F" h:450 legend title:"产品线收入对比" /]
```
