# 05 - 布局容器组件

> ⚠️ 本分册穷举所有布局容器组件及其属性。**禁止使用本册未列出的组件名或属性名。**

---

## 组件字典

| 组件 | 类型 | 合法属性 | 说明 |
|------|------|---------|------|
| `card` | 容器 | `tt`, `tx`, `v`, `w`, `hc`, `ht` | 卡片。**`tx`=自闭合叶子卡**。`ht`：`fill`/`accent`/`underline`/`dot`/`pill` |
| `ft` | 容器 | `tx`/裸内容, `v` | 卡片页脚 |
| `row` | 容器 | `v` | 栅格行（12列 grid）。`v:inline` 转 flex |
| `col` | 容器 | `span` | 栅格列（`span` 1-12） |
| `list` | 容器 | `t`, `plain` | 列表。`t:ol` 有序/默认无序 |
| `item` | 容器 | `tx`/裸内容, `l`, `span` | 列表项（同名按父级区分：list/desc/carousel/command-group） |
| `tabs` | 容器 | — | 标签页容器。子项 `tab` |
| `tab` | 容器 | `tt` | 标签项 |
| `accordion` | 容器 | — | 手风琴。子项 `collapse` |
| `collapse` | 容器 | `tt`, `open`, `id` | 折叠面板 |
| `dialog` | 容器 | `tt`, `id`, `clk` | 对话框 |
| `drawer` | 容器 | `tt`, `pos`, `w`, `h`, `id` | 抽屉 |
| `imgs` | 容器 | `s` | 图片网格 |
| `timeline` | 容器 | `v` | 时间轴。`v`：`h`/`horizontal`/`alt`/`alternate`/`card` |
| `ti` | 自闭合 | `tm`, `t`, `tt`, 裸内容 | 时间轴项。`t`：`primary`/`success`/`warning`/`error`/`info` |
| `steps` | 容器 | `v`, `s`, `vd`, `id` | 步骤条。`v` 当前步（1-based） |
| `step` | 容器 | `tt`, `status`, 裸内容 | 步骤。`status`：`error`/`danger` |
| `desc` | 容器 | `cols`, `stripe`, `bordered`, `v`, `lw` | 描述列表。子项 `item`/`desc-item` |
| `desc-item` | 自闭合 | `l`, `tx`, `span` | 描述项 |
| `carousel` | 容器 | `id`, `auto`, `thumb`, `w`, `h`, `ratio` | 轮播。子项 `carousel-item`/`item`/`img` |
| `carousel-item` | 自闭合 | `s`, `tt`, `tx` | 轮播项 |
| `tree` | 容器 | `id`, `l`, `clk`, `chk`, `dis` | 树。子项 `tn` |
| `tn` | 容器/自闭合 | `v`, `tx`, `open`, `leaf`, `chk`, `dis` | 树节点 |
| `menu` | 容器 | `v`, `act`, `bg`, `fc`, `id` | 菜单。`v`：`vertical`/`horizontal`/`inline` |
| `menu-item` | 自闭合 | `tx`, `clk`, `i`, `dis`, `act` | 菜单项 |
| `resizable` | 容器 | `dir`, `min`, `max`, `default`, `w` | 分割面板。`dir`：`h`/`v` |
| `scroll-area` | 容器 | `h`, `w`, `id` | 自定义滚动区域 |
| `sidebar` | 容器 | `w`, `pos`, `collapsible`, `tt`, `bg`, `fc`, `id` | 侧边栏 |
| `sidebar-content` | 容器 | — | 侧边栏内容区 |
| `sidebar-footer` | 容器 | — | 侧边栏页脚 |
| `print-area` | 容器 | `id`, `tt` | 打印区 |

---

## DSL 示例

```
[card tt:项目概览]
[p 这是卡片内容]
[ft 卡片页脚][/ft]
[/card]

[row]
[col span:6][card tt:左侧]左内容[/card][/col]
[col span:6][card tt:右侧]右内容[/card][/col]
[/row]

[tabs]
[tab tt:基本信息]
[p 基本信息内容]
[/tab]
[tab tt:详细配置]
[p 详细配置内容]
[/tab]
[/tabs]

[steps v:2]
[step tt:需求分析 status:done 已完成]
[step tt:方案设计 进行中]
[step tt:编码实现 待开始]
[/steps]

[timeline v:alt]
[ti tm:2024-01 tt:项目启动 项目正式启动]
[ti tm:2024-03 tt:版本发布 t:success v1.0 发布]
[/timeline]

[accordion]
[collapse tt:常见问题1 open]
[p 答案内容]
[/collapse]
[collapse tt:常见问题2]
[p 答案内容]
[/collapse]
[/accordion]

[desc cols:2 bordered]
[desc-item l:姓名 tx:张三]
[desc-item l:年龄 tx:25]
[desc-item l:城市 tx:北京]
[desc-item l:职位 tx:工程师]
[/desc]

[tree l:项目结构 chk]
[tn v:src open]
[tn v:components leaf tx:组件目录]
[tn v:core leaf tx:核心逻辑]
[/tn]
[tn v:package.json leaf chk]
[/tree]
```
