# 散点图 `[chart t:scatter]`

> ⚠️ 禁止编造属性。

---

**自闭合标签**，Chart.js 渲染。展示两组数值的相关性。

## 属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:scatter` | 必填 | - |
| `d:` | `x1,y1;x2,y2;x3,y3`（`;` 分点，`,` 分 xy） | - |
| `c:` | 颜色（`#` 开头），多色逗号分隔 | 自动 |
| `point-radius:` | 点半径 | `3` |

> 另支持通用属性：`title:`、`w:`、`h:`、`legend`、`animation`、`unit:`。

## 容器模式

省略 `d:`，用子节点逐点声明（适合少量数据点）：

| 子节点 | 说明 |
|--------|------|
| `[pt x:值 y:值 label:名称/]` | 单个数据点 |

---

## DSL 示例

### 1. 基础散点图（`;` 分隔各点）

```tokui
[chart t:scatter d:"10,20;20,30;30,25;40,35;50,40" h:300 title:"温度-销量关系" /]
```

### 2. 自定义颜色 + 大点

```tokui
[chart t:scatter d:"5,10;15,22;25,18;35,30;45,42;55,38" c:"#FF4D4F" point-radius:6 h:350 title:"身高-体重分布" /]
```

### 3. 容器模式（子节点声明）

```tokui
[chart t:scatter h:400 title:"门店分布"
  [pt x:10 y:20 label:"门店A"/]
  [pt x:20 y:30 label:"门店B"/]
  [pt x:30 y:25 label:"门店C"/]
  [pt x:40 y:35 label:"门店D"/]
]
```
