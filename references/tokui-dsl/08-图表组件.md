# 图表组件总览

> ⚠️ 本文件仅为图表组件索引。具体用法请查阅各图表类型的独立文档。
> 禁止在本文件中添加组件用法说明。

---

## 通用属性

所有 `[chart]` 共享（`[chart]` 是容器，但通常自闭合）：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `t:` | **必填**，图表类型（见下方索引） | `bar` |
| `d:` | 数据，格式因类型而异 | - |
| `l:` | 标签，逗号分隔 | - |
| `c:` | 颜色列表，逗号分隔，**必须是 `#` 开头的 hex** | 自动 |
| `title:` | 图表标题（居中） | - |
| `w:` | 宽度（数值px或百分比，**禁止带单位**） | `100%` |
| `h:` | 高度（数值px，**禁止带单位**） | `300` |
| `legend` | 显示图例 | `false` |
| `animation` | 启用动画 | `false` |
| `unit:` | 数值单位后缀 | - |

> ⚠️ **不存在的属性**：`labels:`、`colors:`、`data:`、`type:`、`x:`、`y:`。
> ⚠️ **颜色必须带 `#` 前缀**：`c:"#FF4D4F,#FAAD14"` ✅ `c:"FF4D4F"` ❌

## 数据格式速查

| 图表类型 | d 格式 | 分隔符 |
|---------|-------|--------|
| bar/line/pie/area/radar/doughnut/progress | 单系列：`v1,v2,v3` | `,` |
| bar/line/area（多系列） | `v1,v2\|v3,v4` | `\|` 分系列 |
| scatter | `x1,y1;x2,y2` | `;` 分点 |
| bubble | `x,y,s;x,y,s` | `;` 分点 |
| doughnut（多组） | `v1,v2\|v3,v4` | `\|` 分组 |
| treemap | `名称1:值1,名称2:值2` | `,` 分项，`:` 分隔名值 |
| heatmap | `v1,v2,v3,v4` | `,` + `cols:` |
| candlestick | `o,h,l,c;o,h,l,c` | `;` 分K线 |
| box | `min,q1,med,q3,max;...` | `;` 分组 |
| sankey | `nodes:` + `flows:` | 两个独立属性 |
| gantt | `tasks:` 属性 | `\|` 分任务 |
| funnel | `v1,v2,v3` | `,` |
| gauge | 单个数值 | - |
| mix | `bar:v1,v2\|line:v3,v4` | `t:` 定义类型组合 |
| matrix | `v1,v2\|v3,v4` | `\|` 分行 |

## 容器模式

`[chart]` 是容器，支持子节点（非 title/axis/series）：

| 子节点 | 说明 |
|--------|------|
| `[pt x:值 y:值 label:名称/]` | 数据点（scatter/bubble） |
| `[hrow name:名称 value:值/]` | 水平行（funnel/treemap） |
| `[flow from:来源 to:目标 value:值/]` | 流量（sankey） |
| `[task name:名称 start:0 end:5 progress:50/]` | 甘特任务 |
| `[ms name:名称 date:2025-06-15/]` | 甘特里程碑 |

> 容器模式下可省略 `d:` 属性，数据由子节点提供。
